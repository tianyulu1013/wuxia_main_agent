# 一灯：条件穿透、完整恢复与受伤后攻防跃升

状态：作者核心语义已校准；白人量化模型已完成；全库环境待回归。

## 案例价值

一灯同时展示六个容易混淆的规则边界：

1. 一个大招可以有两个可选放法，而非固定双元素。
2. 同一能力中的主动攻击与可控恢复可以相互独立。
3. “无攻击能力”与“攻击力为0”会产生完全不同的结算结果。
4. “伤害一定造成”不等于附带效果一定命中。
5. “恢复初始状态”会同时清除有利与不利，并且不能复活死人。
6. 回合“前400输出承担”是累计数值池，不会把附带效果一起转移。

## 正确语义

- 一阳指选择`土-`或`火-`之一放出。
- 先天功是被动，持续允许主动招式通过两平放出。
- 一阳指保留常规原输出，再以敌我原输出总和形成额外攻击。
- 原输出计算适用攻击加成，但不先扣防御；渔樵耕读400因来源独立，不计入。
- 对阵者只对一阳指伤害承受“一定造成”；“点”仍正常命中判定。
- 恢复分支是独立可控能力。目标完整回到初始状态，死人不可选。
- 使用恢复后，一灯失去攻击能力和治疗能力；九阴总纲恢复两者后可以再次使用。
- 没有攻击能力时可以放出一阳指，但不能形成攻击，敌方原输出也无法被借用。
- 点化使当前敌方人物单独成为弟子并结盟；关系持续本局，当前回合仍结算完。
- 【一灯大师】只减半伤害所致实际损血；生命流失不减半，自身伤害减半。
- 渔樵耕读在一灯本人受伤后出战的回合开始发动，合计承担敌前400输出，只处理数值。

## 白人输出模型

设一灯常规原输出为`S`，敌方原输出为`E`，一阳指合法放出事件为`C`。

`P(C)=16/25=64%`

`E[S]=400`

`E[S+E|C]=830`

因此一阳指追加伤害：

`E[1_C(S+E)]=531.2`

未受伤总输出：

`E[O]=400+531.2=931.2`

- 方差280,482.56
- 标准差约529.61
- 范围0至1600

受伤后渔樵耕读固定增加400：

`E[O_受伤]=1331.2`

方差和标准差不变，范围平移为400至2000。

## 穿透与侧面

- 对阵者所受一阳指伤害一定造成，白人期望确定伤害为531.2。
- 未受伤路线的期望确定伤害构成约57.04%；受伤路线约39.90%。
- 侧面一阳指不是一定造成。
- 一阳指改打侧面时，当前对阵者承受常规原输出期望400，侧面目标承受一阳指期望531.2；两者共享同一回合资源，不能重复加总完整正面期望。

## 生存模型

白人名义输出`X`期望400。

满生命首回合没有渔樵耕读：

`E[L_首回合]=E[X/2]=200`

受伤后出战：

`L=max(X-400,0)/2`

其期望损血为28.96。按完整离散分布递推：

- 从满生命开始约80.84个白人同分布攻击回合归零。
- 一灯在场下没有渔樵耕读，只有伤害损血折半；约12.95次白人同分布攻击事件归零。

这些数字只能说明一灯极克制低额普通输出。生命流失、杀死、清除、异常和高额大招必须另做环境回归。

## 可迁移结论

1. 攻击能力决定攻击事件能否形成；攻击力只决定已形成攻击的数值。
2. 一定造成的对象必须按文字范围读取，伤害与附带效果不可混为一体。
3. 初始状态恢复应读取完整初始快照，不能只当回血或净化。
4. 伤害折半不处理生命流失；伤害向上取整、治疗向下取整。
5. 回合累计代承池与逐项代承是两种模型，必须由牌面文字区分。
