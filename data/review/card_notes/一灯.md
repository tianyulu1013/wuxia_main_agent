# 单卡评审与机制校准笔记：一灯

## 事实与来源
* **卡牌名称**：一灯
* **卡牌分类**：combat_characters（战斗人物）
* **基础属性**：生命 2500，无武器（以拳掌进行基础战斗比拼）
* **原版特技描述**：
  * 内功：九阴总纲： -- 刷回被禁制的大招及失去的攻击能力，本条亦然
  * 先天功：招式两平可放
  * 招式：一阳指：土火 300/+300点，敌我原输出的总和攻击任何一人点，如攻击对阵者则一定造成；可使用一次一阳指使一人恢复初始状态，自此己无攻击力至放出九阴总纲
  * 渔樵耕读：若一灯受伤，则回合开始时先对敌造成400（来源视为渔樵耕读），且敌前400输出由渔樵耕读承担
  * 一灯大师：计算受伤后实际损血仅为一半，且他人不知；一回合正好三相克使敌与己结盟，算作一灯弟子，顺位低于己；不中异常

---

## 作者校准原话
1. **先天功性质**：“先天功是个被动，所以一直生效，就是普通的主动招式放出放法是不被克但至少克敌1张，可见两平放不出来，但先天功可以让任何自己的主动招式通过两平放出来。”
2. **一阳指原输出与伤害独立性**：“一阳指的原输出的总和不是不计算攻击加成是包括攻击加成的，只不过不算防御。注意渔樵耕读的输出不计算在一阳指里，因为这里明确说来源是渔樵耕读。你曾经问我渔樵耕读算不算人头，不算。一阳指不会抹去原有的常规攻击。无攻击力状态不影响渔樵耕读，来源不是一灯。”
3. **点化（结盟）判定**：“点化是b，相克是克敌或者被克都算。”即：4个卡槽中刚好有3个槽位发生克制关系（我克敌或敌克我），剩下1个槽位相平。
4. **一阳指打侧面**：“注意一阳指可以打侧面，但打侧面没有一定造成。”（打侧面退化为常规物理伤害）。

---

## 主要、次要与保底功能
* **主要功能**：强正面消耗型盾、心理博弈核弹（一阳指大招核威慑）。
* **次要功能**：点化控场与外交结盟（多人局中改写阵营）、一阳指单次强力功能性重置（废除敌方增益或净化队友不利）。
* **保底功能**：受伤后《渔樵耕读》的 400 点开场独立伤害与 400 点护盾吸收。

## 常态、失败与上限结算链
* **常态对局链**：未受伤出战 $\rightarrow$ 承受伤害折半受伤 $\rightarrow$ 下回合触发渔樵耕读 400 盾并造成 400 伤 $\rightarrow$ 博弈打出一阳指/金土组合。
* **大招失败链**：打出一阳指但被敌方“木-水-”拦截，一阳指被拦截放不出。因被克招式比拼输出降为 0，仅内功输出 40。但若受伤，下回合仍有渔樵耕读 400 盾保底，实际仅受 100 伤害。
* **上限结算链**：成功打出一阳指强攻正面，打出 1440/1840 点极高额混合穿透伤害；或者反读敌方拦截改打金土，白打敌方 600/1040 点伤害。

## 生存评估

### 正面生存 (Frontal Survival)
* **较肉（等效 5000HP 的被动免伤体）**：基础生命仅有 2500，但由于《一灯大师》折半损血，等效实际生命值为 5000HP。在受伤状态下出战时，每回合正面战斗开始时由渔樵耕读提供 400 点名义护盾。
* **物理防线局限（无绝对闪避/反射）**：一灯大师**无任何反射伤害或战斗无效化（逃生键）的能力**，其生存全靠被动肉度硬吃伤害。面对 600 点名义输出存活 23 回合，面对 800 点大招存活 12 回合。虽然对“一定造成”也能折半，但无法规避受击和次生状态异常。

### 侧面生存 (Sideline Survival)
* **较肉（场下损血折半）**：虽然《渔樵耕读》的 400 护盾在场下（侧面状态）挂机时无法生效，但《一灯大师》的“受伤实际损血折半”特技是全局被动。一灯在场下被全场波及伤害、溅射伤害击中时，其所受伤害依然自动折半，比普通人物更抗揍，但也无任何盾牌代伤。

---

## 优点与缺点

### 优点
1. **常态生存较肉**：等效 5000HP 与 400 护盾为正面出战提供极高的承伤容错率。
2. **极高的决策博弈统治力**：由于先天功的存在，敌方防守陷入被动，极易被一灯打出 950 点的一阳指强穿追加或 600 点的金土反制。
3. **强大的战局改写力**：一阳指的单次复原和点化的结盟是多人局中的战术核武器。

### 缺点
1. **医疗/复原他人的自我封印代价**：**仅当**一灯选择主动使用一阳指的辅助分支功能（使一人恢复初始状态 / 医疗或重置他人）时，才会承受“自此己无攻击力”的自我封印惩罚，此时必须依靠九阴总纲（两平先天功）刷新才能恢复；**常规打一阳指追加输出时完全没有此惩罚**，本尊攻击力不受任何影响。
2. **场下无主动输出与代防机制**：在场下（侧面状态）挂机不上场时，一灯无法为队友抵挡伤害（其折半只保自己，渔樵耕读盾仅正面生效），且无法产生任何主动侧面输出伤害。

## 规则风险与电子化风险

### 规则风险
* **一灯大师“他人不知”**：在实体桌面卡牌游戏中，一灯玩家隐秘记录实际血量可能会因为记血设备导致争议。规则应明确：一灯玩家可以使用便签暗记当前生命值。

### 电子化风险
* **点化弟子“顺位低于己”**：电子化游戏在结算多阵营或多人选战挑战链时，需要对“弟子顺位”在程序中做特殊的挑战权优先级排序逻辑。

## 详细数学演算与博弈论推导全过程

### 1. 基础物理常数与基本对决规则
* **白人输出基线**：内功期望 $40$（两个位置，每个位置 $1/5 \times 100 = 20$）；招式期望 $360$（两个位置，每个位置 $1/5 \times 300 + 3/5 \times 200 = 180$）。合计为 **400 点**。
* **手牌机制**：玩家拥有全部 **8张** 基础牌（金、木、水、火、土、同第一、同第二、同上）可自由选择出牌，一灯与敌方的出牌不是随机抽取，而是完全决策。
* **条件设定**：假定常规战斗敌方招式名义输出 $A_{敌，招式} = 600$ 点，敌我内功名义输出均为 $40$ 点。
* **事件 C (一阳指成功释放)**：一灯打出土、火，且**两个位置均没有被克**。若敌方选择随机盲打（各元素 1/5 概率），放出率 $P(C) = 4/5 \times 4/5 = 64\%$。

---

### 2. 条件期望推演过程 (Conditional Expectation)

在一阳指“成功放出”（事件 C 发生）的分支下，一灯在槽位 3&4 必然未被克（即发生平手或克敌），敌方对应槽位必然未克制一灯（即发生平手或被克）：

#### A. 一灯招式位的条件期望：
* 排除被克可能后，一灯单槽克敌概率升为 $1/4$，平手概率升为 $3/4$。
* 单槽条件期望 $= 1/4 \times 300 + 3/4 \times 200 = 75 + 150 = 225$ 点。
* 一灯两招式位条件输出：$E[x_{self, moves} | C] = 225 + 225 = 450$ 点。

#### B. 敌方招式位的条件期望：
* 排除克敌可能后，敌方单槽被克概率升为 $1/4$，平手概率升为 $3/4$。
* 单槽条件期望 $= 1/4 \times 0 + 3/4 \times 200 = 150$ 点。
* 敌方两招式位条件输出：$E[x_{opp, moves} | C] = 150 + 150 = 300$ 点。
* 敌方名义招式输出折算（由无条件期望 360 点，折算到未克制一灯条件下的名义输出）：
  $$A_{敌，招式，条件} = A_{敌，招式} \times \frac{E[x_{opp, moves} | C]}{E[x_{opp, moves}]} = 600 \times \frac{300}{360} = 500 \text{ 点}$$

#### C. 一阳指追加伤害：
一阳指伤害为双方名义招式输出之和（不扣防御）：
$$\text{一阳指伤害} = A_{一灯，招式，条件} + A_{敌，招式，条件} = 450 + 500 = 950 \text{ 点 (一定造成)}$$

---

### 3. 不同状态下的总输出期望

#### 场景 1：一灯未受伤时（第 1 回合，盲打对手）
* **支路 A：一阳指释放成功（概率 64%）**：
  $$\text{总输出} = \text{内功} (40) + \text{招式比拼} (450) + \text{一阳指追加} (950) = 1440 \text{ 点}$$
* **支路 B：一阳指被拦截（概率 36%）**（招式比拼被克为 0）：
  $$\text{总输出} = \text{内功} (40) + \text{招式比拼} (0) = 40 \text{ 点}$$
* **总输出期望**：
  $$E[\text{未受伤期望}] = 0.64 \times 1440 + 0.36 \times 40 = 936 \text{ 点/回合}$$

#### 场景 2：一灯已受伤时（激活《渔樵耕读》先手 400）
* **支路 A：一阳指释放成功（概率 64%）**：
  $$\text{总输出} = \text{内功} (40) + \text{招式比拼} (450) + \text{一阳指追加} (950) + \text{渔樵先手} (400) = 1840 \text{ 点}$$
* **支路 B：一阳指被拦截（概率 36%）**：
  $$\text{总输出} = \text{内功} (40) + \text{招式比拼} (0) + \text{渔樵先手} (400) = 440 \text{ 点}$$
* **总输出期望**：
  $$E[\text{受伤期望}] = 0.64 \times 1840 + 0.36 \times 440 = 1177.6 + 158.4 = 1336 \text{ 点/回合}$$

#### 场景 3：无攻击力封印期（一灯使用过复原效果后）
一灯常规出牌对决的输出降为 0：
* **若未受伤**：总输出 $= 0$。
* **若已受伤**：总输出 $= 400$ 点/回合（仅限渔樵耕读先手输出，无本尊伤害）。

### 4. 招式决策博弈矩阵 (Game Theory Payoff Matrix)
当敌方得知一灯身份，并在招式位 3&4 留牌，固定使用“木-水-”进行对位拦截时，双方的出牌决策收益如下：

* **一灯的可选策略**：
  * $A_1$：强攻一阳指（打出土、火组合）。
  * $A_2$：反制拦截（打出金、土组合）。
* **敌方的可选策略**：
  * $B_1$：盲打出牌（各属性 1/5 概率）。
  * $B_2$：针对性防御（打出木、水组合）。

以下是在**一灯已受伤（渔樵耕读 400 盾及折半已激活）**的前提下，不同组合的收益（一灯输出伤害, 一灯净受伤）详细结算过程：

#### A. 组合 $(A_1, B_1)$ —— 强攻一阳指 vs 敌方盲打
* 一阳指成功放出：
  * 一灯总输出 = 内功(40) + 招式(450) + 一阳指(950一定造成) + 渔樵(400) = 1840点（其中 950 穿透）。
  * 敌方名义输出 = 内功(40) + 招式期望(360) = 400点。
  * 一灯承伤：400 点被渔樵耕读盾完全吸收，一灯净受伤 = 0。
* **收益值 $(A_1, B_1) = (\text{一灯输出: } 1840 \text{ [内功40+招式450+渔樵400+一阳指950穿透]}, \quad \text{一灯受伤: } 0)$**。

#### B. 组合 $(A_1, B_2)$ —— 强攻一阳指 vs 针对防御
* 一灯被打出土、火，被敌方木、水双克。一阳指被拦截失败。
  * 一灯总输出：内功(40) + 招式被克(0) + 一阳指被拦截(0) + 渔樵(400) = 440点。
  * 敌方输出：内功(40) + 招式双克敌(600) = 640点。
  * 一灯承伤：640 点扣减渔樵耕读 400 盾后剩余 240 点，折半扣减 $240 / 2 = 120$。一灯净受伤 = 120。
* **收益值 $(A_1, B_2) = (\text{一灯输出: } 440 \text{ [内功40+渔樵400]}, \quad \text{一灯受伤: } 120)$**。

#### C. 组合 $(A_2, B_1)$ —— 反制金土 vs 敌方盲打
* 一灯改出金、土；敌方盲打：
  * 一灯总输出：内功(40) + 招式比拼(360) + 渔樵(400) = 800点。
  * 敌方输出：内功(40) + 招式期望(360) = 400点。
  * 一灯承伤：400 点名义全额被盾吸收。一灯净受伤 = 0。
* **收益值 $(A_2, B_1) = (\text{一灯输出: } 800 \text{ [常规伤害]}, \quad \text{一灯受伤: } 0)$**。

#### D. 组合 $(A_2, B_2)$ —— 反制金土 vs 针对防御（完美反读）
* 一灯打出金、土，完美对位克制敌方的木、水：
  * 一灯总输出：内功(40) + 招式克敌(600) + 渔樵(400) = 1040点。
  * 敌方输出：内功(40) + 招式被克(0) = 40点。
  * 一灯承伤：40 点被盾全额吸收。一灯净受伤 = 0。
* **收益值 $(A_2, B_2) = (\text{一灯输出: } 1040 \text{ [常规伤害]}, \quad \text{一灯受伤: } 0)$**。

### 5. 穿透率占比计算过程

* **未受伤状态下，选择攻击正面对战者**：
  $$\text{穿透占比} = \frac{E[\text{一阳指穿透伤害}]}{E[\text{总伤害}]} = \frac{0.64 \times 950}{936} = \frac{608}{936} \approx 65.0\%$$
* **已受伤状态下，选择攻击正面对战者**（由于渔樵先手贡献 400 点常规伤害）：
  $$\text{穿透占比} = \frac{E[\text{一阳指穿透伤害}]}{E[\text{总伤害}]} = \frac{0.64 \times 950}{1336} = \frac{608}{1336} \approx 45.5\%$$
* **选择攻击敌方侧面（场下人物）**：
  一阳指退化为常规物理伤害。
  $$\text{穿透占比} = 0\%$$

---

### 6. 侧面输出期望定义与计算

* **情况 A：隔空侧面输出（一灯正面出战，一阳指选择攻击敌方侧面/场下人物）**：
  $$\text{期望侧面输出} = P(C) \times 950 = 0.64 \times 950 = 608 \text{ 点常规物理伤害}$$
* **情况 B：场下挂机（一灯自身处于场下，不上场）**：
  一灯无场下自动输出特技。
  $$\text{期望侧面输出} = 0 \text{ 点}$$
