# 燕十三评价摘要

状态：作者核心语义已校准；第一轮输出、夺冠与白人压力模型已完成；真实多人环境回归开放。

燕十三是首个明确的**夺冠型名次保障**锚点。第十五剑成功放出时，不再杀死敌人，而是把燕十三改为普通死亡；无论燕十三最终是否死亡，其所属玩家都已经取得最高胜利顺位的第一名。这个结果不能折算成伤害或穿透。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 伤害优先主值720，标准差370.94；夺冠优先直接尝试第十五剑时为白人400 |
| 确定穿透输出 | 0，穿透率0；第十五剑是胜利触发，不是穿透伤害 |
| 侧面输出 | 使用第十四剑时，每名在场侧面敌期望36、标准差48；夺冠主线通常为0 |
| 正面生存 | 一般偏弱；2500生命，无减伤恢复，白人压力期望约6.69495回合 |
| 侧面生存 | 偏弱；除不中封外没有侧面硬防 |
| 全局影响 | 有条件较强；第十四剑可攻击所有在场敌并附狂，但与夺冠牌形竞争 |

普通对手面前，如果只剩一次机会，直接尝试第十五剑，夺冠率为`7/25=28%`。如果预计至少还有下一次出战，首回合先尝试夺命十三剑更优：两回合内夺冠率为`51.04%`。与谢晓峰作战时，夺命十三剑成功会连带第十五剑，首回合夺冠率直接达到`16/25=64%`。
