# 战斗人物功能路由

本目录只用于战斗人物。附加人物、物品、称号和场景不按人物功能分类。

先标记一个主要功能，再标记零个或多个次要功能。主要功能决定比较锚点和评价权重。

## 当前功能模块

- 正面作战：`frontal-combat.md`
- 侧面生存：`side-survival.md`
- 辅助与调度：`support-and-dispatch.md`
- 控制与规则干预：`control.md`
- 全局局势与关系政治：`global-influence.md`

尚未充分校准的功能可先记录为次要标签，但不得凭空建立评分标尺。

## 判断方法

主要功能不是文本最长或特技最多的部分，而是：

- 最经常兑现的胜负贡献；
- 失去后整张人物最明显失去的核心价值；
- 玩家选择此人占据一个人物名额的主要理由。

不同功能只比较对应维度。正面输出差距只能说明正面作战差距，不能直接推出不同功能人物的整卡强弱。
