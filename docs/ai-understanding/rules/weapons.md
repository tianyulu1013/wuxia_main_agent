# AI 专项理解规则：兵器物理法则与结算

本机制模块仅服务于 AI 对五行卡牌中兵器（Weapons）系统与普通攻击（Basic Attacks）的结算与分析。

## 1. 兵器持有与声明基础

1. **默认持有出战**：所有人物出战时都默认持有且使用自己携带的兵器进行攻击，不存在“空手/无兵器”真空状态。
2. **无兵器默认拳掌**：如果人物卡牌上的“兵器”字段没有任何标注（或为空），则该人物在逻辑上默认以**“拳掌”**作为出战兵器。
3. **多兵器冲突与声明**：
   * 携带多种物理兵器的人物（例如兵器字段标注为 `刀/剑` 或 `枪/剑`），必须在回合开始（对阵前阶段）**声明本回合具体使用哪一种兵器**出战。
   * **锁定法则**：一旦声明，在一回合内通常**不能切换兵器**。
   * **特技互斥效应**：由于锁定法则，该人物身上需要不同兵器限制（例如带有 `（刀）` 和 `（剑）` 标注）的特技，在同一回合内**绝对无法同时激活或生效**。

## 2. 兵器类型的兼容性与特例

1. **拳掌与暗器的通用兼容性**：
   * **拳掌类**与**暗器类（奇门暗器）**特技在逻辑上被视为“无处不在的辅助特技”。
   * 它们可以与任何其他已声明的兵器共存。即如果声明使用“剑”出战，人物在同一回合中依然可以使用拳掌特技或暗器特技。
2. **双持兵器的独占性限制**：
   * 如果人物声明使用的是**双持兵器**（如弓、双持短兵等，但暗器类不在此限），表示双手被占满。
   * **独占限制**：使用双持兵器出战时，人物**无法使用任何拳掌类特技**。

## 3. 【博】（博通万器）的最高特权

* **“博”字标记**：兵器字段写有 `【博】` 的人物（如赤尊信、沈浪、王怜花等）属于兵器大师。
* **特权 A：免除锁定限制**：他们不需要在回合开始锁死某一种兵器，可以在同一回合内声明任意兵器。
* **特权 B：多兵器特技共存**：他们可以在同一回合内**同时触发并使用多种不同兵器限制（刀、剑、奇门等）的特技**，完全豁免兵器互斥效应。

## 4. 学习与复制特技时的兵器派生

* **虚拟持有**：当人物通过“学会”、“复制”或“模拟”等特技获得了一个有特定兵器要求（如 `（剑）`）的招式或武功时，该人物在结算此项特技时，身上自动**“虚拟视为持有”**了该兵器。
* **判定意义**：防止复制来的大招因为手中没有物理兵器卡而直接宣告放不出，确保特技逻辑的自洽性。

## 5. 普通攻击（普攻）的属性继承

* **普攻类型**：普通攻击的伤害属性（是刀伤、剑伤还是拳掌伤害），在结算伤害加倍、免疫或传递时，**自动继承为本回合出战时声明使用的兵器类型**。无兵器出战者，其普通攻击属性为“拳掌”。
