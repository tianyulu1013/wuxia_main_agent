# 丁典：正面输出

## 一、模型范围

这是统一的白人均匀五行、防御前名义输出模型，不代表双方知情选牌后的最优策略，也不代表全库人物平均输出。

假设：

- 四个对应位置的结果相互独立。
- 丁典在每个位置克敌、相平、被克的概率分别为`1/5、3/5、1/5`。
- 两个招式位放置两张有效土。
- 不计目标防御、攻击加成、其他卡牌特技和死亡截断。
- 无影神拳在两个招式位都未被克时放出，并增加一份200大招攻击。

## 二、变量

记：

- `I1、I2`：两个内功位的基础输出，各自在克敌时为100，否则为0。
- `Y1、Y2`：两个招式位的基础输出，克敌为300，相平为200，被克为0。
- `C`：两个招式位都未被克。
- `B=200×1_C`：无影神拳输出。
- `X=I1+I2+Y1+Y2+B`：丁典对当前对阵者的总名义输出。

## 三、无影神拳放出率

每个招式位不被克的概率为：

`P(未被克)=1/5+3/5=4/5`

两个招式位均未被克：

`P(C)=(4/5)^2=16/25=64%`

其中包含：

- 至少一张克敌、另一张克敌或相平：按主动大招默认条件放出；
- 两张均平：由“两平可放”额外允许。

只要其中一张被克，无影神拳不能放出。

## 四、期望

两个内功位：

`E[I1+I2]=2×(1/5×100)=40`

每个招式位：

`E[Yi]=1/5×300+3/5×200=180`

两个招式位：

`E[Y1+Y2]=360`

无影神拳：

`E[B]=200×16/25=128`

总期望：

`E[X]=40+360+128=528`

因此，无影神拳相对白人400增加128期望输出，增幅为32%。

## 五、方差推导

### 5.1 内功部分

单个内功位：

- `E[I]=20`
- `E[I²]=1/5×100²=2000`
- `Var(I)=2000-20²=1600`

两个独立内功位：

`Var(I1+I2)=3200`

### 5.2 招式基础部分

单个招式位：

`E[Y]=180`

`E[Y²]=1/5×300²+3/5×200²=42,000`

`Var(Y)=42,000-180²=9,600`

两个招式位基础和`S=Y1+Y2`：

- `E[S]=360`
- `Var(S)=19,200`
- `E[S²]=19,200+360²=148,800`

### 5.3 无影神拳与招式基础输出的相关性

无影神拳不是独立固定概率奖励：它只有在两个招式位均未被克时出现，而这些牌形的基础输出本来就较高。

`E[B²]=200²×16/25=25,600`

在`C`成立时：

`E[S×1_C]=2×E[Y]×P(另一招式位未被克)`

`=2×180×4/5=288`

所以：

`2E[SB]=2×200×288=115,200`

招式基础与大招合计`Z=S+B`：

`E[Z²]=148,800+25,600+115,200=289,600`

`E[Z]=360+128=488`

`Var(Z)=289,600-488²=51,456`

再加入独立内功部分：

`Var(X)=51,456+3,200=54,656`

因此：

- 期望：528
- 方差：54,656
- 标准差：`√54,656≈233.79`
- 变异系数：`233.79÷528≈44.28%`
- 范围：0至1000

## 六、完整离散分布

| 总名义输出 | 概率 |
|---:|---:|
| 0 | 2.56% |
| 100 | 1.28% |
| 200 | 15.52% |
| 300 | 12.80% |
| 400 | 3.52% |
| 500 | 0.32% |
| 600 | 23.04% |
| 700 | 26.88% |
| 800 | 11.68% |
| 900 | 2.24% |
| 1000 | 0.16% |

概率合计100%。无影神拳把大量原本的400至500输出牌形平移到600至700区间，但没有制造高额终结爆发。

## 七、失败、上限与截断

### 失败下限

- 两个招式位至少一张被克时，无影神拳不能放出。
- 四个位置均未克敌且两个招式位都被克或没有形成基础输出时，总输出可能为0。
- 0输出概率为2.56%，与白人相同，因为最低牌形同时不满足无影神拳。

### 现实上限

- 两个内功位均克敌：200。
- 两个招式位均克敌：600。
- 无影神拳：200。
- 合计1000。

### 死亡截断

本模型假设目标允许四个卡位和无影神拳完整结算。若目标在前序卡位死亡，后续卡位和大招是否继续需要按实际死亡时点处理，不能把1000视为必然完整打出。

## 八、穿透

丁典没有“一定造成”“破”“生命流失”或其他确定穿透：

- 基础四卡普攻可正常防御。
- 无影神拳200为普通大招攻击，也可正常防御。
- 期望确定穿透输出：0。
- 确定穿透占期望总输出：0%。

## 九、策略边界

64%是敌方各位置均匀独立时的白人参考。实战中双方均从完整基础手牌主动摆放，敌方可以针对两张土的已知放法；丁典也能利用完整手牌调整复制卡位置。完整博弈需要同时考虑：

- 保住无影神拳的收益；
- 主动寻求克敌以输出并回满；
- 被克但不致死同样能够回满；
- 相平招式会留下200损血，却有利于双平放出无影神拳。

因此，针对环境下不能只优化大招放出率，还要同时优化当回合输出和回合末生命。
