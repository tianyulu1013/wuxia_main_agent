# 核心规则：基础战斗与计算基线

状态：作者确认。  
加载：设计、改卡、评价时始终加载。

## 基础结算

- 内功相克：被克者损失100生命。
- 内功相平：双方无事。
- 招式相克：被克者损失300生命。
- 招式相平：双方各损失200生命。

## 单个位置的基础概率

在五行均匀的基础估算中，每个对应位置：

- 克敌概率为 `1/5`。
- 被克概率为 `1/5`。
- 相平概率为 `3/5`。

计算组合条件时优先使用独立事件乘法，不为简单概率枚举全部牌形。

例如，两张招式都不被克的概率为：

`4/5 × 4/5 = 16/25`

## 白人输出基线

没有特技的白人每回合期望输出为400：

- 每个内功位期望输出：`1/5×100=20`，两个共40。
- 每个招式位期望输出：`1/5×300+3/5×200=180`，两个共360。
- 合计：`40+360=400`。

白人400只用于以正面作战为主要功能的战斗人物比较，不用于附加人物、物品、称号或场景。

## 主动特技默认放出条件

主动大招必须先在所属位置满足牌面放法。

默认还要求：

1. 放法中的每一张卡都没有被克。
2. 放法中至少一张卡克敌。

只要其中一张被克，即使另一张克敌，也不能放出。牌面明确改变条件时才按例外处理。

评估主动大招必须检查：

- 占用哪些位置。
- 能否由现有八张基础卡组成。
- 放出概率。
- 放不出时剩余的基础伤害。
- 是否与同卡其他主动大招争夺位置。

## 单项修正

“单项输出提高”“单项受伤削减”“单项受伤反伤”等效果，先对每一项伤害分别处理，再合计本回合总量。不得先合并总伤害后只修正一次。

## 计算原则

- 先算默认基础结算，再叠加特技。
- 优先写公式和条件，不用穷举代替简单概率。
- 特定牌形的爆发不等于整体期望。
- 牌面大数字只有乘以合法放出率、目标可用率、结算时序和存活到结算的概率后，才能进入常态评价。
