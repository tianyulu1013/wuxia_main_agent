# 丁鹏评价摘要

状态：第一轮机制与输出模型已完成；生存、全局影响和最终评分等待第二、三轮统一回归。

丁鹏是正面终结与单目标控制型人物。每次回合开始自动对对阵敌造成一项800附加伤害，【魔刀】再把丁鹏此后每一项实际造成的伤害提高到不低于本局已知最高单项伤害。面对无能力高生命人物、且此前最高伤害不超过800时，正面名义输出期望为2400、标准差640；神刀斩另有28%概率使敌彻底死亡，但直接死亡不冒充伤害或穿透输出。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 主值2400；一般公式为`3×max(H,800)` |
| 输出波动 | 主值方差409600，标准差640，范围800至4000 |
| 确定穿透输出 | 0；【魔刀】不能把完全防成0的事件重新变成伤害 |
| 直接终结 | 神刀斩对白人放出率28%，成功则敌彻底死亡 |
| 侧面输出 | 0 |
| 正面生存 | 暂评一般；3200生命，无直接硬防，依赖失灵、抢先攻击与先杀敌 |
| 侧面生存 | 暂评一般偏弱；无独立侧面防御 |
| 全局影响 | 暂评较弱；主要局限于本人对阵，但永久破除一件本回合非神兵武器会留下持续削弱 |
