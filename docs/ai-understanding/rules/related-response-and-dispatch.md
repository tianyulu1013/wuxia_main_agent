# 专项规则：相关、不相关与派遣

加载关键词：相关、不相关、派出、派遣、借出、召回。

## 相关与不相关

- 相关表示两个人物之间发生具有指向性的交互事件。
- 不相关表示该行为不按相关事件处理。
- 不相关不自动等于所有人物都同意该行为；具体操作权限仍以牌面和作者裁定为准。

## 不相关派遣的已确认案例

下列派遣均不需要被派往人物或其玩家同意：

- 段正明将大理三公整体派到场上任一人物处。
- 段正淳将一名或数名大理四护卫借到其他人物处。

四护卫可以任意选择其中一名或数名借出；借出后，对应护卫及其效果停留在被派往的位置，直至被召回或规则另有变化。

## 原人物死亡或离场后的已派出单位

针对大理三公和大理四护卫：

- 已经派出的三公或护卫不因原人物死亡或离场而自动消失或召回。
- 它们停留在原来的位置。
- 后续由谁能够召回、再次派遣或改变其位置，取决于当时仍存在的牌面能力。

本条只确认大理三公和大理四护卫，不自动推广到所有召唤物或附加人物。
