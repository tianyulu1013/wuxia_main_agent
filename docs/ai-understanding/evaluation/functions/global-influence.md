# 战斗人物功能：全局局势与关系政治

加载条件：战斗人物主要通过结盟、阵营、名次、人物关系、战斗对象循环、地点或其他整局局势产生价值。

## 评价问题

- 能力改写默认游戏流程的哪个环节。
- 理论适用对象有多少。
- 发动权掌握在自己、队友、敌人还是任意玩家手中。
- 其他玩家是否可以拒绝或不配合。
- 参与者为什么愿意发动，需让出什么名次或利益。
- 理论覆盖面与实际触发率分别是多少。
- 形成的结盟是否会减少正常战斗、改变围攻或改变胜利顺位。
- 当前阵容强弱是否会改变他人选择。
- 本人的正面作战只是保底，还是仍是主要贡献。

## 固定分账维度

每张战斗人物的全局影响必须独立登记：

1. **己方辅助**：治疗、恢复、代挡、强化、调度或发动权保护。
2. **敌方削弱**：封锁、强制发动、攻击无效、资源破坏或关系改变。
3. **局势控制**：结盟、顺位、战斗对象、物品归属、地点、循环终止或全场规则改写。
4. **覆盖范围**：单人、单方、多方或全场。
5. **持续频率**：一次、单回合、条件反复、持续本局。
6. **发动权与可靠性**：主动、可控、被动自动；是否依赖敌方、物品、座位或其他前提。
7. **净收益与双刃性**：影响是否稳定有利，是否同时波及己方或消耗本人。

“影响强度”和“净收益稳定性”必须分开。全场双刃规则可以影响很强，但净收益阵容依赖；不能因此把影响力写低，也不能把影响强直接等同于整卡收益高。
