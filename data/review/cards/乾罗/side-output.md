# 乾罗：侧面输出

## 1. 额外回合改打另一敌

乾罗可在正常回合后把额外回合投向任意处另一名敌人。对该侧面目标，未填空且矛用于进攻时：

`L_0=B+1000`

- 期望1400；
- 方差22400；
- 标准差149.6663；
- 范围1000—1800；
- 实战穿透输出1000；
- 穿透率71.4286%；
- 严格一定造成输出0。

填空 `k` 次后：

`E[L_k]=400+1000×2^k`

实战穿透输出为 `1000×2^k`。

## 2. 与正面总量的关系

1400不是在1800之外再额外增加的输出。两回合总资源固定，且只有一把矛：

- 集中同一敌：该敌期望1800；
- 正常回合攻击甲、额外回合攻击乙，并把矛给乙：甲期望400，乙期望1400；
- 若把矛给甲，则甲期望1400，乙期望400。

这是一种输出分配与跨位置追击能力，不应在全场总输出中重复计数。

## 3. 侧面反击

乾罗受到有来源的侧面伤害趋势时，可用矛反击来源：

- 未填空时固定1000“破”；
- 填空 `k` 次后为 `1000×2^k`“破”；
- 反击不撤销来袭攻击；
- 正常回合及其追加行动中已经用矛抵挡或进攻时，不能再反击；
- 无来源事件反击落空。

反击属于事件条件值，触发频率未知，不并入1400的额外回合主值。

## 4. 边界

- 额外战斗目标可在场外，但不能在破空。
- 额外回合仍是正面对战；这里把改打另一敌的收益登记为侧面输出，是为了衡量其跨当前对阵关系的投射能力。
- 若选择用矛防御，目标仅承受基础期望400，穿透归零。
