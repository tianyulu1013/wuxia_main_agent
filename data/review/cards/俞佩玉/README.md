# 俞佩玉评价摘要

状态：作者核心语义已校准；环境回归开放。

俞佩玉能把四张牌的攻击力归并成高度稳定的1800单击，以假身份承接侧面伤害与不利，并在阎王债启动后强制全场可控技发动，再用温柔敦厚选择性恢复。他的全局影响很强，但净收益依赖阵容和管理。

| 全局影响 | 强；全场发动权改写，双刃且高度阵容依赖 |
