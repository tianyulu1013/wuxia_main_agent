# 俞佩玉：攻击力归并与双生命检定案例

## 适用范围

本案例用于两类后续分析：

1. 战斗卡之间可以搬移攻击力，但加值本身不能凭空形成攻击；
2. 同一人物具有多条生命状态、条件重生和不同死亡检定点。

完整证据与作者原问原答见`data/review/workcards/batch_013_121_俞佩玉.md`。

## 攻击力归并模型

作者确认：

- 无相神功在结算时临时分配总计1000；
- 它不能让本来没有输出的卡形成攻击；
- 先天无极只搬己方战斗卡，一回合无限次，每次搬走来源卡的全部攻击力；
- 无相神功已经分配到该卡的数值也一并搬走；
- 一张卡的可搬原生攻击力按其最多能打出的攻击记：内功100，招式300。

因此两张内功与两张招式共有`100×2+300×2=800`可搬原生攻击力。只要至少一张卡已经形成合法攻击，800与无相神功1000都能归并到该攻击，总计1800。

均匀五行下：

`P(四张全无攻击)=(4/5)^2×(1/5)^2=16/625`

所以最大名义输出分布为：

- 0：16/625；
- 1800：609/625。

期望1753.92，方差80,820.6336，标准差284.2897，变异系数16.21%。

### 可迁移判断

遇到相似搬移能力时，必须分别回答：

1. 哪些数值属于可搬资源？
2. 搬移是否包含后来分配的加值？
3. 搬移能否创造攻击，还是只改变已有攻击的大小？
4. 可搬次数与每次搬移幅度是什么？
5. 最大总输出路线是否牺牲攻击次数？

不能看到“任意搬移”就默认可以从敌方取值、部分搬移或把无攻击牌变成攻击。

## 双生命状态机

以`(H本体,H假身份,R)`表示状态，`R`为假身份是否已重生过。初始为`(2800,2800,0)`。

- 侧面伤害与不利只处理假身份。
- 正面结果向本体和假身份各处理一份。
- 假身份死亡且本体存活时，无次数上限地重生为2800；清除、离场不重生。
- 假身份第一次重生后，本体取得阎王债。
- 本体死亡时，回合中比较回合开始双血；其他情形比较本次致死事件前双血。不同才重生。
- 同时死亡时先按检定点处理本体；本体仍存活后，假身份才可重生。

### 可迁移判断

多血条人物不得直接把生命相加。至少要登记：

1. 每类攻击、伤害、不利、生命流失与直接效果命中哪条状态；
2. 死亡检定读取结算前、结算后、回合开始还是其他快照；
3. 多状态同时死亡的顺序；
4. 重生是否限次，是否依赖另一状态存活；
5. 杀死、清除、离场是否进入同一重生流程。

俞佩玉的结论不可泛化为“有两条2800就等于5600生命”。从初始相等状态只受对称正面伤害时，本体死亡检定仍相等，基础正面承伤只相当于2800。

## 发动权边界

阎王债把所有可控技变为强制自动立即发动，相当于删去“可”，但不把目标和选项控制权转给俞佩玉。温柔敦厚可以在任意时点、场上或场下、任意多次把任意多项技能恢复为可控，恢复后仍由原拥有者控制。

可迁移原则：强制发动、发动许可和选项控制权是三个独立维度，不能互相替代。
