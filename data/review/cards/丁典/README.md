# 丁典评价摘要

状态：作者核心语义已校准；白人输出与基础生存模型已完成；环境回归开放。

丁典是以“相克后回满”和“每个特技实例只对自己生效一次”为核心的恢复型正面人物。无影神拳只把白人输出由400提高到528，真正的强项是对低中额基础攻击和重复特技形成极强消耗优势；入神坐照还提供一次满血复活，而且神照经已经记录过的特技实例不会因此重置。弱点是每个特技的首次使用仍会正常生效，高额首击、杀死、清除、离场及凌退思剧情均可能绕过长期恢复。

| 维度 | 摘要 |
|---|---|
| 正面输出 | 白人均匀五行、防御前期望528；方差54,656；标准差233.79；范围0至1000 |
| 确定穿透输出 | 0；无影神拳与普攻均可正常防御 |
| 侧面输出 | 0；没有攻击当前对阵者以外目标或场下自动输出 |
| 正面生存 | **很强**；可用第一条生命抗衡一项单独的致死或高爆发能力，且该实例在复活后仍已消耗；通常需要多项不同高爆发／致死能力才能连续突破 |
| 侧面生存 | **很强**；场下同样按实例限次并保留账本，另有一次满血复活；但清除、离场、彻底死亡等仍可绕过 |
| 全局影响 | **基本没有**；主要收益全部集中于丁典本人，固定关系不是主动辅助，凌退思剧情还是对丁典的负面事件 |
