# 燕十三：名次保障／夺冠转化

## 一、类型

燕十三是**夺冠型**，不是白清儿式的保底型：

- 白清儿主要降低垫底和失败概率，接近保住前二；
- 燕十三把一个可重复尝试的主动剑法事件直接转化为最高顺位第一名。

该能力提高的是第一名概率，不只是避免最后。

## 二、最高胜利顺位

规则书当前胜利顺位第一项是“燕十三：第十五剑”。因此：

- 第十五剑成功放出即触发第一名；
- 燕十三自己的普通死亡不撤销胜利；
- 敌方无敌与否无关，因为燕十三使用时不再杀敌；
- 放出后不能被其他响应停止；
- 若同时存在“一位失败”，仍要按规则书的胜利与失败抵消规则处理。

## 三、单次与累计概率

普通对手：

- 初始直接第十五剑：28%
- 解锁两平后：64%
- 两平、混克均解锁后：72%

与谢晓峰：

- 任意剑法成功均连带第十五剑；
- 首回合选择夺命十三剑，夺冠率64%。

在忽略死亡的有限出战模型中：

- 一次机会：28%
- 两次机会：51.04%
- 三次机会：74.08%
- 五次机会：94.4909%

白人承伤联合压力测试中，最优策略在死亡前触发第一名的概率约96.396%。该值不是实际胜率，只说明“2500生命＋可扩张放法”足以提供多次高质量夺冠窗口。

## 四、主要反制

反制必须发生在剑成功放出前：

- 混：关闭身份描述，使放剑不再自动带来第一名；
- 迟、惊：限制主动大招；
- 点、禁招：破坏两个招式位；
- 抢先杀死、清除、离场：消灭后续尝试机会；
- 令燕十三无法出战或在游戏结束前没有足够回合；
- 让其同时承受更高顺位的一位失败并发生抵消。

封无效，因为燕十三不中封。

## 五、结论

暂评：**很强（夺冠型）**。

燕十三建立了这个维度的上端锚点：名次保障不仅是避免输，也包括把可计算的战斗牌形直接转化为第一名。其强度来自胜利顺位、无法在放出后响应停止、牌形永久扩张和谢晓峰特例；主要风险集中在成功放剑之前。
