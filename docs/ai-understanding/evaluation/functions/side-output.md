# 战斗人物功能：侧面目标输出与场下输出

加载条件：人物能攻击当前对阵者以外目标、同时攻击多人，或本人不出战时仍能制造伤害。

## 三种输出必须分账

1. **侧面目标输出**：人物本人正在出战，但攻击非对阵者。
2. **场下输出**：人物本人不是当前出战者，仍产生伤害。
3. **多目标输出**：一次影响对阵者以外的一个或多个人物。

不能把反射、队友攻击、敌方自击或全局事件中的其他人物战斗一律算作该人物个人侧面输出。来源不属于该人物时，登记为辅助、控制或反噬贡献。

## 必填字段

- 目标选择：固定、随机、任意一人、任意处或按距离。
- 单目标期望、方差、标准差、范围。
- 多目标数量变量和总量公式。
- 目标间是否独立；共享同一随机变量时必须保留协方差关系。
- 是否一定造成、破或可正常防御。
- 是否挤占、重分配或共享正面输出资源。
- 发动条件、次数、时序及人物是否必须出战。
- 场下能否发动；不能时明确登记0。

## 资源共用

同一批伤害从正面改投侧面时，只能登记为输出重分配：

- 写明正面减少多少；
- 写明侧面增加多少；
- 不得把改投前完整正面输出与改投后侧面输出相加。

## 多目标

若同一伤害变量`D`同时作用于`n`名目标：

- 总期望可写为`nE[D]`；
- 各目标完全相关时，总方差不是逐目标方差简单相加；
- 必须写出总量公式和目标人数依赖。
