# 专项规则：无敌与防御状态生效

状态：作者确认。
触发关键词：无敌、不中、抢先结算、破除无敌。

## 无敌

- “无敌”生效时，适用来源发出的攻击或效果仍可形成“击中”事件，但对该人物不产生伤害或不利效果。
- 本项目口语中常把这种结算简称为“全都不中”；这里的“不中”描述最终没有效果，不代表物理上的命中事件不存在。
- 牌面若把无敌限定为某一来源或某类人物，则先判断来源；例如“对【恶】无敌”表示来源为【恶】的人物所发出的攻击或效果可以击中叶开，但对叶开没有效果。
- 普通的“一定造成”“破”“无视防御”不能自行穿过无敌；只有明确写明可破除无敌、对无敌有效或同等专属说明的效果才能例外。

## 生效时序

- 无敌只能保护其已经生效之后的结算。
- 如果另一效果抢先结算，使提供无敌的特技尚未生效、已经失效或无法发动，则不能用尚未生效的无敌回溯防御。
- 后发的无敌不会撤销此前已经完成的事件。

## 与其他模块的接口

- 同时发生的效果先按`resolution-priority.md`判断结算顺序。
- “找人作战”本身属于作战对象变化而不是命中人物的效果，不能仅凭无敌避免；进入作战后的攻击和效果仍按无敌判断。
- 清除、离场、杀死等是否能穿过无敌，不按其结果名称猜测，仍需检查来源效果是否明确破除无敌。
