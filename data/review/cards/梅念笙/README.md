# 梅念笙评价摘要

状态：作者核心语义、首轮输出模型与完整维度已完成；环境回归开放。

梅念笙是**延后攻击的受击反攻型人物**。神照经限制每个外来特技实例只能对自己完整使用一次，并在任一方向相克后先承伤、存活则立刻回满；铁骨墨萼则让除梅花拳外的主动特技改为“组成牌位均未克敌则放出”，并把自身攻击延后到敌方攻击之后。

普通单挑统计主样本采用木火牌形、均匀五行盲选白人对手、梅念笙能够活到延后攻击结算。两张招式位均未克敌时进入连城剑分支，概率64%；至少一张克敌且没有被克时进入梅花拳分支，概率28%；一张克敌、一张被克时两项主动均关闭，概率8%。把三条路线各自相关的普攻一并枚举后，正面输出期望1308、标准差432.04、范围300至2400；平均形成6.6次自身击中。全部均为普通攻击，穿透输出为0。

混克空档的条件期望只有340，很可能成为对手压低梅念笙输出的策略；但为防其他`木-`梅花拳，对手又可能放金金，梅念笙则可改放火火追求普攻，双方反制可以继续递进。横向统计因此采用完整盲打期望1308，不伪造唯一的博弈均衡。

连城剑法与梅花拳的每一次攻击都可以改指场上任意一人。单挑盲打模型中，把成功主动攻击全部改投一名侧面目标时，该目标期望908、标准差467.26；这908与正面输出共用，不能在保留1308正面主值的同时额外相加。多人共同偷袭时还会出现多套连城剑、梅花拳提前攻击和首次攻击冻结层数的时序耦合，暂不再用原先只算连城剑的二次公式冒充完整总输出。
