# 战斗人物功能：名次保障与败局规避

加载条件：人物主要或重要次要价值不是提高自身战斗力或广泛改变全场，而是降低所属玩家垫底、出局或输掉的概率。

## 与其他维度的边界

- **不是战斗能力**：本人输出、生存或击杀不一定提高。
- **不是全局影响力**：能力可能只围绕自身玩家和当前宿主运作，覆盖面并不广。
- **不是个人生存**：人物活得久不等于玩家名次安全；玩家名次安全也不要求该人物亲自承伤。
- **不是普通强度的结果**：最强正面人物通常也会提高胜率，但如果牌面没有直接操作结盟、顺位、胜负、投靠、从属、免失败或特殊胜利，就不登记名次保障。否则本维度会与战斗评分重复。
- **既包含保底，也包含夺冠转化**：本维度评价人物如何改变所属玩家的最终名次分布。避免最后一名、稳定前二和直接提高第一名概率必须分开登记，但都属于本维度。

## 评价问题

1. 能力保护的是人物、所属玩家，还是整个阵营的最终名次？
2. 它降低的是死亡、淘汰、最后一名，还是提高第一名概率？
3. 多人混战、双人局和残局中的价值是否不同？
4. 是否可以依附、投靠或绑定当前领先玩家？
5. 接收方能否拒绝，能力方能否反复改换对象？
6. 保障是否依赖男性／女性比例、阵营、场上人数或当前名次？
7. 是否拥有可信威胁，能够阻止宿主强迫其出战或牺牲？
8. 最后是否存在背刺、倒戈或独占第一的上限？
9. 背刺会产生多大信用、报复和以后对局合作成本？
10. 保障是规则确定结果，还是依赖谈判和玩家选择？

侧面找不到、不在场或单纯活得久，只能先提高人物生存，不能自动提高名次保障。若保位依赖别人自愿保护，还要检查本人物是否拥有可信威胁或足够谈判筹码；没有稳定交换条件时，不得把“别人可能照顾他”当作强保障。

## 两类主要路径

- **保底型**：降低垫底、出局或失败概率，稳定前二或依附领先者；不要求提高第一名概率。
- **夺冠型**：把特定事件直接转化为胜利，或显著提高第一名概率。必须检查触发顺位、能否响应、使用者是否同时死亡、是否会被失败判定抵消，以及队友或所属玩家中究竟谁获胜。

同一人物可以兼有两类路径。不能因为某能力直接产生第一名，就把它重复计入输出、个人生存或全面全局影响。

## 当前分档

暂用`无／较弱／一般／较强／强／很强`，只记录作者确认的直接名次、结盟或胜负机制，不制造胜率。没有此类机制的人物写“无”，不因输出、生存或收割能力强而给“间接保障”。

当前锚点：

- 白清儿：大混战中可反复投靠当前第一名玩家，男性人物通常多于女性人物，使投靠载体较常存在；不保证第一，但常能避免最后并接近保住前二。死亡不利通常作为阻止宿主强迫她出战的谈判威胁，末局杀宿主是有信用成本的背刺上限。暂评名次保障很强。
- 燕十三：第十五剑成功放出即触发最高胜利顺位的第一名；燕十三本人普通死亡与否不撤销胜利。普通对手首回合直接尝试为28%，对白人承伤的最优长期压力模型约96.40%。这是夺冠型锚点，不折算为伤害或全局影响。
- 乾罗：没有结盟操纵、顺位移动、投靠、免失败或特殊胜利；跨位置追击、收割与场外抗扰属于战斗和生存，名次保障为无。
