# 核心规则：默认游戏流程

状态：作者确认。  
加载：设计、改卡、评价时始终加载。

除非场景或卡牌明确改写，绝大部分对局均按本流程进行。

## 一、摸牌与选卡

1. 根据一方或多方的某个顺序摸取五张牌，随机去除一张；被去除的牌视为没有摸到。此后视为摸了四张。
2. 根据一方或多方的某个顺序摸取四张牌。
3. 执行可以在弃牌阶段使用的卡牌特技。
4. 选出两张可以战斗的蓝色战斗人物卡。
5. 摸到的红色物品、黑色非战斗人物及称号直接进入本局，不需要在弃牌阶段与战斗人物竞争。
6. 两张战斗人物的具体选取方法由当局规则决定，可包括自由选取、按序弃牌、保留一张后其余随机等。
7. 战斗人物不足两张时，从牌堆中补齐；补齐过程中出现的物品、非战斗人物和称号归该玩家所有。

只有战斗人物竞争两张人物名额。附加人物、物品和称号不占这两个名额。

## 二、选择战斗对象

当前常用流程：

1. 由上一局第一个输掉的玩家指定另一名玩家为敌并经历一个战斗阶段；初局可以随机决定起点。
2. 刚才被选中的玩家再选取一名尚未在此前链条中战斗过的玩家。
3. 持续进行，直至最后一名玩家选择第一名玩家。
4. 此后继续按这一循环选取玩家战斗，除非特技改变顺序。
5. 一方战斗人物已经全部死亡、离场或退出本局时，视为没有该玩家，跳过此玩家选择下一名玩家。
6. 一方无法出战但人物没有全部死亡、离场或退出时，视为中间产生隔断；本来需要与其战斗的玩家和他之间不发生战斗。
7. 双方结盟时不发生战斗。
8. 围攻是特殊攻击顺序，由参与围攻的玩家轮流选择被围攻玩家战斗。

死亡、离场、退出本局、无法出战和结盟造成的流程结果不同，不能互相替代。

## 三、单次战斗

一般情况下，对战双方玩家各选择一张战斗人物卡出战。出战人物可以按牌面和规则携带物品、非战斗人物、称号及其他附加内容。

双方各有一套八张五行卡：

- 金
- 木
- 水
- 火
- 土
- 同上
- 同第一
- 同第二

双方暗中摆放四张战斗卡：

- 前两张为内功。
- 后两张为招式。

双方同时完成摆放后，按对应位置依次比较。

## 四、战斗时序

默认时序：

1. 对阵前／出战前／出阵前
2. 对阵时／对阵开始／回合开始／回合中先
3. 放置战斗卡前
4. 放置战斗卡时
5. 放置战斗卡后
6. 内功前
7. 内功阶段
   1. 一张内功卡战斗前
   2. 一张内功卡战斗
   3. 一张内功卡战斗结束
   4. 重复至没有内功可战斗
8. 内功结束
9. 招式前
10. 招式阶段
    1. 一张招式卡战斗前
    2. 一张招式卡战斗
    3. 一张招式卡战斗结束
    4. 重复至没有招式可战斗
11. 招式结束
12. 回合结束
13. 回合后／战斗后

评价一条能力时，必须先确定它挂接在哪个流程节点。时点不明时不得自行移动到更有利的阶段。

## 五、场景的上位作用

场景不是一次战斗或一个临时地点。只要本局存在场景，整局游戏都发生在该场景中。

因此存在场景时，应先读取场景对整局流程的改写，再理解该局中的人物和其他卡牌。
