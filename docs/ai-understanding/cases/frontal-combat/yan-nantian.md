# 校准案例：燕南天

状态：作者核心语义与白人模型已校准；环境回归开放。

完整证据：`data/review/cards/燕南天/`

## 可迁移结论

1. “受伤×2”经作者校准为本回合累计受伤整体翻倍时，不能套用“本次伤害×2”的普通反伤模型。
2. 后发先至可以使后来确定的触发次数追溯本回合全部伤害，应使用整回合联合变量：
   `Y_i=B_i×2^N_i`。
3. 基础伤害`B_i`与翻倍次数`N_i`由同一组五行结果决定，存在相关性，不能用`E[B]×E[2^N]`。
4. 多人战中每名敌人独立维护账本，总输出为`ΣY_i`；共享牌面结果但倍率不同。
5. 敌人死亡会截断后续卡位，因此必须同时保留“高生命完整模型”和“指定生命死亡截断模型”。
6. 回血不降低累计记录；敌人死亡时该敌本回合链条终止。

## 不可迁移边界

- 只有牌面或作者明确形成整回合回看时才使用本模型。
- 普通反伤、即时伤害翻倍和单局累积不能自动照搬。
- 特殊提前亮卡是额外触发；正常四卡公开不是。
- “尽量”即时贪心属于独立术语规则，不由本伤害模型推出。
