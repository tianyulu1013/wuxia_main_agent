# 类别评价：战斗人物

加载条件：卡牌类别为战斗人物。

## 核心地位

战斗人物是唯一需要竞争两张战斗人物名额的卡牌类型。评价必须回答：

> 这张人物是否值得占据一个人物名额，并在本局通过什么主要方式帮助玩家获胜？

## 评价流程

1. 读取默认游戏流程和基础战斗。
2. 确认本卡进入两张人物阵容后的使用方式。
3. 将每条能力挂到具体流程节点。
4. 判断主要功能、次要功能和保底功能。
5. 只加载相关功能模块。
6. 推演常态、失败下限和现实可达上限。
7. 与同主要功能的校准案例比较。
8. 判断与第二张战斗人物的互补、冲突和人物名额价值。

## 强制评价栏目

- 主要、次要和保底功能
- 流程节点与逐技事实
- 常态、失败和上限结算链
- 输出与爆发
- 正面生存
- 侧面生存
- 辅助、控制或全局价值（实际涉及者）
- 人物名额价值与搭配
- 优点
- 缺点
- 实际玩法
- 规则风险
- 电子化风险
- 同功能比较锚点
- 置信度与待作者校准问题

不得仅凭正面输出判断辅助型、调度型或全局影响型人物的整卡强弱。
