# 战斗人物横向基线索引

状态：随逐卡作者校准持续增长。

结构化数据：`data/review/combat_baselines.json`
定向查询：`python scripts/query_combat_baselines.py title <卡名>`或`python scripts/query_combat_baselines.py function <功能标签>`

## 使用目的

评下一张战斗人物时，不再把全库人物和全部旧评语重新读一遍。先确定新人物的主要功能，再查询：

1. 白人统一参考；
2. 同主要功能的两至四张已校准人物；
3. 机制最接近的一张案例；
4. 新人物明显超出既有区间时，再扩大样本。

## 统一口径

- 正面输出：人物正常出战时对当前对阵者的防御前名义输出。
- 侧面目标输出：人物正常出战时对当前对阵者以外目标的输出。
- 场下输出：人物自己不是当前出战者时产生的输出。
- 正面生存与侧面生存分开登记。
- 全局影响力单独登记，不得用侧面输出、个人正面战力或整卡强度替代。
- 每个可计算输出模型同时记录期望、方差、标准差、变异系数和范围。
- 穿透同时记录“期望确定穿透输出点数”和“穿透占总输出比例”。只写100%不能回答高防御目标仍会受到多少真实伤害。
- 无法计算时保留空值和原因，不用白人400或旧评分填补。
- 多个策略分支分别登记，不能把可选路线相加。
- 网页统计速览优先使用明确标记`topline: true`的模型，没有标记时才回退到每个输出维度的第一条。主基线选择常见实战状态，并排除示例性目标生命和死亡截断。其他策略、短暂初始状态和截断模型保留作详细分析，不并列塞入顶部统计。
