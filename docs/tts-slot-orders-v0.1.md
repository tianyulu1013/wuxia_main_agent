# TTS Slot 顺序权威草案 v0.1

## 1. 说明

本文记录作者提供的 TTS 牌堆卡名顺序。

用途：

- 作为已有 TTS 按钮脚本 `cardNames` 的权威来源。
- 生成未来 `cardNames` 数据块。
- 对比 PSD 文件夹，发现缺失、重复、命名不一致。
- 避免用文件名排序误判 TTS 实际顺序。

注意：

- 这些顺序优先级高于文件夹排序。
- 当前 `黄易温瑞安` 是合并牌堆，用于减少 TTS 牌堆数量。
- `黄易2` 当前不单独需要 release deck，除非未来决定拆分。
- 新增卡进入已有牌堆时，需要更新对应 slot 顺序。
