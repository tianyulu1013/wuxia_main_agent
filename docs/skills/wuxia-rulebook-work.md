# Skill: 规则书整理与重构

## 适用场景

重写、整理、补充、审计规则书和剧本书，消除机制歧义，直接从底层重构有冲突的规则与卡牌。

## 必读与产出文件

- `五行卡牌规则.docx` （最终生成的二进制 Word 规则书）
- `docs/rulebook-refactored.md` （新版 Markdown 规则书源文件，重构的核心）
- `docs/rulebook-docx-extract.md` （旧规则书的纯文本正文提取物）
- `docs/rulebook-confirmed-rulings.md` （已确认的核心概念及口头裁定记录）

## 工作目标

- **直接重构冲突**：不要削足适履去“变通绕过”混淆，应通过直接优化规则和卡牌来把流程理干净。
- **结构重组**：打破以往平铺式结构，按“物理实体 $\rightarrow$ 时空流程 $\rightarrow$ 特技结算 $\rightarrow$ 状态异常 $\rightarrow$ 裁定FAQ”的渐进层级建立目录骨架。
- **细节无遗漏**：将旧规则书中的所有段落、实例（例：蝙蝠岛、了空闭口禅等）全部合并进新版对应章节，做到内容零遗漏。

## 必须理清的重难点概念

- **回合、轮、转轮**：回合是个体出战行动；轮是己方阵营的行动参与度（己方有人出战则全员过轮，否则过轮时间冻结）；转轮是全局所有方完成一圈出战。
- **找不到与波及的判定**：找不到（定位失效）状态下，在场找不到仍吃全体波及伤害，不在场找不到不吃波及伤害。
- **生命流失强穿透性**：属于“效果数值扣除”而非“伤害”，强穿透所有伤害减免与闪避。
- **卡牌与人物单元**：物理卡是容器，单元是实体。全真七子物理卡在，杀死单人单元卡牌不消失。
- **弃牌区与除外区**：除外区（本局弃卡）物理断绝，不可召回。
