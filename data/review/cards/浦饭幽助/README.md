# 浦饭幽助评价摘要

状态：作者核心语义、首轮输出模型与完整维度已完成；环境回归开放。

浦饭幽助是**灵丸资源驱动的正面爆发兼主动打断型**战斗人物。击中数倍率只扩大“击中计数”，不复制原攻击伤害；其主要输出增长来自【灵光波动拳】按击中计数附加的每次100一定造成。

横向主样本取灵丸充足、发动灵光波动拳、对阵敌没有成功使用大招：百裂拳与灵光波动拳使每次实际击中按六个击中计数结算，但原普攻只造成一次。四卡基础输出期望仍为400；基础击中数期望为2，故附加一定造成期望为`2×6×100=1200`，总输出期望1600、标准差614.49。若敌成功使用大招，百裂拳关闭，主值降为1000、标准差377.36，其中600为一定造成。

一回合最多消耗两发灵丸，灵光波动拳占一发且每回合只能使用一次，因此爆发回合最多还剩一发打断。被打断的大招视为没有使用，典型只有一项大招的敌人会同时失去大招并触发百裂拳；拥有多项可连续发动特技的敌人仍可能用第二项关闭百裂拳。423张人物共有753条牌面大招，平均1.7801条；在统一标准两卡放出模型下，约63.44%的对手回合没有成功大招，约36.56%需要幽助再花一发打断。由此估计6发可支撑约4.59个灵光爆发回合，而不是固定三个。该值只是大招结构环境近似。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 灵丸充足且敌无成功大招时期望1600、标准差614.49；其中1200为一定造成 |
| 失败分支 | 敌成功使用大招时，灵光路线期望1000、标准差377.36，其中600为一定造成 |
| 侧面输出 | 0；灵丸只能用于与浦饭幽助对阵的敌人 |
| 正面生存 | 强；3000生命、无常规减伤，但第一次死亡后以3000满生命基础重生并清除有利与不利 |
| 侧面生存 | 较强；没有打断、减伤或防波及，基本以两条独立3000生命硬吃，近似6000裸生命但不是连续血条 |
| 全局影响 | 基本没有；打断只能作用于当前与浦饭幽助对阵的敌人，不能介入其他人的战斗 |
| 名次保障 | 无；没有结盟、投靠、胜负改写或直接胜利能力 |
