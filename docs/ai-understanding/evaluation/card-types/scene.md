# 类别评价：场景

加载条件：卡牌类别为场景。

## 已确认基准

- 场景不是临时地点效果。
- 只要本局存在场景，整局游戏都发生在该场景中。
- 场景位于默认游戏流程之上，先改写整局环境，再理解本局其他卡牌。
- 场景不做普通卡牌强度评分。

## 评价内容

- 改写了默认游戏流程的哪些环节。
- 本局核心玩法和策略选择发生了什么变化。
- 哪些类型的能力更容易或更难发挥。
- 是否形成规则冲突、循环、停滞或无法继续结算。
- 玩家是否容易理解并持续记录场景状态。
- 对整局节奏、互动和体验的影响。
- 规则风险。
- 电子化风险。

场景评价不输出普通强度分、正面生存分或人物名额价值。
