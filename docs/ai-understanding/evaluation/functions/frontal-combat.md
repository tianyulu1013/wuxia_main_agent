# 战斗人物功能：正面作战

加载条件：战斗人物主要或重要次要功能为亲自出战、平克比较和攻击敌人。

## 计算起点

1. 从白人期望输出400开始。
2. 计算本卡如何改变内功、招式、普攻和主动大招。
3. 所有主动大招先验证放法、位置、放出率和冲突。
4. 单项增伤、减伤和反伤逐项结算。

## 输出

分别计算：

- 基础四卡期望。
- 稳定普攻替换或增益。
- 主动大招的期望贡献。
- 特定常见牌形。
- 失败下限。
- 现实可达爆发上限。
- 最早结算时点、目标和穿透类型。

优先使用概率公式。例如两张放法均不能被克时，基础概率为 `(4/5)²`；不要为简单独立事件枚举全部牌形。

## 正面生存

正面生存至少考虑：

- 生命。
- 基础四卡预计承伤。
- 减伤、反伤、回复、护盾和转移。
- 生命至0后的处理。
- 被克、死亡或其他后续条件。
- 能否利用信息或改牌降低下一次被克概率。
- 预计存活回合或可出场次数。

有延迟死亡、概率回复或可控制下一次被克概率时，应估算存活期望，不能只换算成未经推演的固定额外生命。

## 比较

只与正面作战功能接近的已校准人物比较。至少对照：

- 常态输出
- 爆发
- 正面生存
- 结算时点
- 失败条件
- 人物名额价值
