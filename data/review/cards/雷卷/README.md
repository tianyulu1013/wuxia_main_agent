# 雷卷评价摘要

状态：作者定性校准完成；首轮输出、埋雷与白人压力模型完成；真实多人环境回归开放。

雷卷是**反应输出、概率避战与全局埋雷型**战斗人物。实际交手时，完整八卡白人模型正面输出期望1469.6；但小寒神有二分之一概率直接避战，因此按一次被选出场计的正面主值为734.8。失神指无视防御，按实战穿透口径分别贡献1069.6和534.8，约占72.78%；严格一定造成仍为0。它还令来源敌后三回合所有攻击落空；伤害与不利分别触发，`100狂`会给雷卷两次反击机会。

江南霹雳堂使用八张物理基础卡建立扣放的全局雷区。小寒神会凭空恢复一整套卡而不撤旧雷，因此雷区可以跨恢复循环叠层；但雷卷不能指定谁引爆，雷伤会散落到多人身上。按约5名实际出战者摊薄，首个完整八雷波次每名触发者约360，三波完整存续也约3000，而且雷卷很难存活并保雷到三个波次。前人踩掉某卡名后，后来者还能重复使用该安全同名卡规避。所有雷仍是可正常防御的独立附加伤害。
