# 月神评价摘要

状态：作者机制语义已校准；第一轮定量模型完成，真实反制环境回归开放。

月神是**点名隔离、必然换命与全敌普通杀死型**人物。她出战时可以叫出一个具体人物的名字；若点名成立，就强制该人物与月神交手，而且本次战斗只有二人在场，等同于转移到另一处作战。未亮出、当前不在场的人物也可以被点名；点名错误则挑战失败，恢复正常出战。

“月光如刀，刀如月光”没有次数限制。只要已经形成交手，交手后月神可以令本次交手的**全部敌人死亡**。该效果不要求击中、伤害或克敌；即使月神只打了一张基础卡便在中途死亡，交手后敌仍然死亡。这与薛笑人必须以本体活到交手后的杀手剑完全不同。

月神的常规四卡数值输出仍为期望400、标准差149.67、范围0至800、穿透0。普通杀死不属于伤害，不能登记为输出或穿透。单目标合法交手的条件淘汰率为100%；点名正确时，目标取得率也接近规则层确定，但普通死亡仍允许重生。牌面末尾的`（暗）`既要求月神满足暗器兵器条件，也使该死亡属于暗器特技造成的结果；月神持有`【暗】`，所以正常能够使用，但暗器免疫可以使这次死亡无效。

1600生命和没有防御使月神的正面、侧面生存都偏弱。按当前约1400输出环境，`ceil(1600/1400)=2`只是无防御名义承伤窗口；它不能被误读成两次稳定出战。月神的关键价值在于第一次实际交手已经可以完成淘汰，即使自己当场死亡也不减少本次淘汰成功率。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 数值期望400、标准差149.67；非伤害杀死另行统计 |
| 实战穿透输出 | 0；普通杀死不是穿透伤害 |
| 侧面输出 | 0；点名挑战是正面目标捕捉，不是场下伤害 |
| 非伤害淘汰 | 单目标合法交手后100%；多人交手则全部敌人死亡；月神中途死亡不取消 |
| 正面生存 | 弱；1600生命、无防御，但死亡仍能完成本次换命 |
| 侧面生存 | 弱；没有场下减伤、免疫、替身或离场保护 |
| 全局影响 | 强；可抓取未亮出／不在场的指定人物并隔离第三方，形成可靠的定点淘汰与谈判威胁 |
| 名次保障 | 无；没有直接结盟、投靠、免失败、顺位或特殊胜利 |
