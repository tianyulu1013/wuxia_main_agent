# 谢烟客：名次保障

## 1. 直接保位线

玄铁令存世且谢烟客一方主动发起普通挑战时，可以不派谢烟客；若无其他可出战者，挑战直接跳过。这能降低为了完成本方进攻义务而暴露谢烟客的频率。

谢烟客非当前战斗人物时又真正不在场，因此在大混战中有较强的常规侧面保命。

## 2. 反向风险

- 他方挑战谢烟客一方时，摩天居士不起作用。
- 持令者可以要求谢烟客出战、自伤或自杀。
- 没有石破天时，令的控制者通常是其他玩家。
- 令被使用后消耗，摩天居士的特殊避战条件也随令消失。

## 3. 谈判与保护的现实限制

玄铁令持有人未必愿意保护谢烟客。即使持令人让谢烟客帮助攻击第三方，谢烟客获得的也主要是可能的友好度或间接利益，不构成可靠的保位契约。谢烟客自身又缺乏强力谈判手段，不能稳定换取持令人的保护。

## 4. 结论

名次保障暂评**一般**。不在场主要提高侧面生存，不能直接换算成名次保障；玄铁令存世时回避本方主动挑战确有帮助，但无法回避他方挑战，持令人也可能反向控制谢烟客。石破天在场时属于较有利特例，仍不足以把常态评级提高到较强。
