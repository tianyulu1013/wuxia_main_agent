# Skill: 规则书整理

## 适用场景

重写、整理、补充、审计规则书和剧本书。

## 必读文件

- `五行卡牌规则.docx`
- `docs/rulebook-docx-extract.md`
- `docs/rulebook-structure-audit.md`
- `docs/rulebook-confirmed-rulings.md`
- `PROJECT_STATE.md`

## 工作目标

- 不是照抄旧规则书。
- 要把已经讨论确认过但旧规则书没写清的内容补进去。
- 要重组结构，让新读者能理解概念层级。
- 不删复杂机制，但要标明哪些机制需要人工裁定。

## 必须讲清的概念

- 抽牌、随机弃牌、本局弃卡、弃牌堆。
- 战斗人物、附加人物、物品、场景、称号。
- 场景与地点的区别。
- 人物在场、不在场、离场、破空、清除。
- 攻击、伤害、扣血、生命流失、杀死、死亡。
- 回合与轮。
- 内功、招式、武功、大招、技能、字、专属、身份特技。
- 多人一卡、共享生命、各自生命、特技所属。

## 输出原则

- 保留复杂性，但提高可读性。
- 不自行补设规则。
- 不确定的地方列为待作者确认。
