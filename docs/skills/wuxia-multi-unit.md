# Skill: 多人一卡与特技所属

## 核心原则

多人一卡需要拆出真实 unit。特技通过 owner units 表示所属。

## 不使用虚拟全体

不要创建名为 `全体` 的 unit。

如果一个特技属于所有 unit，记录所有真实 unit 名称。前端可以显示为共同特技，但数据层不能把共同特技当作一个人物。

## 常见结构

- 各自生命：四大恶人、全真七子、江南七怪等。
- 共享生命：袁冠南萧中慧、阿三阿四等。
- 单卡多单位但有共同规则：需要把说明、关系、特技所属分清。
- 特殊计数：`五个人头` 基本按一个 unit，但计人数为 5。

## 不确定时

列出：

- 卡名。
- 疑似 unit。
- 每条特技当前 owner。
- 生命、身份、兵器是否共享。

然后问用户确认。

## 重要提醒

- 兵器也可能有所属。
- 身份也可能有所属。
- 人物关系不是都等于结盟。
- 不要脑补关系，例如不要自行解释亲属、剧情、杀妻等内容。
