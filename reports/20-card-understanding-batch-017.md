# 中原一点红单卡评审工作卡

状态：`locked`  
评价性质：AI评估·未校准  
置信度：中

## 一、人物评估结论

### 1. 核心定位

中原一点红是以隐藏结算、指定暗杀目标、对目标实际伤害加倍和濒死强制决斗组成闭环的高压刺客。常态并不靠单个大数字，而靠对方无法及时知道来源、被克时失去响应以及暗杀目标死亡后的永久成长；问题是2000生命很薄，所有终结仍缺少抢先结算。

### 2. 强度、泛用性与置信度

- 强度：**86/100**；泛用性：**76/100**。
- 保守解释82；常态86；现实上限91；置信度中。
- 高分来自目标伤害翻倍、无视防御、条件禁响应和濒死留命一回合的互相支撑；泛用性被固定目标、剑依赖、2000生命和隐藏信息的桌面负担压低。

### 3. 常态、下限与上限

- 常态：暗中指定容易接触的目标，隐藏发动特技；以普通攻击或快剑对其造成的实际伤害翻倍，被克时利用“不能响应”提高兑现率。
- 下限：目标长期不在场或先被别人杀死；一点红未形成出场成长即被抢先结算杀死；隐藏卡尚未翻开，效果便因对象消失而失去价值。
- 上限：亲手杀死目标后快剑系数永久+400并回满，再指定新目标；濒死回合以不会死亡换取最后一次双倍暗杀，完成连续收割。

### 4. 输出与爆发

快剑按出场次数产生每次100的迟发成长，单独不算高；真正乘区是“对目标实际伤害加倍”。“实际伤害”应在防御和减免后翻倍，不能把未穿透的牌面值先翻倍。杀人不流血无视防御能力，且克的张数多于被克时敌不能响应，能打开最可靠的命中窗口，但未写一定造成、杀死或抢先结算。输出常态高、终结速度仍低于东方不败等绝对时序人物。

### 5. 正面生存

2000生命原本偏脆。濒死时与目标战斗一回合且回合结束前不会死亡，是条件极强的留命；它只在已有可交手目标时成立，也不阻止清除、离场或抢先结算在触发前处理。杀死目标回满提供续航，但必须先完成击杀。正面生存暂评72，不能按濒死回合无敌写成常驻高防。

### 6. 侧面生存

没有找不到、波及免疫或场下减伤。受到不利时可翻开隐藏卡，把效果改成与目标作战一回合，可能把侧面效果转化为可操作战斗，但需要有合法目标，且不是直接使效果无效。侧面生存约60。

### 7. 优点

1. 暗中指定与隐藏发动让对手难以为关键窗口预留准确响应。
2. 实际伤害加倍对所有合法伤害来源生效，能放大快剑之外的常规攻击。
3. 无视防御能力并附带条件禁响应，穿透质量高于普通高伤。
4. 亲手杀目标同时永久成长与回满，成功一次后滚动能力明显上升。
5. 濒死留命一回合为2000生命提供现实反杀窗口。

### 8. 缺点

1. 没有抢先结算，可能在隐藏牌翻开或濒死决斗前死亡。
2. 暗杀目标死前不能换人，目标隐藏、离场或难以接触会锁住主循环。
3. 目标被他人杀死只加200且不回满，收益显著缩水。
4. 快剑前期数值低，需要多次出场或击杀成长。
5. “不能响应”依赖克数优势，不是每回合稳定成立。

### 9. 实际玩法

目标应优先选可稳定交手、没有抢先结算且击杀后能打开后续局面的敌人。隐藏卡要留作对方已经投入不利效果后的改战窗口，不应过早暴露。濒死决斗是最后保险，进场前仍需保证当回合能制造足够伤害完成回满。

### 10. 一句话总评

一点红的暗杀链有高穿透与成功滚雪球，但2000生命、目标锁定和非抢先时序阻止他进入绝对统治档，86/76。

### 14. 物理结算链

- 常态链：暗中指定甲→一点红出战摆卡→克数占优→无视防御且甲不能响应→结算实际伤害→对甲翻倍→若亲杀则快剑+400并回满。
- 失败链：甲抢先结算杀死一点红，或长期不在场；隐藏效果未到翻开时点便失去合法对象。
- 上限链：一点红濒死触发与甲作战→本回合不会死亡→双倍伤害杀甲→从濒死回满→换下一目标，快剑系数继续累积。

### 15. 反证审计

最易高估的是把无视防御和不能响应等同无法阻止；前者不天然穿透抢先结算、清除与合法免死。最易低估的是“实际伤害加倍”可放大多种输出而非只放大快剑。心理仇恨不算牌面削弱，但隐藏信息会增加桌面核验成本。审计后维持86，不进90+。

### 16. 必要待校准问题

1. 隐藏特技“暂不计算”能否在原合法时机之后任意翻开？若能，存在追溯；若不能，只是保密，改变核心时序。
2. “不利效果变为与目标作战一回合”是否完全替换原效果？若仍保留原效果，侧面生存下降约6分。
3. 濒死留命是否挡清除与离场？宽解释接近一回合全面不死，窄解释只挡生命归零。

### 17. 规则风险

高。隐藏延迟、翻开时点、实际伤害加倍顺序、目标锁定以及濒死与死亡事件先后都需明确。

### 18. 电子化风险

### 19. 比较锚点

- 常态输出：防御后实际伤害×2；快剑递增。
- 时序/穿透：常规招式；无视防御；条件不能响应；无抢先。
- 双生存：2000生命；濒死目标战留命；侧面无硬免疫。
- 参照：东方不败的终结更早且稳定，故一点红低约10分；傅红雪同为目标锁定与濒死反杀，一点红输出更稳定、非目标保护更弱。
- 分数：86/76，中置信。

### 20. 可迁移结论

2. 来源中原一点红：固定目标倍率应同时计入对象锁定成本；适用于暗杀类卡，高置信，`ai_derived_calibration`。

# 原随云单卡评审工作卡

状态：`locked`  
评价性质：AI评估·未校准  
置信度：低

## 一、人物评估结论

### 1. 核心定位

原随云是把随机放卡猜测、信息买卖、全局场景控制和切入攻击揉在一起的政治型控制人物。上限很高，但几乎每一部分都依赖多人桌面、诚信记录、秘密信息或复杂场景；2000生命且无直接防御，使他在被找到后很容易被终结。

### 2. 强度、泛用性与置信度

- 强度：**82/100**；泛用性：**61/100**。
- 保守解释73；常态82；现实上限91；低置信。
- 蝙蝠岛的全局削技和切入能制造强压制，三十三绝学有直接杀死上限；但随机、交易是否成交、人数、信息价值和楚留香克制令泛用性大幅低于强度。

### 3. 常态、下限与上限

- 常态：一次性把关键人物拖入蝙蝠岛，利用其第一次回合多数能力失灵和不辨敌我制造切入窗口；三十三绝学造成若干200点迟发/方形伤害。
- 下限：二人局或无人交易，随机牌既未形成杀死组合，蝙蝠岛又被楚留香识破；原随云2000生命暴露后迅速死亡，全部人物离岛。
- 上限：掌握岛上身份与资源，交易使多名敌人的战斗结果单向无效；随机三张或四张一致直接杀人，同时己方在不显形状态切入双方。

### 4. 输出与爆发

三十三绝学的稳定部分是敌每不信一张-200、相同再-200迟，以及每张口述不同造成200□；真正爆发是三张相同杀一人、四张全同杀指定某些人。随机放卡令这个上限不能按常态计算，且“某些人”对象不明。蝙蝠岛切入可攻击一方或两方，但没有额外固定伤害或抢先结算。

### 5. 正面生存

2000生命偏脆，没有减伤、免死或回血。交易参与者对原随云战斗结果单方面无效，是非常强的对象性保护，但必须先完成买卖且其他人不知道；未交易敌和楚留香可正常杀他。正面生存约58，交易对象面前可大幅提高。

### 6. 侧面生存

在蝙蝠岛上，原随云方未影响他人时可以不出现在场上，接近条件隐藏；但一旦影响他人或被楚留香找到，2000生命裸露。死亡还会解除整个场景。侧面生存约68，高度条件化。

### 7. 优点

1. 一次性拉入对不在场人物也有效，能绕过通常位置保护。
2. 首回合关闭非大招、技能、物品类特技，对依赖身份字和被动字的人物压制很大。
3. 己方可保持不显形并切入一方或双方，改变既有对阵。
4. 交易同时获取资源/信息并使买家对原随云战果无效，政治收益可叠加。
5. 三十三绝学兼有不信惩罚、差异伤害和低概率直接杀死。

### 8. 缺点

1. 2000生命且死亡即解岛，是明显的全局单点故障。
2. 很多收益依赖敌方愿意交易或相信口述，不能按必然资源计算。
3. 随机放卡使直接杀死上限低频且难规划。
4. 二人局交易和信息政治价值显著下降。
5. 楚留香能辨敌我、找人并找到原随云，形成专属硬克制。
6. 文本包含大量隐藏信息与人工承诺，实战负担极高。

### 9. 实际玩法

应把蝙蝠岛留给对方核心被动依赖者，同时让己方能以技能、大招或物品继续行动。交易应优先换取能再次出售或立即保护原随云的资源，不要为小信息暴露立场。三十三绝学按概率收益使用，不应为追四同而牺牲稳定摆卡。

### 10. 一句话总评

原随云能在合适多人局里重写场面与信息秩序，但低生命、随机和交易依赖让他呈现82强度、61泛用性的巨大分叉。

王怜花在选人阶段伪装成一个单人战斗人物，取得其大招以外全部特技和人物关系；血量暗中按自身2000、1000重生计算。被悖论识破后，只有对阵敌同意才可继续用所易容卡的部分非伤害主动能力。它是选择上限很高、桌面诚信与目标依赖也极高的复制者。

### 2. 强度、泛用性与置信度

- 强度：**76/100**；泛用性：**49/100**。
- 保守62；常态76；现实上限90；低置信。
- 选到高质量被动时可很强，两条命和每三回合回满提供持续力；但强度完全随可选人物、悖论暴露和对手同意波动。不能按复制卡池中最强人物常态计分，泛用性应大胆拉低。

### 3. 常态、下限与上限

- 常态：选一名非多人卡、被动字和技能强而不依赖其原生命/大招的人物易容；隐藏自身生命，利用复制关系和非大招特技周旋，三回合回满并生成100重生。
- 下限：复制能力需要原人物名、专属资源或大招才能工作，易容很快出现悖论被识破；敌不同意继续使用，王怜花只剩2000与1000重生。
- 上限：复制到完整常驻免疫、时序或资源能力，持续未被识破；每三回合回满并不断产生100重生，第一次重生后再从牌堆抽人物换一套适配能力。

### 4. 输出与爆发

本体没有固定伤害。大招以外全部特技可能包含强攻击字，但具体输出取决于易容对象；被识破后的允许范围明确排除伤害主动大招，却仍可能保留非伤害控制。不能给一个虚构的统一爆发值。常态应选择不依赖大招的稳定人物，而非追求理论最高攻击。

### 5. 正面生存

自身生命结构为2000加1000重生，基础偏低；怜花宝鉴每三回合回满并产生一个100重生，若能活到节点则续航可不断增长。复制到的被动防御可能抬高生存，但不稳定。抢先结算、直接杀死或清除可在三回合前终结。正面生存常态68。

### 6. 侧面生存

易容使敌方不知真实血量与能力边界，属于信息保护而非找不到；波及和生命流失仍能命中。复制目标若有场下保护则可能取得，但需确认原人物名与身份适配。侧面生存58。

### 7. 优点

1. 选人阶段可主动选择易容对象，不是纯随机复制。
2. 取得大招外全部特技与人物关系，能力组合范围极广。
3. 无视【】意味着专属标记本身不阻止复制。
4. 真实生命暗中计算，敌难以准确估算终结线。
5. 每三回合回满并增加100重生，拖长局面会持续获利。
6. 重生后可从牌堆抽新人物继续易容，能二次适应局势。

### 8. 缺点

1. 不能复制多人一卡，目标池受限。
2. 不复制大招，很多人物的核心循环会被直接拆掉。
3. 易容出现悖论即被识破，复制关系和身份越复杂越容易暴露。
4. 被识破后继续使用能力需要对阵敌同意，控制权交给对手。
5. 2000/1000肉身薄，三回合回满可能来不及触发。
6. 动态复制的规则与桌面记忆成本极高，泛用性远低于理论上限。

### 9. 实际玩法

优先复制常驻被动、技能和字本身完整，不要求原人物生命、兵器或大招联动的对象；避免复制一眼就会产生身份悖论的人物。第一阶段的目标不是炫技，而是活过三回合取得回满和额外重生。被识破后应转用非伤害政治能力争取对手同意，而非假设还能继续输出。

### 10. 一句话总评

王怜花有选目标复制与持续重生的惊人上限，但目标适配、悖论和敌方同意让它成为76强度、49泛用性的极端卡。

### 14. 物理结算链

- 常态链：选人阶段易容甲→取得甲的非大招特技与关系→真实2000生命暗算→存活三回合→生命回满并生成100重生。
- 失败链：使用复制特技时出现原人物名/资源悖论→被识破→敌拒绝继续使用→王怜花以薄生命遭正常终结。
- 上限链：复制高质量常驻防御→未被识破并多次活过三回合→累积多个100重生→死亡重生后从牌堆抽乙，换成针对当前敌人的另一套非大招能力。

### 15. 反证审计

最易高估是从全卡池挑最强特技拼成王怜花，实际上只能选一张目标卡且失去大招；最易低估是无视【】和主动选目标仍给出很大构筑空间。抢先结算可在第一个三回合节点前结束他。审计后76/49，明确不向批次均值收缩。
