# 燕十三：正面输出与夺冠概率

## 一、模型口径

统一白人环境：

- 双方五行比较独立均匀；
- 敌人无防御、无生命上限截断；
- 两个内功位和两个招式位均正常存在；
- 数值输出与第十五剑的第一名结果分开统计。

基础四卡输出`B`：

- 期望：400
- 方差：22400
- 标准差：149.6663

## 二、夺命十三剑：伤害优先主值

夺命十三剑在通用成功牌形或两平时放出，等价于两个招式位均未被克：

`P(R_{13})=(4/5)^2=16/25=0.64`

令本回合数值输出：

`X_{13}=B+500I(R_{13})`

因为放出条件与两个招式位的基础输出相关，不能把独立方差直接相加。完整分布为：

| 输出 | 概率 |
|---:|---:|
| 0 | 0.0256 |
| 100 | 0.0128 |
| 200 | 0.1552 |
| 300 | 0.1280 |
| 400 | 0.0352 |
| 500 | 0.0032 |
| 900 | 0.2304 |
| 1000 | 0.2688 |
| 1100 | 0.1168 |
| 1200 | 0.0224 |
| 1300 | 0.0016 |

因此：

- 期望：`E[X13]=400+500×0.64=720`
- 方差：137600
- 标准差：370.9447
- 变异系数：0.5152
- 范围：0至1300

这是横向正面数值输出主值。

## 三、第十四剑分支

第十四剑初始在通用成功或混克时放出，等价于两个招式位至少一张克敌：

`P(R_{14})=1-(4/5)^2=9/25=0.36`

当前对阵敌也是“所有在场敌”之一，因此正面数值输出：

`X_{14}=B+100I(R_{14})`

结果：

- 期望：436
- 方差：32384
- 标准差：179.9556
- 变异系数：0.4127
- 范围：0至900

这条路线的主要收益是全体附狂与永久解锁混克，不是正面伤害。

## 四、直接第十五剑分支

第十五剑初始成功率：

`P(R_{15})=7/25=28%`

燕十三使用时不对敌造成第十五剑的死亡，数值输出仅保留基础四卡：

- 期望：400
- 方差：22400
- 标准差：149.6663

成功分支的基础输出条件期望为554.2857，失败分支为340；但成功分支立即触发第一名，不能把这个胜利折算成额外伤害。

## 五、有限出战次数的最优夺冠策略

忽略死亡和其他人物干扰，只给定还可出战`T`次。状态记录：

- 尚未解锁；
- 已解锁两平；
- 已解锁混克；
- 两项均已解锁。

每回合在三种剑法中选择，使`T`次内触发第十五剑的概率最大。初始状态结果：

| 剩余出战次数T | 最优首选 | T次内夺冠概率 |
|---:|---|---:|
| 1 | 第十五剑 | 28.0000% |
| 2 | 夺命十三剑 | 51.0400% |
| 3 | 夺命十三剑 | 74.0800% |
| 4 | 夺命十三剑 | 87.6828% |
| 5 | 夺命十三剑 | 94.4909% |
| 6 | 夺命十三剑 | 97.6297% |

两回合值的推导：

- 第一回合十三剑成功：概率0.64；第二回合第十五剑已可两平放出，成功率0.64；
- 第一回合十三剑失败：概率0.36；第二回合直接尝试第十五剑，成功率0.28。

所以：

`0.64×0.64+0.36×0.28=0.5104`

这说明只剩一次机会时应直接冲第十五剑；预计至少还有一次出战时，先扩张牌形更优。

## 六、谢晓峰特例

与谢晓峰作战时，任意剑法成功都会连带第十五剑。首回合选择初始放出率最高的夺命十三剑：

`P(首回合夺冠|谢晓峰)=16/25=64%`

## 七、穿透

- 夺命十三剑500和第十四剑100均可正常防御；
- 燕十三自己的第十五剑不对敌造成伤害或死亡；
- 第一名属于胜利判定，不是攻击、伤害或穿透。

因此横向确定穿透输出为0，穿透率0。
