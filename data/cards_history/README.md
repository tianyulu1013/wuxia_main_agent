# 卡牌历史版本层

本目录从公开更新 `3.07` 开始记录单卡历史版本，不向更早版本追溯。

## 原则

- 只有实际发生牌面变化的卡才新增历史版本；单卡版本不要求连续。
- `data/cards_current/` 与 `data/cards.sqlite` 始终只保存当前权威版本。
- 历史版本保存完整卡牌数据，不依赖更新日志补丁还原。
- 不保存旧版 PSD。
- 旧版网页卡面保存为单卡 WebP，路径记录在历史版本数据中。
- 历史版本不得进入默认当前卡搜索或当前牌库统计。

## 文件

- `card_versions.jsonl`：被 `3.07` 替代的10张卡的完整改前数据及旧版 WebP 引用。
- `releases.json`：公开更新、单卡新旧版本、新增卡、受影响牌堆及交付状态；3.07当前含10张修改卡和5张新增卡。
- `../release_images/cards_history/<card_id>/pre-3.07.webp`：3.07更新前的单卡 WebP。

## 3.07 当前状态

- 改前完整数据和旧版 WebP 已冻结。
- SQLite、JSONL、当前基准 Excel 与3.07完整数据库 Excel 已按作者最终文本统一同步；发布更新日志已生成。
- 新增战斗人物“天龙六僧”“段正明”“段正淳”属于金庸3；新增场景“幽灵山庄”“地仙村”。五张新增卡均没有旧版本记录。
- 15张3.07新版 WebP 已从对应70卡牌堆图选择性切图生成并登记；其中10张修改卡沿用已冻结的改前历史图，5张新增卡不生成旧版本。
