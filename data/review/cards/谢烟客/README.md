# 谢烟客评价摘要

状态：作者核心语义与首轮参数模型已完成；连续作战长度、玄铁令请求生态等待环境回归。

谢烟客是**连续蓄势、单体控招与契约政治型**战斗人物。碧针清掌的 `木- -木` 是 `木-` 或 `-木` 两种两卡牌形；效果记录在谢烟客自己身上。第一次释放只为下次战斗铺垫；下一次无论对阵谁，敌人在每张基础卡结算时都受到一项500附加伤害。若该战斗再次释放碧针，下一次升为每张1000；再连续释放则逐层增加。

横向主样本暂取连续两次维持碧针：两场输出分别为白人基础400与2400，单次出场混合期望1400、标准差1011.14、穿透0。它准确反映首场铺垫与次场爆发，而不是把第二场伪装成稳定1400。连续第 `t` 场的期望为 `400+2000(t-1)`；前 `T` 场平均为 `1000T-600`。若有一场不再释放，链条在下一场结算完毕后终止。

弹指神通成功时可对任意在场敌造成200大招伤害并附加异常“点”。若作为侧面攻击，指定目标的期望伤害为56、标准差89.80；其更主要价值是异常而非伤害。控鹤功每个谢烟客自己的战斗回合可令一个敌方、且只针对谢烟客本人的特技无效，有利效果同样会被接掉。
