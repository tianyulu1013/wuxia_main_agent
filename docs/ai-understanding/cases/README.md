# 校准案例库

案例库保存具体卡牌的完整推导，用于同功能横向比较。案例不是核心规则，也不是特殊术语。

每个案例必须写明：

- 卡牌类别和主要功能。
- 牌面事实与作者确认口径。
- 完整计算或结算链。
- 可以迁移的结论。
- 不可迁移的边界。

只加载与当前卡同类别、同主要功能、同关键机制的少量案例。禁止把所有高分人物一起加载。
