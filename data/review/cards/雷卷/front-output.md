# 雷卷：正面输出

## 一、主模型口径

采用“完整八张基础卡、无预存埋雷、白人对阵者”的首轮模型：

- 双方四个位置的平克结果按`1/5克敌、3/5相平、1/5被克`独立估算；
- 雷卷先保留四张卡完成基础战斗，并有足够的剩余基础卡支付本回合失神指；
- 失神指每回合基础发动一次；
- 白人没有不利效果，故额外失神指只来自雷卷实际受到的伤害；
- 皮裘大氅按战斗顺序消耗整回合共享的200点抵挡；
- 不计既有埋雷、敌方防御、生命截断和失神指对未来回合的控制收益。

白人基础输出`B`：

- `E[B]=400`
- `Var(B)=22400`
- `SD(B)=149.6663`

## 二、受伤反应次数

按两个内功位、两个招式位的顺序结算敌方伤害，并先消耗皮裘大氅的200点额度。令`H`为抵挡后仍实际造成伤害的事件数：

| `H` | 概率 |
|---:|---:|
| 0 | 0.1936 |
| 1 | 0.4736 |
| 2 | 0.3328 |

白人没有不利效果，因此每次实际受伤只增加一次失神指。雷卷本回合失神指次数为：

`N=1+H`

最大为3次。四张已用于战斗，再弃最多三张，完整八卡足以支付。

## 三、正常交手条件输出

令正常交手时的正面输出为：

`X=B+500(1+H)`

`B`与`H`由同一组平克结果决定，不能当成独立随机变量。完整联合枚举结果：

| 输出 | 概率 |
|---:|---:|
| 1000 | 0.0864 |
| 1100 | 0.0832 |
| 1200 | 0.0656 |
| 1300 | 0.0816 |
| 1400 | 0.1600 |
| 1500 | 0.1824 |
| 1600 | 0.0464 |
| 1700 | 0.1120 |
| 1800 | 0.0480 |
| 1900 | 0.1056 |
| 2000 | 0.0288 |

因此：

- 期望：`E[X]=1469.6`
- 方差：`78115.84`
- 标准差：`279.4921`
- 变异系数：`0.1902`
- 范围：1000至2000

这是**小寒神判定失败、实际发生战斗且手牌完整**时的条件输出。

## 四、按一次被选出场计入小寒神

小寒神成功概率为二分之一。成功时不与对面交手，不能出失神指，本次对敌输出为0；失败时进入上一节的`X`。

令一次被选出场的输出为`Y`：

`Y=0（概率1/2），Y=X（概率1/2）`

得到：

- 期望：`E[Y]=734.8`
- 方差：`578988.96`
- 标准差：`760.9132`
- 变异系数：`1.0355`
- 范围：0至2000

横向正面输出主值采用`734.8`，因为它真实计入了雷卷出场后有一半不发生战斗；同时保留条件战斗值`1469.6`，避免把避战误读成战斗内输出偏低。

## 五、资源不足后的通式

前述数字只适用于完整八卡。设雷卷在保留四张战斗卡后，还剩`a`张可弃基础卡；本回合实际受伤事件数为`H`，不利效果数为`E`，则失神指次数上限为：

`N_a=min(1+H+E,a)`

正面输出写为：

`X_a=B_a+500N_a`

其中`B_a`还取决于缺失的是哪几张物理卡，不能只按剩余张数统一折算。小寒神成功后会凭空恢复全部基础卡，使模型重新回到完整八卡状态。

## 六、控制收益不折算为当回合伤害

失神指命中使来源敌后三回合攻击落空，重复命中只刷新。这会显著降低该敌未来输出，但不增加雷卷本回合数值输出，登记在全局影响和生存文件，不把未来阻断量虚构为当前伤害。

## 七、穿透与基础生命分布

- 失神指500无视防御，能绕过大部分普通抵挡、减伤和闪避。虽然它不是规则类型上的“一定造成”，无敌仍会令伤害和控制均无效，但在大部分常见防御环境中，它与一定造成的兑现效果接近，不能按零穿透处理。
- 正常交手时，失神指次数`N=1+H`，而`E[H]=0.4736+2×0.3328=1.1392`，故失神指期望输出为：

`500×E[N]=500×2.1392=1069.6`

- 实际交手条件下，实战穿透输出为1069.6，实战穿透率为：

`1069.6÷1469.6≈72.78%`

- 按每次被选出场计入二分之一避战后，实战穿透输出为534.8，总输出734.8，实战穿透率仍约72.78%。
- 严格一定造成输出仍为0；该字段只用于保留规则类型边界，不代表实战穿透为0。

正常交手白人模型最大输出2000，仍低于基础生命全体中位数2900及排除极低生命后的中位数3000。因此雷卷正面输出不属于裸生命一击型；真正的大数值来自埋雷，而非正面对阵。
