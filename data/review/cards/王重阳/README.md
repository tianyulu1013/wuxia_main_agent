# 王重阳评价摘要

状态：作者核心语义已校准；环境回归开放。

王重阳是高名义多段输出、续航、抽卡干扰与华山论剑调度兼具的综合人物。极致强攻期望2376但波动很大；华山论剑能制造真实连续战斗和重排物品归属，但依赖物品且王重阳必须参加，因此全局影响属于一般而非稳定强控。

| 正面输出 | 极致全真2376；一阳指路线1992 |
| 侧面输出 | 直接侧面伤害0 |
| 正面生存 | 4500生命、回复、移除全部不利、到0延迟死亡 |
| 侧面生存 | 高生命与延迟死亡；缺少即时硬防 |
| 全局影响 | 一般；高主动权但依赖物品、连续战斗与不确定赛果 |
