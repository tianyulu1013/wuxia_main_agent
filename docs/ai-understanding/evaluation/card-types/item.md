# 类别评价：物品

加载条件：卡牌类别为物品。

## 已确认基准

- 物品被摸到后直接进入本局。
- 物品不需要在弃牌阶段与战斗人物竞争。
- 物品不占两张战斗人物名额。

## 评价目标

在“本局已经获得该物品”的前提下，评价它如何帮助本局游戏。

至少分析：

- 牌面明确的使用者、对象和条件。
- 生效的流程节点。
- 一次性、重复或持续效果。
- 对本局输出、生存、控制、调度、关系或其他局势的实际帮助。
- 常见人物能否使用，以及不同人物使用时的差异。
- 条件不满足时是否完全无效。
- 与人物能力组合后的现实上限。
- 优点、缺点、规则风险和电子化风险。

## 禁止假设

物品的携带、转移、借出、夺取、损坏、焚毁、叠加和失去规则仍需逐项校准。不得预设物品槽位、通用机会成本或未写明的所有权规则。
