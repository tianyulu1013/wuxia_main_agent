# 人物评审的评分与统计展示体系

## 展示顺序

战斗人物网页评审固定按以下顺序展示：

1. 评分系统；
2. 统计系统；
3. 评语与推理；
4. 分维度完整证据与作者校准。

不能用“一句话总评”替代评分和统计。尚未建立口径或尚未完成评价的字段写“待定”，不得由其他数字自动推算。

## 评分系统

评分表达评价结论，统一预留百分制字段：

- 总评分；
- 泛用性评分；
- 战斗评分；
  - 正面输出评分；
  - 正面淘汰评分；
  - 侧面输出评分；
  - 正面生存评分；
  - 侧面生存评分；
- 全局影响评分。
- 名次保障／败局规避评分。

当前总评分、战斗评分及各子评分尚无统一权重。全局影响力也尚未确定己方辅助、敌方削弱、局势控制、覆盖、持续、可靠性与双刃风险怎样换算为分数。因此：

- 有作者确认或完成横向校准的分数才展示数值；
- 没有完成的项目显示“待定”；
- 总评分不得暂时用各子项简单平均；
- 统计期望不得直接线性换算为评分。

## 综合强度的监督性校准

当前22张精评人物的第一次AI粗排出现显著倒挂。作者提供的监督性参考将丁典列为第一梯队第3、丁喜列为第三梯队末位；AI此前分别排在21与3。作者同时说明该顺序不是绝对正确，只供参考。

这证明总强度不能以正面输出、穿透、侧面理论总量或能力影响范围为默认主轴。第三轮建立权重前，先遵守以下限制：

- 低输出不等于低综合强度；长期生存、重复出战、耗尽敌方手段和避免失败必须独立进入总强度。
- 高条件爆发不等于高稳定收益；必须折损敌方适应、资源窗口、信息要求、时序、存活、目标可用率与机会成本。
- 特殊胜利和名次保障都应计入整局价值，但不能因“直接胜利”字样自动置顶，也不能因缺少输出而忽略投靠、保和和不败。
- 全局影响评分必须评价所属玩家的稳定净收益；只证明“能影响很多人物”不足以证明人物强。
- 综合排序优先比较通常牌局中的持续净优势，再讨论单次上限。

监督性参考见`data/review/comparison/overall-strength-supervision.md`。在全人物第二轮回归完成前，该表只用于发现明显倒挂，不转化为固定权重或分数。

## 统计系统

统计表达在明确模型条件下可复算的物理结果，不等同于评分。

### 第一轮整局价值记录

第一轮在机制刚完成作者校准时，同时保存以下结论；它们先以有证据的定性判断为主，不强行换算为分数：

- **常态兑现率**：能力在通常牌局中取得合法窗口、合法目标并活到结算的难易；必须写明主要失败条件以及结果是否由对手控制。
- **预计有效行动次数**：人物通常能取得多少次有意义的出战、攻击、控制或资源兑现机会。没有统一生存模型时允许写区间或“待定”，但要保留重复次数、资源上限和死亡截断。
- **生命周期总价值**：把单回合收益放回整局，判断是一次爆发、稳定重复、递增成长，还是死亡后仍保留影响；不把理论无上限当成常态。
- **淘汰成本**：对手处理该人物需要普通输出、连续爆发、多项致死、清除／离场等特殊手段中的哪些，以及是否会消耗多个独立特技实例或战斗回合。
- **净交换价值**：所属玩家得到的收益减去本人、队友、机会成本与第三方收益。范围大或能改变很多人不自动等于净收益高。
- **长期胜势／结局转化**：优势最终能否稳定转化为杀敌、耗尽资源、避战、和局、结盟、保名次或直接胜利；纯粹“更难死”不能自动写成名次保障。
- **对手控制与规避权**：目标、牌形、分支、是否交手、是否响应及信息公开后反制由谁决定。条件爆发必须按这部分折损。

这些字段保存“单次物理能力怎样变成整局稳定优势”的中间层。第二轮再使用全体输出、穿透、击中、非伤害淘汰和防御环境统一回归；第三轮才换算评分。

### 输出统计

单卡证据仍可为每个策略或状态分别登记完整模型，但横向统计和网页顶部只展示一个主基线：

- 正面输出期望；
- 正面输出标准差；
- 实战穿透输出期望：在当前常见防御环境中，大部分情况下仍能兑现的输出；一定造成属于严格穿透，无视防御等高覆盖防御绕过能力也应计入实战穿透，但必须注明仍会被哪些上位防御挡住；
- 实战穿透率，即实战穿透输出期望占总输出期望的比例；
- 严格一定造成输出另行保留，不能因为无视防御在实战中接近一定造成，就把规则类型改写成“一定造成”；
- 侧面目标输出期望与标准差；
- 场下输出期望与标准差；
- 必要的范围、分布、目标数公式和死亡截断条件。

### 击中次数统计

`data/review/comparison/front-hit-count.json`记录正常正面主模型中形成的攻击击中事件期望：

- 闪避使攻击未击中；抵挡与无敌发生在击中之后，仍计击中。
- 附加伤害是独立攻击类型，每项附加伤害正常判断命中并计入击中次数；不能因名称中的“附加”二字把它理解成依附于另一攻击的数值。
- 生命流失、杀死、死亡和纯效果不因“造成数值结果”自动算作攻击击中。
- `x*y`按`y`次攻击分别计数；反射确实打出一份攻击时另计一次。
- 多目标攻击要区分“每名目标击中数”和“全场总击中数”，不能把人数扩张混入单目标正面主值。
- 没有足够证据判断某一伤害项是否属于攻击时，字段写待定并注明缺失语义，不为补齐表格擅自归类。
- 击中数与输出共用牌形时，方差和相关性应保留；当前只能确定期望时，不伪造标准差。

正面主基线直接读取`data/review/comparison/front-output.json`，侧面主基线读取`side-output.json`。每人只保留一个适合横向比较的主值和一句必要说明。一灯选择大部分时间处于的受伤状态；燕南天选择无目标生命上限的四卡完整模型；叶开采用后续上场1680并在说明中保留首次上场和参数公式。其他策略、初始短暂状态、特定生命目标或死亡截断继续保留在单卡推理中，不在横表重复展示。

累积型侧面输出不能默认取第一次的最低暂态。主值应选择人物在预计生存／资源生成窗口内通常达到的状态；若窗口内有多个连续阶段，可取这些阶段的单次平均并注明窗口。薛笑人的薛宝宝预计可形成约三个刺客，故侧面主值取前三名刺客`500、600、700`的单次平均600，而不是只取第一名500；前三名合计1800仍留在详细模型，不冒充单次输出。

### 非伤害淘汰统计

杀死、彻底死亡、清除、离场等结果独立于输出和穿透，读取`data/review/comparison/non-damage-elimination.json`。至少登记：

- 淘汰类型与规则后果；
- 每次合法机会的条件成功率；
- 触发时点与人物是否必须存活；
- 暂定生存窗口内的预计尝试次数；
- 至少一次成功概率和期望淘汰人数；
- 复活、免死、不能离场、清除免疫等主要反制。

不能把目标生命换算成伤害，也不能把普通杀死写成穿透。第三轮正面战斗评分应综合正面输出、正面淘汰、正面生存和其他直接战斗能力；正面输出评分本身仍只评价输出。

### 生存统计

预留：

- 正面单回合生存率；
- 正面生存回合期望；
- 侧面单次事件生存率；
- 侧面生存事件或回合期望。

生存率必须绑定攻击者、输出分布、非伤害淘汰比例及当前生命状态。没有明确环境模型时写“待定”，不能用`生命÷平均伤害`冒充生存回合期望。

第一轮允许另列“无防御名义承伤窗口”：按当前约1400暂定平均，以`ceil(生命/1400)`计算离散回合数。常规生命组中位数3000对应约3回合。该字段只帮助选择成长技能的常态阶段，不能冒充严格生存期望。

侧面生存目前没有统一的暴露频率与事件分布，网页保留字段但默认待定。正面和侧面生存只有在明确标记为顶部统一口径时才进入速览统计；白人压力测试、特定生命目标和示例性递推继续留在下方推理中。

### 生存强弱档位词典

第一轮定性统一使用以下七级顺序：

`很弱 < 弱 < 较弱 < 一般 < 较强 < 强 < 很强`

这些是相对于当前人物环境的档位，不是修辞语气：

| 档位 | 统一含义 |
|---|---|
| 很弱 | 几乎没有有效防护，并存在低生命、自伤、额外暴露或容易被常见手段直接处理等明显劣势；通常低于一次完整常态压力。 |
| 弱 | 明显低于当前环境；通常难以稳定承受一次完整常态作战，且缺少可重复防御、恢复、复活或可靠避战。 |
| 较弱 | 仍低于环境平均，但具有少量生命缓冲、一次性防御或条件保护，不至于接近完全无保护。 |
| 一般 | 大致处于当前环境中段；能承受常见的一次压力或有普通防御，但没有可靠的持续优势。 |
| 较强 | 明显优于一般人物；在常见场景中有稳定保护、较高有效生命或可靠避战，但仍存在常见反制与明显缺口。 |
| 强 | 具有多层、广覆盖或可重复防线；普通输出通常不足以轻易处理，需要集中爆发、多个独立手段或特定绕过。 |
| 很强 | 接近广泛硬保护或长期难以处理；覆盖多数常见攻击与效果，仅有较窄的规则缺口，应谨慎使用。 |

使用规则：

- `tier`只填写上述七个基础档位；“对【恶】强”“协作时无敌”“单独弱、叠加改善”等条件放入`condition`或`note`，不得创造“有条件偏强”“强但不全面”等无法排序的新档位。
- 正面与侧面必须分别判断；同一能力在两个位置的暴露频率、可用窗口和缺口可能完全不同。
- 生命、白人压力测试或`ceil(生命/1400)`只能提供证据，不能机械决定档位。
- 作者明确给出强弱校准时，以作者校准为当前锚点，并在后续全人物回归时检查旧条目是否存在语气漂移。

### 全局影响统计

当前只保留已有定性分档和一个待定统计区。未来至少需要研究：

- 影响对象数量或覆盖率；
- 每轮／每局触发频率；
- 成功率与可控性；
- 持续时间；
- 对己方和敌方的期望净收益；
- 对选战、结盟、行动和资源的改变程度。

在统一样本与换算方法建立前，不制造全局影响统计数字。

### 名次保障统计

名次保障与全局影响、个人生存分开。未来至少需要研究：

- 避免最后一名或出局的概率变化；
- 稳定前二、并列名次或依附领先者的概率；
- 提高第一名概率或直接触发特殊胜利的概率；
- 胜利判定顺位、失败抵消及成功触发后能否被响应撤销；
- 多人局与双人局差异；
- 接收、投靠、结盟或从属的可拒绝率；
- 谈判成功率、信用成本与背刺后的后续代价。

在没有真实对局样本前只保留定性分档，不用“几乎前二”等观察伪造精确胜率。

## 三轮评测顺序

1. 第一轮：逐人校准机制，完成正面与侧面输出主模型，并登记输出期望、实战穿透输出、实战穿透率和严格一定造成输出；人物具有杀死、彻底死亡、清除或离场时，另建非伤害淘汰模型。
2. 第二轮：全部人物第一轮完成后，使用全人物平均输出与平均实战穿透输出回归正面／侧面生存；全局影响拆为辅助队友、削弱敌方、场面控制、谈判能力；名次保障单独回归避免失败、稳定名次、直接夺冠、胜负顺位和信用成本。
3. 第三轮：依据前两轮形成的全体分布和分位，统一给各项能力、泛用性和总强度打分。

白人400保留为无能力人物的基础物理校验，不要求每张卡重复完整白人计算。当前23张抽样人物正面输出均值1314.42、总体标准差777.82；日常评卡仍按作者既定工作口径暂取约1400作为人物环境，用于解释承伤、生存、受击触发和爆发风险。使用时必须说明这是会随样本更新的暂定均值，不是规则常数。涉及攻击段数、击中次数、伤害类别、穿透或死亡截断时，1400总量不能替代对应分布。

全体输出摘要同时登记人物主值的均值与总体标准差、实战穿透输出的均值与总体标准差、合并实战穿透率，以及最大穿透来源人物的贡献占比；严格一定造成输出作为更窄口径另存。均值不能脱离离散程度和来源集中度单独解释。

## 数据来源

- 评分：`data/review/card_evaluations.json`中的明确评分字段；
- 极简横向统计：`data/review/comparison/`；
- 详细统计：`data/review/combat_baselines.json`与`calibrated_stats.json`逐人持续写入，仅在复核复杂模型时读取；
- 完整推导：`data/review/cards/<卡名>/`；
- 评语与作者裁定：评价摘要、理解笔记和作者校准文件。

网页只显示一个评审区块。存在精评时，理解笔记不再单独形成第二个“评审与理解”区块；没有精评时，理解笔记作为同一区块中的补充材料展示。

## 未来展示

统一评分口径和足够人物样本建立后，再增加：

- 六维或更多维雷达图；
- 按总评分、泛用性、战斗分项和全局影响排序；

在分数尚未建立时不生成空洞雷达图，也不允许用统计期望临时代替评分坐标。
