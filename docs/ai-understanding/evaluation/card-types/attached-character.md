# 类别评价：附加人物

加载条件：卡牌类别为附加人物或非战斗人物。

## 已确认基准

- 附加人物被摸到后直接进入本局。
- 附加人物不需要在弃牌阶段与战斗人物竞争。
- 附加人物不占两张战斗人物名额。
- 附加人物可以有生命、身份、人物关系和类似战斗人物的文本结构，但仍不因此变成需要竞争人物名额的战斗人物。

## 评价目标

在“本局已经获得该附加人物”的前提下，评价它能为本局增加多少实际帮助。

至少分析：

- 帮助对象和实际适用范围。
- 生效的流程节点。
- 发动次数、持续时间和条件。
- 对本局输出、生存、控制、调度、关系或其他局势的帮助。
- 常见局面下能否发挥。
- 与不同战斗人物组合时的上下限。
- 是否具有独立生命、可被指定或承担伤害；只有牌面或规则明确时才分析。
- 优点、缺点、规则风险和电子化风险。

## 禁止假设

不得自行假设携带上限、附加槽位、转移、借出、死亡、失去或独立出战规则。牌面和已确认规则没有说明时，列为待校准。
