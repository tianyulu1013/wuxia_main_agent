# 卡名别名与归属裁定表 v0.1

## 1. 原则

本表记录作者已经确认的卡名、PSD 文件名、TTS 显示名和牌堆归属裁定。

原则：

- 不自动修改 PSD 文件名。
- PSD 文件名会影响 Photoshop 排序位置，除非作者手动修改，否则工具不得改名。
- TTS `cardNames` 显示名优先使用作者确认的展示名。
- 当顺序表与真实 PSD 位置冲突时，先判断是顺序表错误、别名差异，还是牌堆归属变化。
- PSD 有但顺序表没有时，默认进入待确认；确认后修正顺序表。
- 顺序表有但 PSD 文件名不同，默认进入别名待确认。

## 4. TTS 命名脚本裁定

场景牌堆也可以生成一次 TTS 命名脚本。只要场景不增加、不换顺序，脚本长期不需要变化。

基础卡当前不进入发布辅助；未来电子化时再纳入资料结构。

## 5. 新增卡流程草案

新增卡时，默认流程为：

1. 作者把 PSD 放进真实目录。
2. 作者说明进入哪个 TTS 牌堆，以及插入哪个 slot。
3. 工具更新 `docs/tts-slot-orders-v0.1.md`。
4. 工具生成受影响牌堆的 `cardNames` 候选。
5. 作者确认后，用于 TTS 命名按钮脚本。
