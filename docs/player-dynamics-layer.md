# 玩家动态层

`data/review/player_dynamics.json` 用于记录玩家行为特点、桌面心理、仇恨值、围攻倾向等非牌面因素。

这一层不是规则术语，也不是卡牌源数据。

## 使用边界

- 可以用于评估实际玩法强度、暴露风险、隐藏价值和策略选择。
- 不得反向写入源数据库、Excel 或牌面事实。
- 不得把玩家行为特点写成某张卡自己的能力或优点。
- 不得把桌面心理当作规则结算。

## 当前观察

- 强者暴露后，其他玩家可能因为挑战强者的游戏快感而倾向于围殴或针对他们。
- 玩家重视第一和名次上升，但通常更想避免最后一名；不同玩家风险偏好不同。
- 玩家会通过拉拢、商量和默契形成临时阵营，但这不是规则结盟，也可能随谈判改变。
- 玩家往往讲究信用，以免被复仇或之后无法合作。
- 角色复杂度有舒适区：过复杂会玩不明白，太简单又无聊，中等复杂度通常更舒服。
- 玩家更喜欢华丽联动或大招赢下比赛；被表演干掉通常比被全屏蔽、全禁用、憋屈至死更容易接受。
- 玩家追求有意思的机制；稍微随机可以增加变化和趣味，但桌游是真随机，不能默认像电子游戏一样用伪随机或隐藏保底平滑体验。太过随机会削弱策略感和掌控感，尤其闪避、不中、完全落空类随机挫败感很强。

这些观察可以用于解释实际玩法强度、玩家选择、围攻目标、合作谈判和体验风险，但它们都不是卡牌源数据。
