# 燕南天评价摘要

状态：作者核心语义与白人模型已校准；环境回归开放。

燕南天以嫁衣神功把本回合对每名敌人的累计伤害按自身受伤次数及特殊亮卡次数整体翻倍，所有伤害一定造成并同时削减生命上限。其后发先至可以先杀死攻击者、取消尚未结算的后续攻击；多人战中每名敌人独立维护累计值。全局影响为一般。

| 维度 | 摘要 |
|---|---|
| 正面输出 | 四卡完整结算期望3110.4，标准差1761.73，范围900至11200 |
| 确定穿透输出 | 四卡完整期望3110.4；5000生命死亡截断期望2886.72；两模型穿透占比均为100% |
| 侧面输出 | 场下受有来源非对阵攻击时反击来源300；无来源不反击 |
| 正面生存 | 4400生命，无常规减伤；以后发先至击杀取消后续攻击 |
| 侧面生存 | 吸取及吸血无效，另有300反击；不防流失、异常、杀死、清除 |
| 全局影响 | 一般；约70名【恶】受即时贪心回避约束，但全库五百余张，覆盖有限 |
