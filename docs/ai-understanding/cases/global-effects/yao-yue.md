# 防反与储存案例：邀月

状态：作者核心语义已校准，环境量待回归。

完整证据：`data/review/workcards/batch_005_048_邀月.md`

## 白人盲打输出

假定邀月不储存输出，并把所有合格反射都打向对阵者。

定义：

- `K`：邀月本回合攻击次数；本节白人模型中只有普攻；
- `M`：敌方对邀月形成、被明玉功减免的基础攻击项数；
- `B`：邀月未计明玉功增攻的基础输出。

白人基线：

`E[B]=400`

`E[K]=2×1/5+2×4/5=2`

`E[M]=2`

明玉功每项减免100，并把总减免`100M`后发先至地加到本回合每一次攻击。由于同一位置的攻防事件相关：

`E[KM]=3.84`

回溯增攻期望：

`100×E[KM]=384`

邀月自身普攻名义期望：

`400+384=784`

两个招式位合计反射期望：

`2×(1/5×200+3/5×100)=200`

总防御前期望：

`784+200=984`

## 反射门槛

初始反射限制为300。普通单项名义伤害`A`先由明玉功减100：

`R=max(A-100,0)`

当`A≤400`时，`R≤300`，邀月可反射全部剩余伤害并承受0。

主动移花接玉使用招式位`--`。每次成功后反射限制提高100，从该回合结束后生效；可以反复单局累计，持续到本局结束。

## 储存与回滚

- 可储存自身将造成伤害的任意数值，攻击次数不减少。
- 储存可任意支取抵挡，或在出战回合向对阵者输出并附冰。
- 储存跨铜先生形态保留。
- 弃掉全部储存后，本回合双方及混战其他参与者的全部战斗结果、回合后结果和一定造成均无效，视为所有人空过。
- 这也撤销邀月自己的结果，不是单方面无敌。

## 铜先生

- 只能在回合外预先切换；回合中不能响应切换。
- 铜先生不中禁制、即死、看不见、清除，并视为男性。
- 此时没有邀月宫主，但明玉功和移花接玉仍在。

## 可迁移结论

1. 附加伤害是独立伤害类别，不等于攻击附带的所有效果。
2. 后发先至必须按相关条件期望计算，不能按普通顺序截断，也不能把`E[K]E[M]`当作`E[KM]`。
3. 储存伤害不减少攻击次数时，攻击事件与伤害数值必须分账。
4. “任意处”可包含空地；“人”和“人物”的对象范围不同。

## 不可迁移边界

- 明玉功向前追溯增攻是本卡特例。
- 邀月宫主整回合事务式回滚是本卡特例。
- 铜先生的形态保留储存和四类免疫不能推广。
