# 周威信评价摘要

状态：作者机制语义已校准；第一轮定量模型完成，真实多人局与全库机制环境回归开放。

周威信是**全场在场改写、人头优势调度、永久身份污染与强制行为控制型**人物。他本人只有2400生命，单独作战还会把自身克敌改成相平，因此不是靠单兵战斗取胜；真正价值是留在本方阵容中持续改变所有人的可被影响状态、参战方式和战后代价。

“不在场的人都在场”持续作用于全局：所有原本不在场的人重新成为可以被指定、攻击、波及和施加效果的在场人物。破空和无此人不是不在场，不被这句话拉回。与此同时，他人战斗不能影响周威信，而周威信可以影响他人，因此周威信本人获得单向侧面隔离，其他依靠不在场保命的人却会被暴露。

本方全部人头多于对阵方时，周威信玩家可以选择本方任意多名人物叠加出场，也可以不叠加；周威信本人不必参加。叠加人数没有牌面上限。这个能力能把最高攻击加成、多个可用特技和承伤选择集中到一套基础卡上，但并非无代价：如果叠加方打得差，该方每名叠加人物都分别受到一次无来源400附加伤害；若双方有多名【恶】，每名参战【恶】各受一次无来源800，而不是按两两组合倍增。

周威信不参加战斗时，与本方对阵者不能使用内容中含有其本人姓名的非被动特技，并永久变为【恶】。周威信亲自参加的战斗全部为非对阵，因此该战斗的另一方不属于“与本方对阵者”，上述禁名和改恶均不触发。战斗仍完整放置四张基础卡并正常比较，只把关系、攻击与响应属性改为非对阵。

单独战斗时，“铁鞭镇八方”把周威信原本克敌的位置改为相平。统一盲打模型下：

- 正面输出期望320，方差12800，标准差113.14，范围0至400；
- 防御前平均攻击／击中数1.6，方差0.32；
- 穿透输出0；
- 敌方基础输出期望480；
- 周威信以59.04%概率打得差并额外受到无来源400；
- 合并后单回合承伤期望716.16，白人压力测试下2400生命的期望存活约3.93回合。

这些单兵数字明显低于当前约1400的已评人物输出环境。周威信的整卡强度不能由320输出判断：最优思路通常是让其他人物叠加作战，周威信本人保持不参战，从侧面持续提供身份污染、在场改写、打得差惩罚和强制即时不利。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 单独盲打期望320、标准差113.14；叠加调度收益不冒充本人输出 |

| 全局影响 | 很强但高双刃；无上限叠加、全场在场、永久改恶、禁名与强制即时不利 |
