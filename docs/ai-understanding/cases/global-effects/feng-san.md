# 全局输出记录案例：凤三

状态：作者语义已校准；定量待回归。
用途：跨对手输出历史、递增失败归零、输出保底、差额生命流失、无来源邻近伤害。

## 1. 为什么本案例不能直接给固定分数

凤三的输出、防御与穿透均依赖全体人物的实际输出分布和防御环境。白人400是空白四卡模型的长期期望，不是全库人物平均，也不是单回合确定输出。作者确认凤三本人没有其他正面输出加成，所以第一回合正面对阵者输出接近白人400期望。应先逐张建立人物输出模型，随机积累几十张形成初版分布，最后用全库分布回算凤三。

## 2. 作者确认的核心状态

- 每个人物只有一份跨对手保存的“本局最近一次实际正常输出”记录。
- 人物先与第三方作战形成的输出，也用于以后对阵凤三阵营时比较。
- 人物本局第一次出战没有记录，直接视为高于上回合。
- 非凤三阵营人物未严格高于历史记录时，攻击与不利效果无效，本回合输出记录为0。
- 凤三阵营人物无法以正常输出达到`上次实际输出+100`时，由敌方发生差额生命流失。
- 生命流失不是输出，不更新下一次输出记录。

## 3. 敌方递增状态模型

令`X_t`为本回合待校验输出，`P_t`为该人物此前最近一次实际输出，`V_t`为本回合实际生效输出。

无历史记录：

`V_t = X_t`，`P_(t+1) = X_t`。

有历史记录：

- `X_t > P_t`时，`V_t = X_t`，`P_(t+1) = X_t`。
- `X_t ≤ P_t`时，攻击与不利效果无效，`V_t = 0`，`P_(t+1) = 0`。

失败会把下一次门槛重置到0，但不能由此预设固定的`400、0、400`周期。期望承伤必须由人物输出分布驱动上述状态转移。

## 4. 凤三阵营输出保底模型

令：

- `B_t`：本回合原始正常输出。
- `P_t`：上一次实际正常输出。
- `T_t = P_t + 100`：本回合目标。
- `O_t`：提高输出并经过防御后实际形成的正常输出。
- `L_t`：敌方发生的差额生命流失。

有历史记录时先争取`O_t ≥ T_t`。若正常输出仍无法达到目标：

`L_t = T_t - O_t`。

下一次记录：

`P_(t+1) = O_t`，

不能记录为`O_t + L_t`。例如目标1100、正常输出被完全阻断为0、敌方发生1100生命流失时，本回合输出记录仍为0。

## 5. 行云布雨模型

本能力没有“可”，属于被动自动结算。

令凤三本回合实际受到总伤害为`D`，对阵者周围有`n`个距离1且属于凤三之敌的人物：

- 每个目标防御前受到`2D`的一次无来源伤害。
- 防御前总量为`2nD`。
- 目标可以防御。
- 无来源只使需要寻找来源的反击、反弹无法确定对象，不使伤害变成一定造成。
- 凤三处于侧面时没有“凤三对阵者”，本能力不提供个人侧面输出或自保。

## 6. 条件穿透矩阵

| 防御环境 | 凤三机制 | 穿透结论 |
|---|---|---|
| 无防御 | 正常输出达到目标 | 没有独立一定造成部分 |
| 普通数值减伤 | 继续提高正常输出补足目标 | 对数值防御具有强制兑现能力 |
| 完全闪避或无伤 | 无法兑现的差额改为生命流失 | 对能发生生命流失的目标具有条件穿透 |
| 正常输出与生命流失均被阻断 | 进入悖论处理 | 扔出游戏不是伤害，不计为穿透输出 |

不得给凤三一个脱离环境的固定穿透百分比。

## 7. 生存计算接口

凤三3333生命，无减伤、闪避、回复、免死或异常免疫。

未来得到人物输出分布后，正面期望承伤按：

`E[V_t] = E[X_t × I(无历史或X_t>P_t)]`

并使用失败后`P_(t+1)=0`的状态转移求长期分布。侧面生存另按3333生命、无独立硬防及敌方整回合效果可能被全局校验无效的条件概率计算。

## 8. 可迁移结论

1. 白人400只可作为空白人物输出基线，不能当作全库平均或单回合确定值。
2. “上回合输出”若经作者确认是人物历史，必须跨对手保存。
3. 输出失效后记0会改变下一次状态，必须用递归或马尔可夫状态模型，不能只看单回合。
4. 生命流失不是输出，不能写回输出历史。
5. 无来源伤害仍可被防御，只切断需要寻找来源的反击链。
6. 依赖全库环境的卡应先保存符号模型，样本积累后回归重算。

## 9. 不可迁移边界

- 悖论、无限循环及卡住导致和局时移出相关卡片，是凤三专属裁判条款。
- 行云布雨的距离中心、两倍累计伤害和无来源属性不能推广到普通反伤能力。
- 本案例不提供凤三固定强度、泛用性、穿透率或存活回合。
