# 叶开评价摘要

状态：作者核心语义与内生数值模型已校准；复制收益与真实事件频率待环境回归。

叶开是必须保持在场、但不必参加当前对战的救援与打断人物。首次上场已有两次小李飞刀机会；主动放出小李飞刀既造成可防御的1000大招伤害，又增加一次以后使用的救援／打断机会。对【恶】时按规则书获得无敌；对非【恶】可令一项特技对自己无效；对阵时还能在对手全部“技能”和全部`*`特技之间选择一类复制。

| 维度 | 摘要 |
|---|---|
| 正面输出 | 总体期望待定；首次上场2680，后续上场1680；实际上场`T`回合时平均为`1680+1000/T` |
| 穿透 | 期望确定穿透0，占比0%；小李飞刀没有一定造成或破 |
| 侧面／场下输出 | 每把飞刀可选0或1000；首次总容量2960、后续每次边际容量1960，但真实兑现依合格事件 |
| 飞刀资源 | 首次上场固定获得并可兑现2把；主动成功率28%，每次成功另生成一把 |
| 正面生存 | 真实平均生存／上场回合数待定；5.44仅是非【恶】白人压力测试，不能代入总体输出 |
| 侧面生存 | 对【恶】来源同样无敌；对非【恶】可封一项相关特技，但对其余普通伤害无硬减免 |
| 全局影响 | 强；在场即可跨战斗撤销一次致死事件或后发先至取消一项特技，次数可持续积累 |

评分面板目前全部待定；统计与评分不混用。
