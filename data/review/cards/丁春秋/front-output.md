# 丁春秋：正面输出

## 一、统计口径

主模型采用以下状态：

- 丁春秋固定摆放内功土火、招式木火；
- 敌方各位置五行按白人均匀基线独立取值；
- 丁春秋真实喊话，法螺功令两个已按组合放置的大招不看平克结果直接施放；
- 化功大法当前造成400大招攻击；
- 星宿火当前回合产生第一项300；
- 不计目标防御、死亡截断、腐尸毒尸体资源和星宿火未来回合；
- 标准毒、禁内、禁招和类别禁制分别登记，不折算成当前伤害。

固定摆牌面对均匀敌方时，每个位置仍有`1/5克敌、3/5相平、1/5被克`，所以基础四卡输出`W`沿用白人分布：

- `E[W]=400`
- `Var(W)=22,400`
- `SD(W)=149.67`
- 范围`0—800`

## 二、法螺功强制双大招主模型

当前回合名义输出为：

`D=W+400+300=W+700`

因此：

- 期望：`E[D]=400+700=1100`
- 方差：常数平移不改变方差，`Var(D)=22,400`
- 标准差：`SD(D)=149.67`
- 变异系数：`149.67/1100≈13.61%`
- 范围：`700—1500`
- 确定穿透输出：0
- 穿透率：0

离散分布：

| 当前名义输出 | 概率 |
|---:|---:|
| 700 | 2.56% |
| 800 | 1.28% |
| 900 | 15.52% |
| 1000 | 12.80% |
| 1100 | 26.56% |
| 1200 | 27.20% |
| 1300 | 11.68% |
| 1400 | 2.24% |
| 1500 | 0.16% |

法螺功把大招部分变成固定700，使总输出相对稳定；输出波动只来自基础四卡。

## 三、不喊话时的默认放出参考

这个模型不是推荐策略，只用于说明法螺功的真实增量。

任一两卡主动大招默认成功条件是：

1. 两个位置都没有被克；
2. 至少一个位置克敌。

成功率为：

`(4/5)^2-(3/5)^2=16/25-9/25=7/25=28%`

化功大法与星宿火分别占独立的内功、招式位置：

- 每项成功率均为28%；
- 两项同时成功概率为`(7/25)^2=7.84%`；
- 因大招成功事件与基础输出共享平克结果，不能把大招贡献当成与`W`独立。

枚举四位置`克敌／相平／被克`共81种状态后：

- 期望：596
- 方差：115,360
- 标准差：339.65
- 变异系数：56.99%
- 范围：0—1500

法螺功喊话把当前期望从596提高到1100，并把标准差从339.65降低至149.67。它的价值不仅是提高均值，也把两个大招从28%条件事件变成固定兑现。

## 四、星宿火的跨回合容量

设星宿火施放回合记为第1回合，目标在此后共维持该不利`T`个回合，且没有提前死亡或移除不利。

星宿火累计名义伤害为：

`S_T=300T`

若只计施放回合的基础四卡与化功大法一次，则截至第`T`回合，丁春秋对该目标的累计名义输出容量为：

`C_T=W+400+300T`

所以：

- `E[C_T]=800+300T`
- `Var(C_T)=22,400`
- `SD(C_T)=149.67`

`T=1`时即顶部主模型1100。未来每多维持一回合，增加固定300场下输出。

这个公式不包含：

- 目标每回合支付200免除毒的自身生命成本；
- 不支付时每次毒判定的生命-100和1/6死亡；
- 目标防御每回合300的结果；
- 目标死亡导致后续300终止；
- 重复施放星宿火是否产生额外同名持续源；当前不把同名持续源重复相加。

## 五、毒的两种策略分支

标准毒不累积。每个毒判定前，目标选择：

### 支付200

- 当前毒被彻底免除；
- 本次不进行毒判定；
- 星宿火持续不利仍存在，下一回合重新附毒；
- 目标若连续支付，需每回合重新支付200。

支付属于目标主动承担的生命成本，不登记为丁春秋的攻击输出，也不算确定穿透伤害。

### 不支付

- 每回合只进行一次毒判定；
- 生命-100，不减少生命上限；
- 有1/6概率死亡；
- 多次重新中毒不提高单次判死率。

若只研究毒判定、不考虑300伤害和其他死亡来源，连续不支付时：

- 通过`r`次判定仍未被毒死的概率为`(5/6)^r`；
- 首次毒死前的判定次数期望为6。

这是毒机制压力测试，不是目标实际还能活6回合；每回合300和其他攻击通常会更早截断。

## 六、下一回合控制收益

化功大法与星宿火同回合放出后，目标下一回合同时受到：

- 禁内：两个内功卡位为空；
- 禁招：两个招式卡位为空；
- 禁制内功类大招；
- 禁制招式类大招。

目标下一回合基础四卡全部为空。其对手若正常放满四张基础卡，四个位置都视为克敌，基础输出固定为：

`2×100+2×300=800`

这800来源于目标下一名对手，不是丁春秋个人输出，登记为敌方削弱／全局控制收益。目标仍可能使用未被禁制的技能、身份特技、武功或其他特殊结果。

## 七、结论

丁春秋自己的正面主模型是稳定1100，而不是只看两个大招的700。真正长板是：

1. 法螺功把两个28%主动大招变为固定放出；
2. 星宿火每多维持一回合增加300；
3. 双禁令目标下一回合四卡全空并封锁两类大招。

腐尸毒另有尸体资源和死亡连锁，不混入无资源的顶部正面统计。

## 八、正面击中次数

自喊双大招主模型中：

- 基础四卡攻击期望2次；
- 化功大法固定形成1次400大招攻击；
- 星宿火本回合固定形成1次300附加伤害攻击；
- 毒、禁内、禁招及类别禁制是效果，不另增加攻击击中。

合计期望4次，方差仍由基础四卡产生，为0.64，标准差0.8。星宿火的300虽是附加伤害类别，仍是一项独立攻击并计入击中。
