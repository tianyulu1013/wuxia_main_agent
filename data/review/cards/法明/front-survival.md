# 法明：正面生存

## 一、基础条件

- 生命2689；
- 低于全体有限生命中位数2900，也低于排除极端低血后的中位数3000；
- 没有减伤、回复、复活或免死；
- 主要防线是不碎金刚产生的跨回合无敌；
- 首次放出要等四卡全部结算，不能保护本回合此前伤害。

当前已评人物约1400的输出均值说明2689约为不足两个平均输出回合的裸生命量级，但该比较不能代替攻击时序和爆发分布。四卡结束前的高爆发仍可直接杀死法明。

## 二、不碎金刚放出率

对每个卡位，均匀盲打下：

- 法明克敌概率`1/5`；
- 被敌克概率`1/5`；
- 相平概率`3/5`。

设四位置净克制分数为：

`S=克敌数-被克数`

不碎金刚在`S>0`时放出。精确分布为：

| S | 概率 |
|---:|---:|
| -4 | 0.0016 |
| -3 | 0.0192 |
| -2 | 0.0928 |
| -1 | 0.2304 |
| 0 | 0.3120 |
| 1 | 0.2304 |
| 2 | 0.0928 |
| 3 | 0.0192 |
| 4 | 0.0016 |

由对称性：

`P(放出)=P(S>0)=(1-0.312)/2=0.344`

即单次盲打放出率34.4%。

## 三、无敌持续与续接

已处于无敌时，一回合至少一个内功位被克的概率为：

`1-(4/5)²=9/25=36%`

若暂不考虑同回合续接，从无敌开始到包含终止回合在内，受保护回合数服从参数0.36的几何分布，期望：

`1/0.36=2.7778回合`

但终止回合可能再次放出不碎金刚。联合枚举四个位置：

- 内功被克且本回合再次放出：3.2%；
- 内功被克且没有放出：32.8%；
- 没有内功被克：64%。

因此简化为回合开始状态的两态链：

| 当前状态 | 下一回合无敌 | 下一回合非无敌 |
|---|---:|---:|
| 非无敌 | 0.344 | 0.656 |
| 无敌 | 0.672 | 0.328 |

稳态无敌比例：

`π=0.344/(0.344+0.328)=0.5119`

约51.19%。这只是均匀盲打、每回合持续出战、没有禁内功／改牌／强制离场的长期结构值，不是实战固定减伤率。

## 四、无敌覆盖

无敌生效后：

- 普通攻击、伤害和不利效果无效；
- 普通一定造成、破与无视防御也不能自行穿过；
- 五行比较和“内功被克”事件仍会记录；
- 抢先在不碎金刚放出前完成的攻击不会被追溯；
- 明确破除无敌、使不碎金刚失效或令法明来不及放出的能力仍可突破。

## 五、结论

正面生存暂评：**有条件强**。

无敌一旦建立，可以覆盖完整的终止回合，并可能同回合续接；这是真实的跨回合硬防。但34.4%的首次放出率、四卡结束后的晚时点和2689低生命，使法明在第一次建立状态之前明显脆弱。不能只凭约51.19%的长期无敌比例，把他评成稳定全程无敌。
