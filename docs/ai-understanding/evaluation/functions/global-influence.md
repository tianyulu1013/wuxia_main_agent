# 战斗人物功能：全局局势与关系政治

加载条件：战斗人物主要通过结盟、阵营、名次、人物关系、战斗对象循环、地点或其他整局局势产生价值。

## 评价问题

- 能力改写默认游戏流程的哪个环节。
- 理论适用对象有多少。
- 发动权掌握在自己、队友、敌人还是任意玩家手中。
- 其他玩家是否可以拒绝或不配合。
- 参与者为什么愿意发动，需让出什么名次或利益。
- 理论覆盖面与实际触发率分别是多少。
- 形成的结盟是否会减少正常战斗、改变围攻或改变胜利顺位。
- 当前阵容强弱是否会改变他人选择。
- 本人的正面作战只是保底，还是仍是主要贡献。

玩家意愿必须调用 `data/review/player_dynamics.json`，但不得把玩家倾向写成自动规则。

不同功能人物之间，正面输出差距只能说明战斗差距，不能直接推出整卡强弱。
