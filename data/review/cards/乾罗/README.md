# 乾罗评价摘要

状态：作者核心语义与首轮参数模型已完成；强制空位出现率、填空成长速度和额外战斗目标生态等待环境回归。

乾罗是**双回合强攻、单矛攻防与场外抗扰型**战斗人物。正常回合结束后，他可以再行动一回合并挑战任意处任意敌；额外回合仅令敌人的普攻及其攻击加成为0，不封大招、附加伤害和效果。乾罗只有一把矛，正常回合与追加行动不能各算一把；整段行动中只能选择一次矛的攻击、抵挡或侧面反击。

横向主样本取未成功填空、两回合集中同一敌并把唯一一矛用于进攻：输出期望1800、标准差211.66、范围1000—2600；其中1000“破”是实战穿透能力，占名义输出55.56%，但并非无条件一定兑现。破无视目标的普通防御和抵挡，却仍受乾罗自身降命中、降输出影响；“一定造成”还额外突破闪避并无视这些攻击者负面状态。二者都不能自行穿过无敌。

成功用任意手牌填补一次自身被迫产生的“空”后，本卡除生命外的阿拉伯数字从此永久翻倍，并能在本局继续累计。设已成功填空 `k` 次，唯一一矛的伤害为 `1000×2^k`，两回合集中输出期望为 `800+1000×2^k`。但作者确认填空在实际游戏中非常罕见；乾罗不能主动留空，手里能放满四张时必须放满。因此成长只作为罕见上限分支，不参与常态定位。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 无填空集中主值1800，标准差211.66；罕见填空 `k` 次后为 `800+1000×2^k` |
| 实战穿透能力 | 无填空1000“破”，占名义输出55.56%；仍受自身降命中、降输出影响，且不能破无敌 |
| 侧面输出 | 额外回合改打另一敌时，该目标期望1400、标准差149.67，其中1000为实战穿透；与正面总量共用 |
| 正面生存 | 一般偏强；3100生命接近总体均值，整段双回合可牺牲唯一一矛换一次攻击抵挡，额外回合还令敌普攻归零 |
| 侧面生存 | 较强；不出战时不中不利效果，且可用矛抵挡一次侧面攻击，但普通攻击和伤害仍然有效 |
| 全局影响 | 较弱；任意处追击主要仍是个人侧面输出，没有队友辅助、跨战干预或持续场面改写 |
| 名次保障 | 无；没有结盟操纵、名次移动、胜负改写、投靠或直接胜利能力 |
