# 全局与机制控制案例：邀月

状态：作者校准。  
用途：防御对决、双重身份切换、伤害反射与输出储存蓄能的典型案例。

## 1. 数值管线与 Phrasing 映射

本案例严格适用以下数理概念：
* **$x$（基础攻击/基础伤害）**：五行牌比对产生的原始伤害（内功 100，招式 300/200），不计任何特技加成。
* **$a$（名义攻击）**：包含大招、附加等所有加成计算完、但未结算防御前的攻击值。
* **$b$（实际伤害）**：名义攻击 $a$ 扣减防御结算后的最终值。
* **$c$（实际受伤）**：真正扣减血量的值（受生命值上限卡死）。

## 2. 特技机制精确分析

### 特技一：明玉功 (内功)
1. **名义降低**：`受到的单项伤害基础-100` 作用于 **名义攻击 $a$**（包含大招/附加加成但未计防御），而非最原始的五行牌基础伤害 $x$。
2. **生命与攻击增长限时**：
   * **普通加血**：明玉功增加生命时未写“上限”二字，因此判定为**普通治疗加血（常规治疗恢复）**，不能突破 3300 的最大生命上限。
   * **单回合攻击力增长**：明玉功带来的攻击力提升是**单回合限时增长**，在当前轮对决结束后失效，不能跨回合永久累加。该加成在生效回合直接增加到邀月自己该回合发起的**每一次伤害性打击上**。
3. **大招伤害趋势吸收**：`大招伤害趋势吸敌300` 属于“伤害趋势”判定。若敌方的大招在机制设计上**不造成伤害**（例如纯控制/纯异常特技），则**不发生吸收**。若有伤害属性但因防御降为 0，则正常吸收。

#### 💡 明玉功 1v1 经典对决模拟演算 (精确到 4 次单项比拼)

邀月在对局中受到的伤害是按 4 次单项比拼（前 2 张内功，后 2 张招式）**逐次独立结算**的。

##### 演算案例 1：双方对战全平 (All Ties)
* **比拼状态**：内功 2 张皆平（各造成 0 伤害）；招式 2 张皆平（敌名义攻击 $a_3 = 200$, $a_4 = 200$）。
* **明玉功结算**：
  * 对敌方的 2 次招式打击分别削减 100：
    * 实际被削减值（减免的伤害）：$100 \times 2 = 200$ 点。
    * 邀月获得增益：**普通治疗 +200 生命**；**该回合名义攻击力 +200**。
  * 敌方实际造成的伤害 $b$：
    $$b_3 = 200 - 100 = 100 \text{ 点}, \quad b_4 = 200 - 100 = 100 \text{ 点} \quad (\text{合计 } 200 \text{ 点})$$
* **邀月自身攻击输出**：
  * 邀月招式位同样为平（基础伤害 200 点），但攻击力获得明玉功的 +200 增益，且作用于每一次打击：
    $$\text{实际输出 } b_{\text{邀月}} = (200 + 200) \times 2 = 800 \text{ 点}$$
* **血量盈亏判定**：
  * 邀月承受实际伤害 200 点，同时获得明玉功的治疗加血 200 点。
  * **净血量变动 = 0**（不掉血），并对敌方打出 **800 点高额输出**。

##### 演算案例 2：敌内功两克，招式两平 (Opponent wins 2 Internals, ties 2 Moves)
* **比拼状态**：敌方内功 2 张皆克（名义攻击 $a_1 = 100$, $a_2 = 100$）；招式 2 张皆平（名义攻击 $a_3 = 200$, $a_4 = 200$）。
* **明玉功结算**：
  * 对敌方 4 次打击分别削减 100：
    * 内功 2 次各减免 100（减至 0）；招式 2 次各减免 100（减至 100）。
    * 实际被削减值（减免的伤害）：$100 \times 4 = 400$ 点。
    * 邀月获得增益：**普通治疗 +400 生命**；**该回合名义攻击力 +400**。
  * 敌方实际造成的伤害 $b$：
    $$b_1 = 0, \quad b_2 = 0, \quad b_3 = 100, \quad b_4 = 100 \quad (\text{合计 } 200 \text{ 点})$$
* **邀月自身攻击输出**：
  * 邀月招式位为平（基础伤害 200 点），名义攻击力获得明玉功的 +400 增益：
    $$\text{实际输出 } b_{\text{邀月}} = (200 + 400) \times 2 = 1200 \text{ 点}$$
* **血量盈亏判定**：
  * 邀月承受实际伤害 200 点，同时获得明玉功的治疗加血 400 点。
  * **净血量变动 = +200**（不但不掉血，反而多回血 200），并对敌方打出 **1200 点恐怖输出**。

### 特技二：移花接玉 (武功)
1. **反射顺序**：反射的伤害值是在明玉功等前置名义减免结算之后，针对最终的 **实际伤害 $b$** 进行判定。
2. **“反射伤害”与“反射攻击”的本质差异**：
   * **反射伤害 (邀月情况)**：邀月**实际承担了这次攻击事件**。如果该攻击带有冰冻等附加状态效果，**邀月自身依然会中这些状态异常**。她仅仅是将结算出的“伤害数值”反射转嫁出去。
   * **反射攻击 (其他卡牌特有)**：角色完全不承担这次攻击事件，因此豁免一切攻击附带的次生效果或状态异常。

### 特技三：邀月宫主 (专属特技)
* **储存源判定**：`可将伤害储存` 实际上是指**可将自身造成的输出伤害进行储存**。
* **战术代价**：需要主动放弃或削减自己某回合某次对敌方造成的输出，将其充能存入蓄能池，用以在后续回合抵挡伤害，或在输出时释放并附带“冰”（触发时机由邀月自由选择）。
* **无效化高优先级与漏洞**：弃掉所有储存使自己一回合战斗结果无效。
  * **战术规避**：这可以作为紧急逃生键，强行躲掉敌方单次极高额的爆发输出（如 1500 点打击）；后续回合可以通过再次输出、重新充能，循环利用此招躲避爆发。
  * **穿透漏洞**：**“一定造成”属性的伤害能直接穿透并无视此无效化效果**。若敌方的爆发打击附带“一定造成”，即使邀月弃掉所有储存也无法躲避，依然会受到伤害。

### 特技四：铜先生 (身份特技)
* **身份切换**：选择以铜先生面目出现时，临时失去《邀月宫主》特技（无法储存与释放）。
* **最高优先级过滤**：铜先生面目下，获得对“禁制”（抹去）、“即死”（杀死）、“看不见”、“清除”的绝对免疫。
* **性别改写**：人物逻辑性别转为男性（影响所有针对女性人物的敌对特技或结盟判定）。

## 3. 受击伤害门槛与净血量盈亏数学推演

将《明玉功》（-100名义减免与治疗）与《移花接玉》（反射实际伤害 $b_i \le 300$）联结进行状态机模拟，可以推导出极其关键的**受击门槛定理**：

设敌方单次名义攻击值为 $a_i$。

### A. 单次受击结算公式：
1. **明玉功减免与治疗**：
   * 减免量（治疗量）为 $\Delta_i = \min(a_i, 100)$。
   * 减量后的名义攻击为 $a_i - 100$。
2. **移花接玉反射过滤**：
   * 实际伤害 $b_i = \max(0, a_i - 100)$。
   * 若 $b_i \le 300$（即 $a_i \le 400$），则该实际伤害被**完全反射**至任意处，邀月承受的实际受伤为 0。
   * 若 $b_i > 300$（即 $a_i > 400$），反射失败，邀月承受实际受伤 $c_i = b_i = a_i - 100$。

### B. 单次受击的净血量变动 (Net HP Change)：
* **当敌方名义攻击 $a_i \le 400$ 时**（且无特殊穿透属性）：
  $$\text{净血量变动} = \text{治疗} - \text{实际受伤} = \Delta_i - 0 \ge 0 \quad (\text{若 } a_i \ge 100\text{ 则净回血 } +100)$$
  * **定理一**：**在无穿透属性时，任何名义攻击低于或等于 400 点的打击，不仅无法对邀月造成任何伤害，反而会每次为邀月净回复 100 生命值。**
* **当敌方名义攻击 $a_i > 400$ 时**（或有特殊穿透，反射失效）：
  $$\text{净血量变动} = \text{治疗} - \text{实际受伤} = 100 - (a_i - 100) = 200 - a_i < 0$$
  * **定理二**：**只有名义攻击大于 400 点的单次重击，或者带有下述“顶级穿透属性”的打击，才能突破防御网，真正对邀月造成血量削减。**

### C. 穿透防御网的致命克星 (防御漏洞分析)：
邀月的防守在常规对决中表现优异，但**绝非顶级防御**。她面对以下三种高层级攻击属性时会彻底暴露出防守死角：
1. **一定造成 (Certain Damage)**：强行产生伤害，绕过常规防御和减量。
2. **破 (Defense-Pierce)**：强行破防。
3. **无法抵挡 (Unblockable) $\rightarrow$ 导致不能反射**：
   * **核心铁律**：**如果敌方的攻击带有“无法抵挡”属性，则该次攻击不仅无法被防御/减免，同时也直接导致“不能被反射”**。邀月的《移花接玉》在此类攻击面前完全哑火，必须强吃实际伤害。

*(注：相比之下，《谢玄》的“自身无敌”（九品高手）才属于游戏内的顶级防御，能够彻底免除一切正侧面敌方伤害，仅受限于自身每回合 -400 的强制生命扣减。)*

### D. 攻击频次模拟（为什么敌方出手次数越少越好）：
假设敌方在一回合里发起总额相同的输出（无无法抵挡/破/一定造成等属性）：
* **分兵蚕食（多段小攻击）**：敌方攻击 3 次，每次名义攻击为 300。
  * 每次 $a_i \le 400$ 全部被反射，邀月承受 0 伤害，**净回血 300 点**，且本回合名义攻击力暴增 300，并将 900 伤反射给敌方。敌方彻底自杀。
* **孤注一掷（单次大爆发）**：敌方集中为 1 次大攻击，名义攻击为 900。
  * $a_1 = 900 > 400$ 反射失效。邀月承受实际伤害 $900 - 100 = 800$，明玉功治疗 100。
  * **最终结果**：邀月**净损失 700 生命**。
  * **战略结论**：对战邀月时，**敌方攻击次数越少越好**。多段、小额、高频的输出在邀月的联防面前无异于送血送攻。

## 4. 邀月自身输出期望解析

设敌方一回合内发起了 $M$ 次名义攻击 $a_i \ge 100$ 的打击，其中有 $R$ 次常规打击满足反射条件（$a_i \le 400$ 且不含“无法抵挡”）。

邀月在招式位正常放卡时（设造成伤害的攻击次数为 $K$，通常平手时 $K=2$）：

* **输出组成**：`自身招式输出`（基础值 200 + 明玉功加成）+ `移花接玉反射的敌方实际伤害`。
* **总输出数学期望公式**：
  $$\text{总输出} = K \times (x_{\text{招式}} + 100 \times M) + \sum_{j=1}^{R} (a_j - 100)$$

* **全平状态下的伤害兑现**（敌 2 次 200 伤招式，皆平且反射）：
  * $K = 2$, $M = 2$, $R = 2$, 敌名义值 $a_3 = a_4 = 200$。
  * 自身打击输出：$2 \times (200 + 200) = 800$。
  * 反射伤害输出：$2 \times (200 - 100) = 200$。
  * **全平输出总期望 = 1000 点**（自身打 800 + 反射 200）。
* **内功被克、招式平手状态**（敌 2 次 100 内功克，2 次 200 招式平且反射）：
  * $K = 2$, $M = 4$, $R = 2$, 敌名义值 $a_1=a_2=100, a_3=a_4=200$。
  * 自身打击输出：$2 \times (200 + 400) = 1200$。
  * 反射伤害输出：$2 \times (200 - 100) = 200$。
  * **总输出期望 = 1400 点**（自身打 1200 + 反射 200）。
