# 白清儿评价摘要

状态：第一轮机制与输出模型已完成；环境回归开放。

白清儿不是正面输出人物。她的四卡输出仍是白人基线：期望400、标准差149.67、严格穿透0，且没有侧面输出。她的核心价值来自四个方向：

1. 场上没有战斗时，可以强制投入大多数其他玩家，算作从属但仍由原玩家控制；
2. 姹女大法把正面一回合合计受伤或侧面单次受伤拆成两个尽量接近平方根的整数乘子，再把乘积改为两乘子之和；
3. 可一次性令所属玩家一名男子在此后参加两次战斗后死亡。
4. 在大混战中反复投靠当前第一名，并以延迟死亡作谈判威胁，显著降低原玩家垫底或提前出局的概率。

对白人一回合原始承伤分布，姹女大法把期望400压到约39.2576，标准差由149.67压到约9.2064。600生命在该模型下预计约15.8054个战斗回合死亡。这只是检验机制强度的白人压力测试。当前已评人物真实正面输出均值虽超过1500，但乘积改和是非线性的，不能把均值直接代入；在缺少逐项伤害与回合总伤害分布时，不估算真实环境生存期。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 期望400，标准差149.67 |
| 确定穿透输出 | 0，穿透率0 |
| 侧面输出 | 0 |
| 正面生存 | 伤害型生存很强；白人压力测试约15.8054回合，真实综合待回归 |
| 侧面生存 | 伤害型生存很强；不防流失、死亡、清除和控制，综合待回归 |
| 全局影响 | 一般；能影响一名宿主及一名男子，但覆盖不全面 |
| 名次保障／败局规避 | 很强（大混战）；可依附当前第一名并以死亡威胁谈判避战 |
