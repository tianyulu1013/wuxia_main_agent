# 凤三：规则语义与结算

## B. 牌面原文

> 武功：行云布雨，凤舞九天：回合中凤三对阵者周围距离为1的敌承受此回合凤三受到伤害2倍的伤害，无来源

## D. 已确认的语义边界

### D1. 行云布雨

1. 牌面没有“可”或其他可控文字，属于不可选择的被动能力，条件满足时自动生效。
2. “此回合凤三受到伤害2倍”按回合累计理解：先确定凤三本回合受到的伤害总量，再形成一次两倍伤害；不是每受一段伤害便立即反击一段。
3. 目标以凤三对阵者为距离中心，先找出其物理距离为1的人物，再过滤出凤三之敌。
4. 对阵者本人通常不属于“自己周围距离为1”的人物，因此通常不是目标。
5. 无来源伤害可以被防御。无来源的主要作用是反击、反弹等需要寻找攻击来源的能力找不到承受对象，所以不会把伤害反送给凤三。
6. 本能力写的是“伤害”，不是生命流失、一定造成或杀死，不得虚构穿透属性。

### D2. 非凤三阵营人物的递增校验

1. “该人物”指当前出战的非凤三阵营人物。
2. 输出记录属于该人物本局全部出战历史，不以对手阵营划分。该人物先与第三方作战形成的输出，也会成为以后对阵凤三阵营人物时的比较记录。
3. 该人物本局第一次出战、没有任何历史输出记录时，直接视为已经高于上回合，攻击与不利效果正常生效。
4. 有历史记录时必须严格高于；相等也不合格。
5. 未高于时，本回合攻击与不利效果无效，本回合实际输出记录为0。
6. 下一次出战因此与0比较；但不能把人物自然输出预设为固定400，所以不得直接写成固定的“400、0、400”循环。

### D3. 凤三阵营的输出保底

1. 凤三阵营人物有历史输出记录时，本回合目标值为上次实际输出记录加100。
2. 先尝试提高正常输出至目标值。普通数值防御造成的缺口可继续通过提高输出补足。
3. 如果闪避、无伤等机制使正常输出无论怎样提高仍无法兑现，则使敌方发生等于缺口的生命流失。
4. 生命流失作用于敌方，不是凤三阵营人物自损。
5. 生命流失不是输出。下一次使用的历史记录只保存本回合实际形成的正常输出，不把生命流失补足量计入输出。
6. 例如目标为1100，正常输出被完全阻断为0，敌方再发生1100生命流失，则本回合输出记录为0。
7. 敌方若无法发生生命流失，才构成悖论；悖论处理不是伤害，不能虚算为一定造成输出。

## F. 递归计算模型

### F1. 非凤三阵营人物攻击凤三阵营

定义：

- `X_t`：该人物第`t`次出战时，在垂天大星校验前的本回合待校验输出。
- `P_t`：该人物此前最近一次出战的实际输出记录。
- `V_t`：本回合通过校验后实际生效的输出。

无历史记录时：

`V_t = X_t`，并记录`P_(t+1) = X_t`。

有历史记录时：

`V_t = X_t`，当且仅当`X_t > P_t`；

`V_t = 0`，当`X_t ≤ P_t`，同时本回合攻击与不利效果无效。

每回合结束后：

`P_(t+1) = V_t`。

因此失败会把下一次门槛重置到0。凤三的期望承伤必须在获得人物输出分布后，用上述状态转移回归计算，不能用固定输出上限臆造周期。

### F2. 凤三阵营人物攻击敌方

定义：

- `B_t`：该人物本回合原本能够形成的正常输出。
- `P_t`：该人物此前最近一次出战的实际正常输出记录。
- `T_t = P_t + 100`：有历史记录时的目标输出。
- `O_t`：经过凤三提高与敌方防御后实际形成的正常输出。
- `L_t`：因正常输出无法达到目标而使敌方发生的生命流失。

有历史记录时，系统先争取实现：

`O_t ≥ T_t`。

若正常输出无法达到目标，则：

`L_t = T_t - O_t`。

但下一次的历史输出记录为：

`P_(t+1) = O_t`，

而不是`O_t + L_t`，因为生命流失不是输出。

没有历史记录时，不得把白人400自动写成首次记录；首次记录来自该人物第一次实际出战形成的输出。

## G. 同卡组合与冲突

- 凤三亲自出战时，基础四卡和垂天大星决定对阵者方向的正常输出；本回合承伤又决定行云布雨对侧面邻近敌人的条件输出。
- 行云布雨需要凤三实际受到伤害。敌方递增校验若使其攻击无效，凤三没有受到伤害，行云布雨本回合数值也为0。
- 敌方高输出通过递增校验后，会提高凤三承伤，同时放大行云布雨的侧面伤害；这是“正面承伤换侧面输出”，不是防御。
- 无来源只切断来源链，不切断目标自身防御。
- 悖论移出游戏是异常结算终止，不属于凤三的常态爆发。

## H. 物理结算链

### 常态链

1. 非凤三阵营人物出战，读取该人物本局最近一次出战输出记录。
2. 若没有记录，本回合直接通过递增校验；若有记录，则比较本回合待校验输出是否严格更高。
3. 未严格更高时，攻击与不利效果无效，输出记0。
4. 若凤三亲自出战且实际受到伤害，则累计本回合凤三受到的全部伤害。
5. 本回合伤害累计完成后，凤三对阵者周围距离1的合格敌人分别承受该累计值2倍的一次无来源伤害，各目标可以正常防御。

### 凤三阵营进攻链

1. 凤三阵营人物出战，读取该人物最近一次实际正常输出。
2. 有记录时建立`上次输出+100`的本回合目标。
3. 先提高正常输出并结算敌方防御。
4. 普通数值防御的缺口继续以提高输出来补。
5. 正常输出被完全阻断或仍无法达到目标时，敌方发生差额生命流失。
6. 下一次只记录实际正常输出，不记录生命流失。
7. 生命流失也无法发生时，进入悖论终止链。

### 失败或反制链

1. 凤三只有3333生命，没有减伤、闪避、免死或异常免疫。
2. 敌方第一次出战必然通过递增校验；稳定高输出人物也可能连续通过。
3. 敌方在其他阵营处形成的输出记录同样有效，可以改变之后攻击凤三阵营的门槛。
4. 行云布雨没有合格邻近敌人时没有输出；目标的防御仍可减少伤害。
5. 凤三在侧面受到指向侧面的攻击、波及、生命流失或其他效果时，没有独立硬防。

### 现实可达上限链

凤三阵营人物先形成较高正常输出记录，后续受到垂天大星持续保底；敌方用完全闪避等方式阻断正常输出时，缺口转为生命流失。与此同时，凤三亲自承受一次高伤后，行云布雨对对阵者两侧多个合格敌人分别造成两倍无来源伤害。这个上限依赖历史输出、敌方防御类型、凤三存活、座位与阵营分布，不能当成常态。
