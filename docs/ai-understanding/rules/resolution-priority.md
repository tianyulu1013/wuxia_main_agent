# AI 专项理解规则：特技结算优先级与嵌套限制

本机制模块仅服务于 AI 对五行卡牌中特技结算优先级（Priority）、响应（Response）、以及时间轴嵌套限制的分析。

## 1. 战斗与作战的“嵌套禁止原则”

为了保证时序逻辑的绝对干净，游戏严厉禁止战斗的无限嵌套：
1. **概念区分**：
   * **作战（Match / Event）**：是由流程或特技触发的一次两方或多方的对决“事件”（如普通单挑、擂台战、找人作战、逼战、袭击、偷袭、决战等）。
   * **战斗（Combat / Process）**：是作战事件内部五行卡暗摆、比拼和伤害计算的“流程”（包含 22 个时序阶段）。
2. **嵌套禁止**：除非卡面极其特殊地声明“可以”，否则**不能在战斗中插入一场新的战斗**，或者中止当前战斗并插入另一场战斗。
3. **特技与对决时点**：如果一个主动/被动特技已经开始结算（例如“袭击”或者“偷袭”作为特技正在生效），在它的中间和战斗前，均不能再嵌套插入任何其他的袭击/偷袭战斗。

## 2. 12层特技结算硬性优先级序列

当两个或多个卡牌效果在同一时点冲突、碰撞，或产生相互克制与豁免时，AI 必须严格按下述 12 层优先级顺序从高到低依次进行结算：

| 优先级层级 | 机制类型 | 结算逻辑与冲突判定原则 |
| :--- | :--- | :--- |
| **层 1 (最高)** | **特殊声明** | 卡牌上有极其明确的“凌驾于一切规则之上”的例外文案，以该例外为准。 |
| **层 2** | **场景重写** | 全局场景效果（如淝水、蝙蝠岛） vs 角色持有的“无视场景”特技。若无视场景的特技被关掉，场景重写立刻生效。 |
| **层 3** | **响应免疫** | “无法响应”、“不屑响应”、“不会受到响应”等强控制 vs “不会不响应” vs “不会受到影响”。 |
| **层 4** | **身份描述/身份特技** | **最根本属性层**（如卡牌血量旁的短句，或标注 `（身份）` 的特技）。它具有极高的抗性：**免疫一切关掉、看不见、失效或反弹效果**。但极特殊地，身份描述**会受到“混乱（混）”异常状态的影响**。 |
| **层 5** | **无视与看不见** | 结算“看不见（李沉舟、小马等）”或“无视三行后内容”效果，将其屏蔽，然后再计算后续特技。 |
| **层 6** | **破防判定** | 破除防御的特技判定，其优先级高，生效于任何“不中效果”或“豁免”之前。 |
| **层 7** | **反弹与不中** | 结算效果反弹、不中不利效果、化解、转化为其他效果的防御特技。 |
| **层 8** | **失灵判定** | 结算角色特技“失灵”以及“不会失灵”的对抗。 |
| **层 9** | **意志抗拒** | 结算“不敢用”、“不愿用”、“不能使用非被动” vs “一定能用”。 |
| **层 10** | **禁制类（清除/抹去）** | 结算屏蔽、抹去、打没特技的效果（如杨过的玄铁剑法、了空闭口禅）。这会使目标人物卡的特技直接被削减。不中禁制的特技在此免受影响。 |
| **层 11** | **使无效/限制** | 结算使某特技“无效”、“不能使用”（不减特技个数，只是使其无法放出）。 |
| **层 12 (最低)** | **正常特技结算** | 没有任何冲突修饰的常规特技效果。若双方在同级别冲突，遵循**“先出先用（先下手为强）”**原则（除非有“后发先至”声明）。 |

## 3. 主动打断与响应的区别

作者确认，带“后发先至”的打断不必然属于反制型响应。若牌面将其定义为人物可控制地主动发出的动作：

- 它可以打断写有“无法响应”的特技，因为发动者不是在用响应能力抵消该特技；
- 它可以打断身份特技的当前发动实例，因为打断不等于禁制、失灵、看不见或永久关闭身份特技；
- 它可以打断被动特技的一次触发，但不自动封禁该被动；以后再次满足触发条件时仍会再次触发；
- 是否能连续打断取决于打断能力自己的资源和次数上限。

浦饭幽助的灵丸属于此类主动打断：仅能作用于当前与其对阵的敌人，每回合最多消耗两发。

## 4. 响应的发动性质边界

作者确认，“响应”按特技或能力是否针对当前事件发生处理判断，不按发动性质判断：

- 主动、可控或被动特技都可能构成响应；
- 被动无敌等自动防御能力针对来袭攻击生效时，也算作响应；
- 单纯承受攻击或伤害不是响应；
- 主动打断是使用者主动攻击、停止或破坏对方的特技实例，仍按上一节处理，不因为它发生在对方动作之后就改称响应；
- 某能力写“若敌响应”时，只要敌方确实以特技或能力作出了响应，就满足后续条件；响应最终成功、失败、闪避、抵挡、转移或令原攻击无效，不自动撤销“已经响应”的事实。

法明的魔佛十式是该边界的校准案例：敌方被动无敌也会触发九击追加资格，但无敌本身仍可能令全部追加攻击无效。

## 5. 切入战斗的通用结算

作者确认，“切入”不是替换原战斗，也不是取消原参战者：

1. 原本两名人物继续完成彼此之间的正常战斗。
2. 切入者另放置自己的一套基础卡。
3. 切入者若选择攻击其中一方，只与该方的对应位置进行双向比对。
4. 切入者若选择攻击两方，则分别与两方的对应位置进行双向比对。
5. 被切入者对切入者的攻击、伤害和效果照常结算；切入不是只输出、不承伤的旁观攻击。
6. 同一位置对不同人物形成的克敌、被克和相平是不同实际比对结果，应分别记录。
7. 若切入者的同一特技在交手后对多名敌分别判定，并且作者确认这些判定同时发生，应先冻结共同的判定前状态，再分别掷出结果；其中一项结果造成的后续成长不追溯提高同一时点的其他判定。

薛笑人切入追杀是当前校准案例：攻击两方时八个实际比对均可分别记录克敌，杀手剑对两名敌同时、分别判定。
