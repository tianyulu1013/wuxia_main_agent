# 术语理解层（迁移中的历史说明）

> 术语层今后只保存特殊词义。本文件现有内容中混入的基础规则、评价方法和具体案例将逐步迁移，不再整份默认加载。当前路由见`docs/ai-understanding/README.md`。

本文件说明 `data/review/rule_terms.json` 的用途。

## 定位

规则书面向玩家，术语理解层面向 Agent。

很多术语可能尚未写入规则书，或在规则书中没有展开到足以支持 AI 评卡。此时应先记录在术语理解层，供评卡、改卡、新卡候选时检索。

术语理解层不是源数据库，不覆盖牌面、Excel 或 SQLite。

## 当前重点样例

### 基础战斗与主动特技放出模型

作者裁定：

- 正常情况下，两个没有特技的白人各放四张五行基础卡，前两张为内功，后两张为招式，四个位置与对手对应比较。
- 内功克敌时敌方损失 100，自己不损失；内功相平时双方均不损失；内功被克时自己损失 100。
- 招式克敌时敌方损失 300，自己不损失；招式相平时双方各损失 200；招式被克时自己损失 300。
- 每个人物持有金、木、水、火、土、同上、同第一、同第二各一张，共八张基础卡，从中排列组合出本次战斗使用的四张五行。
- 主动特技必须在其所属位置按牌面写明的放法摆卡。默认释放条件是：这组放法中的每一张卡都没有被克，并且其中至少一张克敌。只要其中一张被克，即使另一张克敌，也不能放出；牌面另有说明时才改变这个默认条件。
- 一个没有特技的白人，其每回合对敌输出期望正好为 400。正面作战型人物应先与这个零点比较。
- 单项输出提高、单项受伤削减和单项受伤反伤按每一次基础比较分别计算，不能先合并两张招式伤害后只处理一次。

评卡强制要求：

- 先按四张基础卡推演正常战斗，再评价人物特技。
- 看到“招式：段家剑：金土 100×5”时，只能确认最后两张招式放成金、土且满足默认释放条件时，才可产生 `100×5`；不能把它直接写成每回合稳定输出。
- 不得凭空假设敌方具有牌面没有出现的多段攻击、大招、破或其他伤害。
- 多项主动特技若占用相同位置，必须检查同一组四张卡能否同时满足；不能把所有主动特技伤害直接相加。
- 评估常态输出时，应区分基础四卡伤害、主动特技成功放出后的伤害，以及主动特技放不出的失败下限。

作者验算例：

```text
段正淳两张招式均相平：
两项基础输出为 200、200；
两项各提高 100，故输出 300+300=600；
两项受伤各削减 100，故受到 100+100=200；
两次受伤各反伤 100，故反伤 200；
护卫的 100 基础攻击享受输出提高，成为 200。
最终段正淳输出 600+200+200=1000，受到 200。
```

### 战斗人物功能分类与评卡基准

作者裁定：

- 评战斗人物前先判断人物的主要功能。
- 以自己出战和正面攻击为主的人物，以白人输出期望 400 为基础零点，继续计算合法牌形、主动特技放出期望、失败下限和预计存活回合。
- 主要靠结盟、地点、场景、派遣、关系或跨局状态影响全局的人物，不能只按正面输出衡量。
- 全局影响能力若需要其他玩家主动宣布或配合，应计算玩家是否愿意触发，而不是把所有理论对象都计为稳定收益。
- 防御能力若包含生命至 0 后不死、后续条件死亡、抽走敌方基础卡或概率回复，应换算为存活期望或预计出场回合，不只看牌面生命。

王重阳锚点：

- 四张均平时，两张招式攻击均可成为全真剑法 300，并由一炁化三清各变成 `300×3`，两项共 1800。
- 两平允许王重阳放出招式，再产生一个 `300×3`；四平总输出为 2700。
- 王重阳的每次普攻均可改为全真剑法，再由一炁化三清变为 900；这不仅包括招式处相平或克敌产生的普攻，也包括内功处克敌产生的普攻。
- 两个内功位各有 `1/5` 概率克敌并产生 900，期望为 `2×(1/5×900)=360`。
- 两个招式位各有 `1/5+3/5=4/5` 概率克敌或相平并产生 900，期望为 `2×(4/5×900)=1440`。
- 主动全真剑法要求两张招式均未被克且至少一张克敌，可放出的普通牌形为双克、一克一平、另一位置一克一平，共 `1+3+3=7` 种；先天功又允许两张均平的 9 种牌形放出。一克一被克不符合“放法中的每一张卡都没有被克”，不能释放。因此 25 种等概率招式对位中共有 16 种可以放出，期望为 `16/25×900=576`。
- 因此王重阳单轮输出期望为 `360+1440+576=2376`，约为 2400。
- 王重阳生命至 0 后还要下次被克才死亡；抽走对方两张基础卡后，若至少有一张不是“同”类卡，通常可确认对方缺少某个五行并安排自己不被克。
- 先天功有三分之一概率回复 300，回复后敌方需要重新将其打至 0。因此应按预计还能出战多少回合评价其防御。

### 大辈结盟与自愿触发

作者裁定：

- 段正淳【大理段二】不要求被宣布为父、母、养父或养母的人物实际存在于本局牌组或场上。
- 只要场上有人作出相应宣布，段正淳就可无视真实人物关系，宣布自己是该人的亲爹。
- 当前暂用“高顺位结盟”表述，其结果可以按段正淳高一顺位、对方相对低一顺位理解；作者尚未给出严谨的统一术语文本。
- 由于发动入口掌握在其他玩家的主动宣布中，实际触发率取决于参与者对当前局势和结盟结果的判断。

### 普通学会 / 完美学会 / 完美复制

作者裁定：

- 普通学会通常获得原特技文本本身。
- 如果原特技文本写有原人物名字，学习者不会自动把名字替换成自己。
- 完美学会/完美复制的关键，是解决这种原人物名绑定问题，使学习者/复制者可以作为实际受益人。

例：

```text
A 有特技：A 不会死。
B 普通学会后，文本仍然是“A 不会死”，通常 B 自己没有用。
B 完美学会后，受益人按 B 理解，B 可受益。
```

### 单局累积 / 累积 / 累计

作者裁定：

- 单局累积：只在本局游戏内一直累积计算，本局结束后不延续。
- 累积：通常需要跨局记录，可能写在本子或腾讯文档里，持续一段现实时间；当前习惯大致按上半年、下半年分段，但持续时间可调整。
- 累计：不同于累积，通常只是普通统计或合计计算，不自动表示跨局长期记录。

例：

```text
葵花老祖：交手者立即受伤*2（单局累积）。
这里每个交手者分别在本局内累计层数，不是所有交手者共享层数，也不跨局延续。
```

### 抢先攻击 / 抢先结算

作者裁定：

- 抢先攻击：只是一回合中先手攻击。若抢先攻击打死对方，对方就不攻击；但仍会被各种特技响应，也要计算对方防御能力等。
- 抢先结算：先计算这个人的所有内容，包括攻击、特技等；此时不看对方任何内容。若因此打死对方，对方即使有复活，也不能复活。
- 葵花宝典和葵花老祖的“优先结算修习者的一切”属于抢先结算，只是牌面写法不够清楚。

潜规则速度序列：

```text
葵花老祖 > 学葵花者 > 东方不败 > 其他抢先结算
```

其他抢先结算之间，如果双方都抢先结算，则双方都按没有抢先结算来正常计算。

### 【博】（兵器属性）

作者裁定：

- 人物出战时可随意声称自己持有一种任意兵器，且可以在回合中切换所持有的兵器。
- 若特技要求必须持有相关兵器（例如特技名后带括号标注兵器类别的，如“（剑）”、“（刀）”等），角色必须在战斗回合中持有该兵器才能使用该特技，否则在战斗回合中无法使用；而在侧面/后备席时可以任意切换兵器。
- 持有【博】的人物理论上可以在回合内动态声明并切换兵器以释放这些有兵器限制的特技。

### 围攻（玩家 vs 人物）

作者裁定：

- **围攻玩家**：参与围攻的多个对手玩家依次派人与被围攻的玩家进行 1v1 的车轮战（被围攻者期间无法休息或自动回满状态）。
- **围攻人物**：多个卡牌/人物同时出战，在同一场战斗中共同对敌。

### 神速

作者裁定：

- 神速是一名人物加入已经发生或将要发生的战斗，辅助其中一名原出战者，并与其叠加上场共同作战。
- 神速不是另开一场战斗，也不是两名人物各自放置一套基础卡；叠加者共用同一套五行卡，按叠加作战规则结算。
- 神速人物若有出战次数限制，此次参与会消耗一次；没有出战次数限制则无需额外记录。
- 是否需要被派遣人物同意、可以辅助谁及其他限制，由具体牌面决定，不能从“神速”二字自动推断。
- 神速不等于抢先攻击或抢先结算。

### 双特技自锁与协同（组合技白嫖机制）

作者裁定：

- 卡牌自有的多项特技在自身上可能通过被动自消解形成闭环协同（如自身特技的异常自损被自身的另一特技免负面完全消解）。这是故意设计的组合技特点。
- 当其他角色“复制”或“普通学会”拷贝其中单项能力时，因为失去免疫保护，拷贝者会直接承受副作用；反之，若原人物的两项特技发生自锁（内耗），他人如果只单独学走其中一项好用的，反而能发挥极大威力。

## 使用要求

当卡牌涉及以下词汇时，Agent 应检索术语理解层：

- 学会、学习、复制、模拟、获得特技。
- 完美学会、完美复制。
- 特技文本中出现原人物名。
- 特技所属、身份技、专属技、兵器条件与人物绑定。
- 单局累积、累积、累计。
- 抢先攻击、抢先结算、优先结算。
- 神速、叠加上场、辅助作战。
- 四张基础卡、内功、招式、主动特技放法、特技放出率与常态输出。

## 记录原则

- 作者明确解释后，状态可记为 `author_confirmed`。
- AI 推测不得写成已确认术语。
- 如果术语影响源数据结构或规则书正文，应先和作者确认，再进入规则书修订流程。
