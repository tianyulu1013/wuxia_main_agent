# 数据源基准原则

本项目当前阶段已经完成一次性旧日志同步。后续不再用旧更新日志反向覆盖当前数据。

## 当前权威顺序

1. 作者口头裁定。
2. 当前数据库与当前基准 Excel。
3. PSD 牌面，用于核对当前基准是否录错。
4. 旧更新日志，仅作为历史线索。
5. 未来更新日志，由数据库/Excel 的确认变更生成。

## 当前基准文件

- Excel：`outputs/2025-excel-sync-candidate/已制作_2025日志同步候选_PSD校准.xlsx`
- SQLite：`data/cards.sqlite`
- JSONL：`data/cards_current/all_cards.jsonl`

## 后续修改流程

1. 作者提出修改意见。
2. 基于当前数据库生成候选新版文本。
3. 作者确认。
4. 更新当前 Excel 和数据库。
5. 从确认后的变更生成对外更新日志。

## 禁止事项

- 不再批量扫描旧更新日志来覆盖当前数据库。
- 不把腾讯文档视为唯一源头。
- 不自动重命名 PSD 文件。
