# 梅念笙：正面输出

## 1. 横向主样本

采用以下统一口径：

1. 一名无能力、无防御、按均匀五行盲选的对手；
2. 梅念笙在两个招式位放置木、火；根据实际平克结果自动进入连城剑、梅花拳或混克空档；
3. 不计目标生命上限截断；
4. 白人单回合最高基础伤害不足以击杀2800生命，故梅念笙能活到延后攻击；
5. 成功放出的连城剑法或梅花拳全部指向当前对阵者。

## 2. 每个位置的随机结果

两个内功位各有三种结果：

| 结果 | 概率 | 梅念笙基础输出 | 敌方击中次数 |
|---|---:|---:|---:|
| 梅念笙克敌 | 1/5 | 100 | 0 |
| 相平 | 3/5 | 0 | 0 |
| 梅念笙被克 | 1/5 | 0 | 1 |

两个招式位固定为木、火，每个位置：

| 结果 | 概率 | 梅念笙基础输出 | 敌方击中次数 | 该位置允许连城剑法 |
|---|---:|---:|---:|---|
| 梅念笙克敌 | 1/5 | 300 | 0 | 否 |
| 相平 | 3/5 | 200 | 1 | 是 |
| 梅念笙被克 | 1/5 | 0 | 1 | 是 |

设：

- `B`为梅念笙四张基础卡最终造成的普通输出；
- `R`为两个招式位均未克敌、进入连城剑分支的指示量；
- `F`为至少一个招式位克敌且两个位置均未被克、进入梅花拳分支的指示量；
- `N`为梅念笙第一次攻击前受到的敌方击中总数。

连城剑法输出为：

`L=500NR`

梅花拳输出为：

`M=500F`

`R`与`F`互斥。总输出为：

`O=B+500NR+500F`

## 3. 期望

基础四卡仍有：

`E[B]=400`

连城剑法放出概率：

`P(R=1)=(4/5)^2=16/25=64%`

在`R=1`的条件下，两个招式位都必然形成一次敌方击中；两个内功位各以`1/5`再增加一次。因此：

`N|R=1=2+Bernoulli(1/5)+Bernoulli(1/5)`

`E[N|R=1]=2.4`

于是：

`E[L]=P(R=1)×500×2.4=768`

梅花拳要求至少一个位置克敌且没有位置被克：

`P(F=1)=(4/5)^2-(3/5)^2=7/25=28%`

`E[M]=500×7/25=140`

剩余8%是一张克敌、一张被克的混克空档，两项主动特技均不能放出。

所以综合期望为：

`E[O]=400+768+140=1308`

加入本卡后，当前19张精评人物正面输出均值为1458.51。梅念笙盲打主值仍略低于均值，但已经不是此前漏算梅花拳后得到的1168。

## 4. 三条路线的条件结果

普攻不能脱离路线单独使用无条件400解释。精确条件分布为：

| 路线 | 概率 | 条件总输出期望 | 条件标准差 | 物理原因 |
|---|---:|---:|---:|---|
| 连城剑 | 64% | 1540 | 300.33 | 两张招式均未克敌；相平保留200普攻，被克无普攻，同时所有敌方击中加深五段剑法 |
| 梅花拳 | 28% | 1054.29 | 66.52 | 至少一张克敌且没有被克；克敌与相平使招式普攻较高，另加五次100 |
| 混克空档 | 8% | 340 | 56.57 | 一张克敌、一张被克；只有一项300招式普攻，两项主动均关闭 |

这正是混克可能成为对手主要压制策略的原因：它同时避开梅花拳和连城剑，只留下单项克敌普攻及内功小额输出。

## 5. 方差与离散分布

对两个内功位和两个招式位的三结果进行`3^4=81`种精确枚举，并按相同输出合并：

| 输出 | 概率 |
|---:|---:|
| 300 | 0.0512 |
| 400 | 0.0256 |
| 500 | 0.0032 |
| 1000 | 0.1680 |
| 1100 | 0.1120 |
| 1200 | 0.1104 |
| 1300 | 0.0592 |
| 1400 | 0.1392 |
| 1500 | 0.0960 |
| 1600 | 0.0176 |
| 1700 | 0.0576 |
| 1800 | 0.0192 |
| 1900 | 0.0864 |
| 2000 | 0.0304 |
| 2200 | 0.0096 |

由此：

- `E[O]=1308`
- `E[O²]=1,897,520`
- `Var(O)=186,656`
- `SD(O)=432.0370`
- 变异系数`=432.0370/1308=0.3303`
- 范围为300至2400

最低值不是0：混克空档至少保留一项300招式普攻；连城剑成功时两个招式位至少提供两次受击；梅花拳成功时又必有克敌普攻。

## 6. 自身击中次数

防御前无闪避环境中：

- 基础四卡平均形成2次击中；
- 连城剑法以64%概率形成5次击中，期望3.2次；
- 梅花拳以28%概率形成5次击中，期望1.4次；
- 合计平均击中次数为`2+3.2+1.4=6.6`。

精确枚举得到击中次数方差2.96、标准差1.7205。该值已写入独立横表`comparison/front-hit-count.json`，用于以后估算依赖“受到攻击／击中次数”的人物。

## 7. 身份暴露后的无穷博弈边界

1308是木火牌形在均匀盲选下综合三条分支的统计期望。身份暴露后的针对选择可以不断反制：

- 对手可追求一克一被克的混克空档；
- 为防梅念笙转换其他`木-`梅花拳牌形，对手又可能采用金金，克制木并让火克敌；
- 梅念笙还可改放火火追求普攻，或转换其他梅花拳放法；
- 双方策略继续循环，没有稳定、唯一且可从牌面直接推出的最优终点。

因此横向统计采用完整盲打期望1308，不伪造所谓最优博弈均衡。混克、金金、其他`木-`和火火只作为现实策略分支解释。

## 8. 单独使用其他`木-`牌形

梅花拳不受铁骨墨萼影响，按普通两卡主动规则放出。均匀五行下：

`P(放出)=7/25=28%`

其五次100合计500，因此：

`E[梅花拳额外输出]=500×7/25=140`

若梅念笙放弃木火双重威胁，改用其他`木-`牌形单独博弈梅花拳，则无条件参考仍为：

`E[梅花拳路线]=400+140=540`

这个540只是不含连城剑的独立牌形盲打参考，不参与木火综合主值1308；实战转换牌形的价值在于破坏对手针对木火设计的放卡，而不是固定获得540。

## 9. 穿透

基础攻击、连城剑法和梅花拳都没有“一定造成”“破”或“无视防御”：

- 严格一定造成期望：0；
- 实战穿透输出主值：0；
- 穿透率：0。

五连击会消耗按次数限制的闪避或抵挡资源，对部分防御具有段数压力，但不能据此把任何固定点数登记为穿透。

## 10. 截断与适用边界

- 单个白人最高只能造成800基础伤害，不会在延后攻击前击杀2800生命，因此主样本无需死亡截断。
- 面对当前约1400平均输出人物或多人偷袭时，首次高爆发可能在梅念笙攻击前将其击杀；真实输出会低于无截断模型。
- 抵挡和无敌不会减少连城剑法的受击层数，因为攻击已经击中；闪避会减少。
- 多敌模型不并入1308主值，详见`side-output.md`。
- 身份暴露后的策略可以无限递进；1308是完整木火盲打统计，不代表知情博弈均衡。
