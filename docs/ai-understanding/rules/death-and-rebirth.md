# 专项规则：死亡与基础重生

状态：作者确认。

## 基础重生

牌面只写“重生”而没有另写恢复数值或保留状态时：

1. 人物先发生死亡；
2. 人物以初始满生命复活；
3. 清除人物当前全部有利与不利状态；
4. 造成上一条生命死亡的攻击或效果已经终止，溢出伤害不继续作用于重生后的生命。

## 上位结果

- 普通“杀死”仍然是死亡，可以触发基础重生。
- “彻底死亡／彻底杀死”明确禁止重生。
- 清除不是死亡，不能触发重生。
- 卡牌另写重生生命、次数、历史记录保留或状态保留时，以专属文本和作者裁定为准。

## 案例

- 浦饭幽助第一次死亡后，以初始3000满生命重生，清除全部有利与不利；此后灵丸总量无限。
- 丁典的“入神坐照”不是普通“重生”文字，而是单独身份机制；其神照经实例历史按作者特例跨复活保留。
