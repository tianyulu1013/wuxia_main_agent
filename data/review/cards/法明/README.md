# 法明评价摘要

状态：作者核心语义、首轮输出模型与完整维度已完成；环境回归开放。

法明是**响应威慑型正面人物**。魔佛十式不需要放卡，每回合只能使用一次：无响应对阵者只承受1000大招攻击并中狂；一旦以特技或能力响应，法明可以向同一对阵者追加900至100的九击。被动无敌等防御能力也算响应，普通承伤不算，主动打断另属打断。

横向正面主样本采用无能力、无防御且不响应的对阵者：基础四卡期望400，加魔佛十式1000，合计期望1400、标准差149.67、范围1000至1800，穿透0。若敌响应并且只统计法明发出的名义攻击，总量改为基础四卡加5500，条件期望5900；但响应本身可能是无敌、闪避、抵挡或转移，5900不能冒充实际造成伤害。

不碎金刚占用四个卡位，四卡全部结算后统计全部位置：克敌数严格多于被克数时放出。均匀盲打放出率34.4%。无敌持续到未来某回合法明内功被克的回合结束；若该回合又放出不碎金刚则刚好续上。简化长期模型中，法明在回合开始时处于无敌的稳态比例约51.19%，但首次放出发生在四卡结算完毕后，不能保护本回合此前伤害。

【僧王】令所有非【恶】佛门人物分别与法明结盟。全场任一人类以非死亡方式离场后，法明在该回合结束时永久转为不在场且不能出战；他没有死亡或离场，但此后也不能再使用需要在场的能力。
