# 一灯：正面输出

> 本文件由已校准完整工作卡按章节机械拆分，不新增或改写结论。旧完整归档：`data/review/workcards/batch_018_164_一灯.md`。

## F. 白人盲打输出模型

### F1. 假设与变量

这是统一回归基线，不是全库人物平均，也不是双方真实最优博弈：

- 敌方四个位置独立、五行均匀。
- 一灯预先选择一个合法一阳指放法；固定选`土-`或`火-`在均匀模型下对称。
- 不计真实人物大招、防御、资源消耗与读牌。
- 内功位：克敌输出100，其余0。
- 招式位：克敌输出300，相平输出200，被克输出0。

记：

- `S`：一灯四位置常规原输出；
- `E`：敌方四位置常规原输出；
- `C`：一阳指两个招式位都未被克，因此合法放出；
- `Y=1_C(S+E)`：一阳指追加攻击；
- `O=S+Y`：未受伤时攻击当前对阵者的总名义输出。

### F2. 放出率与条件输出

每个招式位不被克的概率为`4/5`：

`P(C)=(4/5)^2=16/25=64%`

无条件：

`E[S]=400`

在`C`发生的条件下：

- 一灯两个内功位期望合计40；
- 一灯两个招式位期望合计450；
- 敌方两个内功位期望合计40；
- 敌方两个招式位期望合计300。

所以：

`E[S+E | C]=40+450+40+300=830`

一阳指追加伤害期望：

`E[Y]=0.64×830=531.2`

未受伤正面总输出：

`E[O]=400+531.2=931.2`

### F4. 受伤后的渔樵耕读分支

渔樵耕读固定增加400，且不进入一阳指原输出总和：

`O_受伤=400+S+Y`

- 期望：1331.2
- 方差：280,482.56
- 标准差：约529.61
- 变异系数：约39.79%
- 范围：400至2000

固定平移不改变方差；它降低相对波动，但没有提高一阳指放出率。

### F5. 穿透

只有攻击当前对阵者的一阳指伤害一定造成：

- 未受伤路线中，期望确定穿透输出为531.2，占期望总名义输出`531.2÷931.2≈57.04%`。
- 受伤路线中，期望确定穿透输出仍为531.2，占期望总名义输出`531.2÷1331.2≈39.90%`。
- 渔樵耕读400和常规原输出均可正常防御。
- “点”不属于确定命中部分。

因此，高防御人物在白人盲打模型下平均仍需面对531.2点不能由普通防御消除的伤害；57.04%与39.90%只是该确定穿透量在两条总输出路线中的期望构成比例，不代表每个实际回合都固定穿透该百分比。

一阳指有36%概率没有成功放出，所以单回合确定穿透分布并非固定531.2，而是：

| 确定穿透输出 | 概率 |
|---:|---:|
| 0 | 36.00% |
| 600 | 1.44% |
| 700 | 10.56% |
| 800 | 25.12% |
| 900 | 21.12% |
| 1000 | 5.76% |

其期望531.2、方差164,194.56、标准差约405.21、范围0至1000。攻击侧面人物时这份伤害不再一定造成，故侧面确定穿透量为0。

### F6. 侧面目标输出

一灯正面出战时可让一阳指攻击一名侧面人物：

- 当前对阵者仍承受常规原输出，期望400；受伤时再加渔樵耕读400。
- 侧面目标承受一阳指期望531.2。
- 侧面一阳指不是一定造成，可正常防御。
- 两项输出共享同一回合和同一组基础牌，不能把“正面931.2”再与“侧面531.2”相加。

一灯本人不出战时没有场下自动输出。

### F7. 决策博弈边界

白人64%只是均匀盲打基线。实际双方都可选择基础牌，需另做策略博弈。

只看“一阳指能否放出”而不看完整伤害收益时，一灯可在土、火两个首位选择间混合，第二个任意位也可分散选择；针对者能压低放出率。一个粗略的纯放出率下界参考约为`1/2×4/5=40%`，但这不是完整纳什输出，因为敌方为阻止一阳指而改变的牌，也会改变双方常规原输出。后续只在需要研究针对环境时建立完整收益矩阵。

## G. 点化概率参考

在双方固定出牌、敌方四位置独立五行均匀的白人参考中，每个位置发生任一方向相克的概率为`2/5`，相平概率为`3/5`。

正好三个位置相克：

`P=4×(2/5)^3×(3/5)=96/625=15.36%`

这是随机参考，不是实战固定触发率。玩家选牌、读牌和为一阳指选择放法都会同时改变点化概率与输出。
