# 战斗人物功能：辅助与调度

加载条件：战斗人物主要通过帮助队友、派遣人物、代战、叠加出战、转移资源或改变参战者产生价值。

## 评价问题

- 帮助发生在摸牌、选人、选择敌人、出战还是战斗结算中。
- 由谁决定发动，是否需要被帮助者同意。
- 帮助的是人物、玩家还是一方。
- 是否让另一人物加入同一战斗、替代原人物或另开战斗。
- 是否消耗出战次数、人物位置、基础卡、次数或其他资源。
- 派出后原持有者是否同步失去对应能力。
- 一局中可帮助多少次、多少人。
- 对弱队友和强队友的放大程度是否不同。
- 本人正面作战不足是否由稳定辅助价值补偿。

不得把可以产生的最佳组合当作常态；必须计算目标可用率、发动权和实际战斗循环。
