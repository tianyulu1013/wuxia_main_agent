# 丁春秋评价摘要

状态：本轮精评完成；作者核心语义、定量模型与全部证据维度已整理，真实玩家喊话、尸体环境和移除不利环境继续开放回归。

当前定位：

- 主要功能：异常、类别禁制与持续削弱。
- 次要功能：正面双大招、尸体链爆发、隐藏死亡计数、跨战斗单人辅助／削弱。
- 保底功能：2500生命与白人基础四卡。

当前已确认：

- 化功大法与星宿火分别占内功区、招式区，可同回合放出。
- 禁内／禁招是标准异常；禁制内功／招式是另一层类别禁制。正面命中时均不追溯本回合，从本回合结束开始持续到目标下一回合结束；其中卡位限制在场下通常没有即时影响。
- 法螺功分号前后是两个独立分支；他方人类可通过真实喊话令丁春秋无敌，丁春秋自己喊话则无视大招标准放出结果，按已摆组合施放大招。
- 连环腐尸毒以尸体或队友彻底死亡为资源；500附加伤害可防御并附加标准毒，只有该伤害杀死人并继续使用新尸体时才翻倍。
- 三笑逍遥散是非标准异常的“毒”类负面状态；目标累计三张基础卡克敌后死亡。
- 星宿老仙在丁春秋一次上场开始至下一次上场前，可令另一人物实际受伤加倍或无敌。
- 星宿老仙与法螺功可以形成交换式谈判：丁春秋给他方无敌，换取符合条件的他方人类高喊使丁春秋无敌；配合自身高喊的稳定强攻威胁，可将一次战斗近似中和。丁春秋给出的无敌有次数和区间缝隙，他方喊话覆盖更灵活，不能按永久无缝互保计算。
- 虚竹只能在与丁春秋对战时直接施放生死符；免除大招标准放出条件，但不破无敌。
- 星宿火没有自然终止条件：每回合产生300并重新附加一层毒；标准毒不累积，支付200只彻底免除当时的毒，下一回合仍会被重新附加；移除星宿火这项不利才停止循环。

## 总分析

丁春秋能固定摆出土火／木火并通过自喊无视平克结果，同回合稳定放出化功大法与星宿火。当前正面名义输出期望1100、标准差149.67；目标下一回合四个基础卡位全空，同时禁制内功和招式类大招。星宿火还会无期限每回合造成300并重新附毒，支付200只能解决当时毒层，不能根治持续来源。

连环腐尸毒拥有指数上限，但每一环必须实际杀死目标并消耗新尸体，不能当作常态爆发。三笑逍遥散平均使用2次、留下1名未被发现的长期目标；未被发现白人目标约4.1247个自身战斗回合累计三克，但单次施毒纳入发现分支后的最终致死率只有51.36%，不等于稳定杀死两人。星宿老仙可以在两次上场之间令任意阵营另一人物无敌或实际受伤加倍，使其全局影响暂评强。

主要弱点是2500生命且没有自控硬防。法螺无敌必须由其他阵营人类及其玩家真实喊话，不能纳入稳定生存；但丁春秋能用自身高喊后的稳定强攻和星宿老仙给他方无敌作为交换筹码，争取双方无敌并近似减少一次战斗。多人混战中减少暴露次数是优势；双人局没有第三方消耗，若双方都愿意持续互保，就会导向和局，变量是双方意愿。双方覆盖窗口仍不对称，不能假设未经协商即可无限持续。因此丁春秋是“控制、持续压迫和政治上限很强，但本人脆弱且执行负担极高”的人物。
