# 单卡逻辑解构与机制校准标准作业程序 (SOP)

> 历史兼容文档。当前规范以`docs/skills/wuxia-card-calibration-sop.md`、`.agents/skills/wuxia-card-review-calibration/SKILL.md`和`data/review/cards/README.md`为准。下文所称单篇`card_notes/<卡名>.md`已被“每人物一目录、各维度分文件、README总摘要”结构取代，不得再作为新评审写入模板。

本规范为 **《五行卡牌》** 项目中每一位人物卡牌进行深度解构、人机校准及文档化归档的最高指导流程。为了防止 AI 产生公式懒惰、概念脑补与数据格式不一致，任何人（包括 AI）对单卡的研究与记录均必须**严格遵循此标准流程及规定的十级大纲模块**。

---

## Ⅰ. 单人卡牌研究与对齐三大物理阶段

在开始研究任何新人物卡前，必须严格划分物理研究阶段：

### 阶段一：纯定性质检与汇报 (Qualitative Alignment Phase - 严禁越界计算)
1. **基础事实检索**：AI 从 SQLite 数据库及 JSONL 源数据中读取该卡的生命、兵器与特技文本。
2. **定性条目汇报**：AI **逐条**列出特技在规则层面的定性理解（具体内容见下文大纲 Ⅱ）。
3. **暂停并等待确认**：**AI 必须在此处截断 turn，将定性报告提交给作者口头审查。在此阶段，AI 严禁打出任何期望数字、存活回合或博弈矩阵，违者直接判定为计算无效。**

### 阶段二：严格定量计算 (Quantitative Calculation Phase)
* 只有在阶段一获得作者“完全正确”或修正后的口头裁决后，AI 方可开启数学计算。
* AI 必须按照概率公式与条件期望方程，计算出不同对局策略下的精确期望，并列出参数假设。

### 阶段三：归档至单卡笔记与对账表 (Documentation Phase)
* 将阶段一和阶段二的研究成果，严格套用下文的**“十级单卡笔记标准大纲”**，在 `data/review/card_notes/<卡名>.md` 中生成独立的、无简化的归档笔记。
* 将五个核心对账维度（正面攻击期望、穿透率、正面存活回合数、侧面防御、侧面输出）登记至 `data/review/calibrated_stats.json`。

## Ⅱ. 十级单卡笔记标准大纲 (Standard Markdown Template)

每一位人物的 `data/review/card_notes/<卡名>.md` 必须完整、无简化地包含以下十个部分：

```markdown
# 单卡评审与机制校准笔记：[卡牌名称]

## 1. 事实与来源 (Card Facts)
* **卡牌名称**：[姓名]
* **卡牌分类**：combat_characters / items / support_characters 等
* **基础属性**：生命 [值]，武器 [【金/木/水/火/土】属性或无]
* **原版特技文本**：[直接复制 SQLite 数据库中的 description 原文，不得改写]

## 2. 作者校准完整记录 (Author Calibration Logs)
* [逐条记录作者在对话中做出的所有口头裁定、习惯用语纠偏及规则解答原文]

## 3. 主要、次要与保底功能定位 (Functional Profiling)
* **正面作战定位**：[例如：正面爆发输出手 / 被动防反物理盾]
* **辅助与干扰定位**：[例如：通过距离1调节邻近队友名义攻击力 / 抽走手牌控制敌方牌池 / 结盟改变阵营 / 医疗复原队友]
* **全局/规则更改定位**：[例如：强制修改全场比拼递增规则 / 触发无限循环时移除悖论源卡牌的规则裁判权 / 全场异常状态免疫环境]
* **保底功能**：[例如：败阵后的残留全场伤 / 固有护卫队的基础攻击]

## 4. 逐技事实判定表 (Technique Facts Table)
| 特技名称 | 生效位置与时序 | 伤害属性/效果 | 机制详情 |
| :--- | :--- | :--- | :--- |
| [特技名] | [例如：正面出战比拼阶段 / 场下常驻被动] | [常规伤害/一定造成/生命流失/无伤害/重置/不利移除] | [主语语义“自身”指谁，该特技的判定边界，与哪些位置产生冲突] |

## 5. 常态、失败与上限结算链 (Resolution Chains)
* **常态对局链**：[常规无大招/平手状态下的出牌与结算流]
* **大招失败与被拦截链**：[如果核心特技被克制或拦截，人物如何结算，伤害与承伤如何流转]
* **上限/爆发结算链**：[特技完美触发、反读敌方针对时的最高收益流转]

## 6. 正面战斗防御与生存精细评估 (Frontline Survival & Defense)
* **正面防线评级**：[防反盾 / 全局较肉 / 绝对免死 / 脆弱脆皮]
* **不同承伤额度下的存活回合数模拟**：
  * 面对 400 点名义输出者：[期望存活回合数与计算过程]
  * 面对 600 点名义输出者：[期望存活回合数与计算过程]
  * 面对 800 点名义输出者：[期望存活回合数与计算过程]
  * 面对 1000 点名义输出者：[期望存活回合数与计算过程]
* **物理避伤天敌与漏洞**：[对一定造成、生命流失、破防、持续性压制的抵抗情况]

## 7. 侧面挂机与侧面打击生存评估 (Sideline Survival & Off-field Targeting)
* **侧面防御特权**：[当一灯/邀月等身处场下挂机（非出战）时，受波及、濺射伤害的防御表现。其免伤/折半/反射被动是否在场下生效？]
* **跨界侧面输出**：[出战时，其大招或特技是否能隔空打击敌方侧面（场下）人物？该打击是否附带穿透属性？]

## 8. 严格条件期望输出演算过程 (Rigorous Output Expectation Calculation)
* **基础参数假设**：
  * **敌方招式名义输出** $A_{敌，招式}$ = [设定值，例如 600]
  * **双方内功名义输出** $A_{内功}$ = [设定值，例如 40]
* **推演全过程（公式书写）**：
  * [写出事件 C (大招放成功) 的概率与条件。手牌统一为 8 张专属卡全开决策模型。]
  * [写出事件 C 下一灯/邀月的条件期望 $E[x_{self} | C]$ 及敌方的条件期望 $E[x_{opp} | C]$。]
  * [写出大招被克拦截分支下的期望计算。]
  * [计算全概率空间加权总期望公式。]
* **未受伤状态下的输出期望**：$E[\text{未受伤}] = $ [公式与计算值]
* **已受伤状态下的输出期望**：$E[\text{已受伤}] = $ [公式与计算值]
* **无攻击力/被禁制封印期的输出期望**：[计算值]

## 9. 决策博弈与战场生态 (Battlefield Dynamics / Nash Matrix)
* **适用条件判定**：**仅当卡牌具有明确的招式位策略分支**（如一灯打出一阳指【土火】与改打【金土】反制针对防守）时，方可撰写纳什博弈矩阵。对于无策略分支或被动卡牌，**严禁硬塞或伪造敌我双方的策略选项（如伪造“保守输出200”等非规则出牌）**，统一标注为“**不适用**”并转为分析多人局战场生态。
* **博弈矩阵模版 (仅在适用时填写)**：
  * **己方策略**：$A_1$ (明牌强攻), $A_2$ (反制暗算)
  * **敌方策略**：$B_1$ (盲打随机), $B_2$ (针对防守)
  * 组合 $(A_1, B_1) = (\text{我输出伤害}, \text{我净血量受伤})$ —— 详细计算步骤
  * 组合 $(A_1, B_2) = (\text{我输出伤害}, \text{我净血量受伤})$ —— 详细计算步骤
  * 组合 $(A_2, B_1) = (\text{我输出伤害}, \text{我净血量受伤})$ —— 详细计算步骤
  * 组合 $(A_2, B_2) = (\text{我输出伤害}, \text{我净血量受伤})$ —— 详细计算步骤

## 10. 穿透率分析与漏洞评估 (Penetration Rate Analysis)
* **穿透模式**：[一定造成 / 破防 / 生命流失 / 无穿透]
* **不同分支下的穿透占比计算**：
  * 未受伤强攻轮：[穿透伤害占总伤害的比例与计算过程]
  * 已受伤强攻轮：[穿透伤害占总伤害的比例与计算过程]
  * 侧面攻击轮：[穿透伤害占总伤害的比例与计算过程]
```
