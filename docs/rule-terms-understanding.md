# 术语理解层

本文件说明 `data/review/rule_terms.json` 的用途。

## 定位

规则书面向玩家，术语理解层面向 Agent。

很多术语可能尚未写入规则书，或在规则书中没有展开到足以支持 AI 评卡。此时应先记录在术语理解层，供评卡、改卡、新卡候选时检索。

术语理解层不是源数据库，不覆盖牌面、Excel 或 SQLite。

## 当前重点样例

### 普通学会 / 完美学会 / 完美复制

作者裁定：

- 普通学会通常获得原特技文本本身。
- 如果原特技文本写有原人物名字，学习者不会自动把名字替换成自己。
- 完美学会/完美复制的关键，是解决这种原人物名绑定问题，使学习者/复制者可以作为实际受益人。

例：

```text
A 有特技：A 不会死。
B 普通学会后，文本仍然是“A 不会死”，通常 B 自己没有用。
B 完美学会后，受益人按 B 理解，B 可受益。
```

### 单局累积 / 累积 / 累计

作者裁定：

- 单局累积：只在本局游戏内一直累积计算，本局结束后不延续。
- 累积：通常需要跨局记录，可能写在本子或腾讯文档里，持续一段现实时间；当前习惯大致按上半年、下半年分段，但持续时间可调整。
- 累计：不同于累积，通常只是普通统计或合计计算，不自动表示跨局长期记录。

例：

```text
葵花老祖：交手者立即受伤*2（单局累积）。
这里每个交手者分别在本局内累计层数，不是所有交手者共享层数，也不跨局延续。
```

### 抢先攻击 / 抢先结算

作者裁定：

- 抢先攻击：只是一回合中先手攻击。若抢先攻击打死对方，对方就不攻击；但仍会被各种特技响应，也要计算对方防御能力等。
- 抢先结算：先计算这个人的所有内容，包括攻击、特技等；此时不看对方任何内容。若因此打死对方，对方即使有复活，也不能复活。
- 葵花宝典和葵花老祖的“优先结算修习者的一切”属于抢先结算，只是牌面写法不够清楚。

潜规则速度序列：

```text
葵花老祖 > 学葵花者 > 东方不败 > 其他抢先结算
```

其他抢先结算之间，如果双方都抢先结算，则双方都按没有抢先结算来正常计算。

### 【博】（兵器属性）

作者裁定：

- 人物出战时可随意声称自己持有一种任意兵器，且可以在回合中切换所持有的兵器。
- 若特技要求必须持有相关兵器（例如特技名后带括号标注兵器类别的，如“（剑）”、“（刀）”等），角色必须在战斗回合中持有该兵器才能使用该特技，否则在战斗回合中无法使用；而在侧面/后备席时可以任意切换兵器。
- 持有【博】的人物理论上可以在回合内动态声明并切换兵器以释放这些有兵器限制的特技。

### 围攻（玩家 vs 人物）

作者裁定：

- **围攻玩家**：参与围攻的多个对手玩家依次派人与被围攻的玩家进行 1v1 的车轮战（被围攻者期间无法休息或自动回满状态）。
- **围攻人物**：多个卡牌/人物同时出战，在同一场战斗中共同对敌。

### 双特技自锁与协同（组合技白嫖机制）

作者裁定：

- 卡牌自有的多项特技在自身上可能通过被动自消解形成闭环协同（如自身特技的异常自损被自身的另一特技免负面完全消解）。这是故意设计的组合技特点。
- 当其他角色“复制”或“普通学会”拷贝其中单项能力时，因为失去免疫保护，拷贝者会直接承受副作用；反之，若原人物的两项特技发生自锁（内耗），他人如果只单独学走其中一项好用的，反而能发挥极大威力。

### 郭靖生存评估锚点

作者校准：

- 郭靖的正面生存为“强”，不是“极强”。
- 郭靖的侧面生存为“一般”。
- 九阴真经对异常有很好的后续处理，但防异常不能等同于全面侧面生存；侧面生存还必须检查场下攻击、波及、远程指定、生命流失和杀死。

## 使用要求

当卡牌涉及以下词汇时，Agent 应检索术语理解层：

- 学会、学习、复制、模拟、获得特技。
- 完美学会、完美复制。
- 特技文本中出现原人物名。
- 特技所属、身份技、专属技、兵器条件与人物绑定。
- 单局累积、累积、累计。
- 抢先攻击、抢先结算、优先结算。

## 记录原则

- 作者明确解释后，状态可记为 `author_confirmed`。
- AI 推测不得写成已确认术语。
- 如果术语影响源数据结构或规则书正文，应先和作者确认，再进入规则书修订流程。
