## C. 物理结算链

### 常态链

1. **出战对决**：心剑神尼出战。
2. **触发奴役标记**：心剑神尼在交手时受到对方侧面攻击，或被对方施加了异常状态。
3. **标记主人**：该敌方人物被系统标记为心剑神尼的“主人”。注意，心剑神尼的阵营/控制权**不会易手**给对方，依然属于己方玩家控制。
4. **特技受限与不死触发**：心剑神尼的 `大威天龙` 特技伤害翻倍为 600，但由于限制“尽量不对主人使用特技”，她无法用 `大威天龙` 轰炸这些被标记为主人的人。但只要这些主人仍在场上，心剑神尼即使生命值降至 0 也绝不死亡。
5. **铁拳制裁**：心剑神尼凭借 0 生命的不死金身，使用普通攻击（物理平砍）一刀一刀地将被标记为主人的人全部砍死。

### 失败或反制链

1. **敌方主动退场**：敌方被标记为“主人”的人物眼见不妙，通过主动退场、独立或被队友清除等方式离开交战席。
2. **金身破灭**：一旦场上所有被标记的“主人”全部离场，心剑神尼的 0 生命免死壁垒瞬间瓦解，当场暴毙。

### 上限链

1. **全场均是主人**：心剑神尼与多名敌方角色交手，通过侧击和异常将所有敌人全部标记为自己的主人。
2. **不灭拳王**：心剑神尼锁死在绝对不死状态，且己方不需要提供任何防死护航，仅靠基础普通攻击打满全场，将所有敌人逐一清扫。

## D. 初始评价

- 核心玩法循环：极其强悍的“碰瓷不灭”战术卡。通过挨打、中异常或被侧击，将对方强制绑定为自己的“主人”以白嫖 0 生命不死特权；同时由于自身控制权并不易手，仅是主动特技（大威天龙）不能对主人使用，她完全可以靠不灭之身使用普通攻击将所有主人活活耗死。
- 常态表现：很强。4000 生命，配合大威天龙 300 点出场伤害。
- 上限：极强（全场敌人均成为主人，自身达成绝对物理平砍不死金身）。
- 下限：中等（若敌方不使用异常或侧击，且心剑神尼没有战败，则不触发不死机制）。
- 正面/侧面生存，或宿主收益/负担：正面生存极强（极易通过受击白嫖不死）；对己方阵容没有任何控制流失负担。
- 初始评分与置信度：强度 81，泛用性 72，置信度：高。
- 横向参照卡及差异：林月如（林月如 72 分，属于一次性团队挡枪；心剑神尼强在通过标记主人锁定个人不死金身，强度显著高出一档）。

## E. 反证审计

- 最可能高估的能力：大威天龙的双倍爆发。因为面对主人时无法使用特技，600 点双倍伤害通常只能用于轰炸未标记为主人的其他敌人，对被标记的直接对手只能依靠普通攻击。
- 最可能低估的能力：控制权并未易手这一底层事实。这使得她从“投敌娱乐卡”一跃成为“碰瓷不死的战术核心”。
- 审计后的评分变化：由于纠正了控制权未易手这一关键规则细节，其强度评分从 68 大幅提升至 81 分，泛用性提升至 72 分。
