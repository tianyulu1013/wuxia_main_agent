# 卡牌理解校准计划

本计划用于提升 AI 对卡牌的理解，但不把 AI 理解写入源数据库。

## 当前 v0.1 样本

样本清单见：

- `data/review/understanding_samples.json`

这批样本不是强度排行榜，而是理解标尺。它们覆盖：

- 顶级强者与抢先结算：葵花老祖。
- 正面高伤害强者：萧峰、郭靖。
- 规则控制：李布衣。
- 多生命与阶段变化：金轮法王。
- 特异化长板：白飞飞。
- 卡面弱但实战价值高：方恨少。
- 多人一卡：全真七子。
- 文本/规则破坏：冢中枯骨。
- 非人物卡：九阴真经、道心种魔大法。
- AI 易解析错的结构：张愚。
- 作者指定复杂代表：桑书云、花铁干、公子羽。

## 使用方式

1. Agent 先查询目标样本的当前卡牌文本。
2. Agent 写“理解笔记”而不是直接写强度结论。
3. 作者纠正误读。
4. 纠正后的内容再进入正式理解层或评语层。

理解笔记当前文件：

- `data/review/card_understanding_notes.json`

第一条样本为 `方恨少`，状态为 `ai_draft`，用于校准“卡面弱但不占名额导致实际价值更高”的评卡原则。

## 理解笔记建议格式

- 核心定位。
- 关键机制。
- 实战价值与卡面价值差异。
- 艺术形象对齐。
- 规则稳定性风险。
- AI 易误判点。
- 可参考的相似卡。

## 禁止事项

- 不把未经作者确认的 AI 理解写入源数据库。
- 不把这 15 张样本视为强度前 15。
- 不用单一分数替代机制分析。
