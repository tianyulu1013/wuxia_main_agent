# AI 专项理解规则：阵营、结盟与关系判定

本机制模块仅服务于 AI 对五行卡牌中阵营划分（Factions）、结盟（Alliance）、以及称号对阵营/关系的修正进行结算分析。

## 1. 阵营关系的严格互斥划分

在任意游戏时点，所有玩家和角色之间的关系必须被划分为以下四个严格互斥的范畴。不存在一个卡牌单元同时属于两个范畴的情况：

1. **己方 (Self / Own)**：
   * 指某人物自身，或由同一个玩家控制且属于同一阵营的其他人物。
2. **友方 (Allies)**：
   * 指与己方结盟、结友的非己方玩家控制的阵营。
3. **队友 (Teammates)**：
   * **计算公式**：$\text{队友} = \text{己方} + \text{友方}$。所有特技中指向“队友”的效果，对己方和友方均生效。
4. **敌方 (Enemies)**：
   * 指不属于“己方”且不属于“友方”的其他所有玩家阵营。
   * 特例：即使在同一个玩家的多开控制下，如果阵营未结盟，彼此依然视为“敌方”（例如死战或特定剧本的对立结算）。

## 2. 结盟避让与从属法则

结盟是改变“敌我判定”的核心流程：

1. **基本避让法则**：
   * 不同玩家或角色一旦结盟，双方人物自动互为“队友”，互不视为敌。
   * **战斗免除**：若选战链条中抽到本来是结盟的双方，战斗**不发生**，直接跳过并选取下一个。
2. **对决发起中的结盟结算**：
   * **对局前结盟**：在挑战发起前（进入出战前阶段前）双方触发结盟，本次战斗未发生，直接取消本次对局。
   * **对局中结盟**：在战斗比拼过程中（五行卡比拼中）触发结盟：
     * 若特技写有“立即中止/取消”，则结算中止前的现有结果，然后强行中止；
     * 若无特殊中止声明，战斗照常完成全部比拼结算，结算完毕后双方正式缔结盟友。
3. **单人从属避让法则 (Subordinate Alliance)**：
   * 若某玩家阵营中的**单个人物**独立与另一方阵营结盟（且顺位低于常规结盟），而其原本阵营的队友没有参与此结盟：
   * **传递规则**：该单人从属人物将“原本的队友”和“新结盟的对手”**均视为队友**。
   * **隔离规则**：但原本的队友与新结盟的人物之间**依然互为敌方**，战斗正常发生。

## 3. 称号卡对阵营/结盟的修饰影响

* **关系/阵营改写**：**称号卡（Titles）**挂载在人物身上时，通常具有改写该人物“人际关系”和“阵营/结盟归属”的能力（如由于红鞋子称号、特定组织结盟等）。
* **生效机制**：一旦称号卡挂载，其带有的阵营修正（如“与某人结盟”、“加入某阵营”）会实时重写上述的互斥关系判定，使得原有的敌方变更为队友，触发避让法则。
