# 丁典：相克回满与特技实例限次案例

状态：作者核心语义已确认；白人模型已完成；真实环境回归开放。

## 可迁移结论

1. “相克”表示五行位置存在任一方向的克制关系，包括人物克敌和被敌克；它不等于“克敌”。
2. “受伤后回满”必须先扣血并检查死亡；生命归零时不能靠同一事件后续的回满救活。
3. “每个特技实例只能对目标使用一次”按实际实例而非名称记账；同名不同实例可以各使用一次。
4. 一次完整多段使用与第二次重新使用不同：第一次发动的全部合法内容结算，第二次发动才失效。
5. 已成功用出的特技即使被闪避或抵挡，也消耗实例机会；根本没有放出则不消耗。
6. 特技实例限次是个人防御，不自动转换成个人输出或全局控制。
7. 丁典的入神坐照只重置人物状态，不重置神照经的特技实例使用记录；该账本属于跨复活保留的本局历史。
8. 因此丁典正面与侧面生存均属很强：一项单独致死／高爆发能力通常只够消耗第一条生命，持续突破往往要求多个不同危险实例接力；这仍是个人生存，不应重复计入全局影响。

## 丁典专属边界

- 入神坐照只明确属于丁典与狄云，且故意不写成“重生”。
- 无影神拳的土土200与两平可放是丁典自身输出结构。
- 神照经明确排除自身，才能反复相克回满。
- 凌退思杀死凌霜华后强制丁典挑战并死亡，是跨卡剧情特例。
- 白人一条命约278,038.84回合、计复活约556,077.69回合，只是丁典在基础四卡低压环境中的离散吸收结果，不可迁移为其他恢复人物的寿命。
