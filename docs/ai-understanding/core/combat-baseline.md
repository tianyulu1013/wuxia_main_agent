# 核心规则：基础战斗与计算基线

状态：作者确认。  
加载：设计、改卡、评价时始终加载。

## 基础结算

- 内功相克：被克者损失100生命。
- 内功相平：双方无事。
- 招式相克：被克者损失300生命。
- 招式相平：双方各损失200生命。
- “相克”描述五行位置存在任一方向的克制关系，包括人物克敌和被敌克；只表示人物克制对方时应明确写“克敌”。

## 基础卡与空位

- 人物手中存在足够合法基础卡时，必须放满本次战斗要求的四个卡位，不能为了触发“空”或其他收益而主动少放。
- 只有规则、状态或真实卡牌不足造成的缺位才是可利用的“空”。若某特技允许用其他手牌填补空位，填入卡是否参与比较与攻击按该特技文字或作者裁定；不得默认它只是无内容占位符。
- 同一位置只有一方放有基础卡、另一方为空时，有基础卡的一方视为克敌。
- 该次克敌按卡位正常产生基础攻击：内功位100，招式位300；人物的合法普攻倍率与修正可继续作用。
- 空位不是一张基础卡，也没有物理卡名或五行；除非特技另写，不能用空位再次触发要求某张基础卡出现的效果。
- 双方同一位置都为空时，没有基础卡比较，也不产生基础攻击。

## 单个位置的基础概率

在五行均匀的基础估算中，每个对应位置：

- 克敌概率为 `1/5`。
- 被克概率为 `1/5`。
- 相平概率为 `3/5`。

计算组合条件时优先使用独立事件乘法，不为简单概率枚举全部牌形。

例如，两张招式都不被克的概率为：

`4/5 × 4/5 = 16/25`

## 白人输出基线

没有特技的白人每回合期望输出为400：

- 每个内功位期望输出：`1/5×100=20`，两个共40。
- 每个招式位期望输出：`1/5×300+3/5×200=180`，两个共360。
- 合计：`40+360=400`。

白人400只用于以正面作战为主要功能的战斗人物比较，不用于附加人物、物品、称号或场景。

## 主动特技默认放出条件

先按`../parser-guide.md`区分发动性质。内功、招式、武功只是特技类别，不代表其中每一项都是主动大招：

- 有五行放法、主动发动动作或支付代价结构的，才进入本节的主动放出模型。
- 只有触发条件、没有“可”及主动结构的，按被动自动生效，不计算主动放出率。
- 写有“可”“可以”“可选择”等授权文字但没有主动放法的，按可控效果处理，在合法窗口由玩家选择，不套用主动大招的五行放出条件。

主动大招必须先在所属位置满足牌面放法。

默认位置与放法：

- 内功默认使用两个内功位置。
- 招式和武功默认使用两个招式位置。
- `--`表示在对应位置连续两张可使用任意五行。
- `----`表示使用四个连续卡位。
- “连绵”允许按主动特技放法所需的张数，在连续位置连接使用，不受内功/招式分区边界限制；没有“连绵”不能自行跨区。

默认还要求：

1. 放法中的每一张卡都没有被克。
2. 放法中至少一张卡克敌。

只要其中一张被克，即使另一张克敌，也不能放出。牌面明确改变条件时才按例外处理。

评估主动大招必须检查：

- 占用哪些位置。
- 能否由现有八张基础卡组成。
- 放出概率。
- 放不出时剩余的基础伤害。
- 是否与同卡其他主动大招争夺位置。

## 单项修正

“单项输出提高”“单项受伤削减”“单项受伤反伤”等效果，先对每一项伤害分别处理，再合计本回合总量。不得先合并总伤害后只修正一次。

## `x*y`多次击中

形如`x*y`的主动特技表示形成`y`次独立击中，每一次攻击的基础数值为`x`：

- 每一次攻击可以分别指定场上任意一人；
- 可以集中同一目标，也可以拆分给不同目标；
- 因此评审时必须检查侧面目标输出，不能默认全部锁定当前对阵者；
- 每一击分别与闪避、抵挡、无敌及次数型防御结算。

若`x`会被其他状态动态提高，则先按该状态求出每一击的当前数值，再结算`y`次。

## 击中与防御

评审依赖“击中”“受到攻击次数”或“每次攻击”的能力时，必须区分：

- 附加伤害是一种独立攻击类型，不表示“依附在另一项攻击上的伤害”；每一项附加伤害攻击都独立进行命中与防御结算，命中后计入击中次数。
- 闪避：攻击没有击中，不计入击中次数；
- 抵挡：攻击已经击中，随后攻击或伤害被抵挡，仍计入击中次数；
- 无敌：攻击已经击中，随后攻击和效果无效，仍计入击中次数。

因此不能把“最终没有造成伤害”统一解释为“没有击中”。

## 计算原则

- 先算默认基础结算，再叠加特技。
- 优先写公式和条件，不用穷举代替简单概率。
- 特定牌形的爆发不等于整体期望。
- 牌面大数字只有乘以合法放出率、目标可用率、结算时序和存活到结算的概率后，才能进入常态评价。
