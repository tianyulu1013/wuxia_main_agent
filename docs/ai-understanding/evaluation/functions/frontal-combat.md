# 战斗人物功能：正面作战

加载条件：战斗人物主要或重要次要功能为亲自出战、平克比较和攻击敌人。

## 计算起点

1. 输出机制需要基础校验时引用白人期望400；若计算人物在真实角色环境中的承伤、生存或受击触发，暂用当前已评样本约1400的平均输出，并注明该值会随样本更新。
2. 计算本卡如何改变内功、招式、普攻和主动大招。
3. 所有主动大招先验证放法、位置、放出率和冲突。
4. 单项增伤、减伤和反伤逐项结算。

## 输出

分别计算：

- 基础四卡期望。
- 稳定普攻替换或增益。
- 主动大招的期望贡献。
- 特定常见牌形。
- 失败下限。
- 现实可达爆发上限。
- 最早结算时点、目标和穿透类型。

人物输出、受击触发或防御明显依赖攻击段数时，另登记防御前平均击中次数及方差，并按需读取`data/review/comparison/front-hit-count.json`。闪避令攻击未击中；抵挡与无敌处理的是已经击中的攻击，不能混同。

优先使用概率公式。例如两张放法均不能被克时，基础概率为 `(4/5)²`；不要为简单独立事件枚举全部牌形。

## 非伤害淘汰

人物能以杀死、彻底死亡、清除或离场直接处理敌人时，定向读取`non-damage-elimination.md`：

- 数值输出仍按攻击和伤害独立统计，不把目标生命折算为输出；
- 穿透只统计伤害兑现，不把非伤害淘汰写成穿透；
- 另算每次合法机会的淘汰概率、目标数、触发时点、预计尝试次数、至少一次成功率与期望淘汰人数；
- 人物必须活到交手后或回合结束才触发时，生存概率是淘汰模型的必要乘数；
- 第三轮正面战斗评分综合正面输出、非伤害淘汰、正面生存及其他正面能力，不能由单一输出数字决定。

## 高输出与基础生命分布

人物具有可达到常见生命量级的单次或单回合高输出时，读取`data/review/comparison/base-life-distribution.md`：

- 先将名义输出与基础生命平均数、中位数和75%分位比较；
- 需要评价“一击覆盖多少人物”时，按该文件的实体卡、多人一卡合计、多条生命及例外口径计算不计防御覆盖；
- 多人一卡以整张卡总生命判断能否整体清空，不能把每名成员拆成多个分母样本；
- 此结果只说明裸生命截断，不能冒充真实击杀率；防御、无敌、重生、生命流失、杀死与清除必须另行结算。

普通低输出模型不必加载基础生命分布，避免无关上下文。

## 正面生存

正面生存至少考虑：

- 生命。
- 基础四卡预计承伤。
- 减伤、反伤、回复、护盾和转移。
- 生命至0后的处理。
- 被克、死亡或其他后续条件。
- 能否利用信息或改牌降低下一次被克概率。
- 预计存活回合或可出场次数。

有延迟死亡、概率回复或可控制下一次被克概率时，应估算存活期望，不能只换算成未经推演的固定额外生命。

白人400只适合说明基础平克压力。当前已评样本正面输出均值约1450，日常可取整为1400作为暂定人物环境；不能再用白人低压结果直接证明人物正面生存强。若防御效果依赖攻击段数、击中次数、伤害类别或穿透，仍须说明1400总量无法替代这些尚未统一的分布。

对没有防御的人物，第一轮可以用`ceil(生命/1400)`描述离散的名义承伤窗口。例如常规生命组中位数3000在固定1400压力下约到第三回合归零，因此约有3回合名义窗口。该值不是严格生存期望，只用于初步判断一项成长能力通常能取得几次尝试；第二轮仍需加入输出方差、穿透和非伤害淘汰。

高裸生命首先只说明承伤池较厚，不能单独推出“正面生存强”。必须继续检查减伤、回复、重生、免死、无敌、避战和对多段／多来源压力的覆盖；只有裸生命较高而缺乏稳定硬防时，通常最多先记为“较强”，再等待环境承伤回归。谢烟客5500生命并有每个自身战斗回合一次定向控招，但没有固定减伤、回复、重生或免死，作者校准为正面生存较强。

## 比较

只与正面作战功能接近的已校准人物比较。至少对照：

- 常态输出
- 爆发
- 正面生存
- 结算时点
- 失败条件
- 人物名额价值
