# 薛笑人评价摘要

状态：作者机制语义已校准；第一轮定量模型完成，真实对局环境回归开放。

薛笑人是**假身份蓄势、非正常战斗介入与递增杀死型**人物。玩家每次出战可自由选择2700生命的薛笑人本体或1800生命的假身份薛宝宝，两套生命分别记录。薛宝宝死亡不影响本体，本体死亡则整张人物死亡；薛宝宝死亡后不能再次使用。

本体四卡数值输出仍为白人基线：期望400、标准差149.67、范围0至800、穿透0。但杀手剑会在交手后自动分别判定当前各敌：初始概率为`1/3`，本回合每次克敌都会先使概率提高`1/3`。在四个位置独立均匀的盲打模型中，首次单目标交手后的杀死概率为59.04%；已有一次永久增长时为86.35%，已有两次时为100%。该结果是普通“杀死”而不是伤害，不能登记为穿透输出；薛笑人必须活到交手后。

2700生命本体在当前约1400的暂定输出环境中，第一层离散近似为两个本体交手窗口。若完整取得两次本体交手并忽略先死截断，至少杀死一人的概率约86.95%，期望杀死人数约1.44。因此400伤害不能代表薛笑人的正面等价战力；以后正面战斗评分必须把数值输出、非伤害淘汰和正面生存分账后综合。

切入追杀允许薛笑人加入曾与薛宝宝交手者正在参加的战斗。原两人仍正常作战，薛笑人另放一套基础卡；攻击一方就与该方双向比对，攻击两方则分别与两方双向比对。首次状态同时攻击两方时，数值总输出期望800、标准差211.66；八次比对先累计克敌后，每名敌被杀死的边际概率为77.63%，至少杀死一人的概率约88.82%。

薛宝宝每出战一回合获得一名一次性刺客。第`j`名实际出场的刺客在回合开始先攻击`100j`，随后进行正常四卡战斗；无生命使普通攻击、伤害和生命流失对其无效，但杀死和离场有效、清除无效。无上限生命目标模型中，第`j`次刺客袭击期望输出为`400+100j`。考虑薛宝宝的定向特技保护和约三个常态资源回合，侧面横向主值改取前三名刺客`500、600、700`的单次平均600；三名合计1800只保留在详细模型。刺客没有穿透。

| 维度 | 当前结论 |
|---|---|
| 正面输出 | 本体与薛宝宝数值期望均为400，标准差149.67；本体首次交手后另有59.04%普通杀死概率 |
| 实战穿透输出 | 0；杀手剑是非伤害杀死，另行统计 |
| 侧面输出 | 前三名刺客单次平均600、混合标准差170.49；第`j`名为`400+100j`，前三名合计1800；本体切入单目标400、双目标总计800 |
| 非伤害淘汰 | 首次本体59.04%；完整取得两个本体交手窗口时，至少杀死一人86.95%、期望杀死1.44人；实际值受先死截断 |
| 正面生存 | 较强；1800假身份与2700本体分别记录，顺序使用时名义生命池4500，但本体没有硬防且杀手剑时点较晚 |
| 侧面生存 | 较强；未出战默认薛宝宝，针对性主动与可控特技不能对其使用，但被动、全体及波及仍能作用 |
| 全局影响 | 较强；永久追杀名单、无限次切入和一次性刺客可持续介入他人战斗，控制中原一点红是条件性额外收益 |
| 名次保障 | 无；没有直接结盟、投靠、免失败、顺位或特殊胜利 |

评分系统暂不填分，第三轮按全人物分布统一评分。
